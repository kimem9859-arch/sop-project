# 비전 모델 학습 이론 (YOLO)

> 2026-09-15 신설 · 비전 모델 재정립 ① · spec `docs/superpowers/specs/2026-09-15-비전모델-학습이론-design.md`
>
> - **이 문서는 이론과 근거만 담는다.** 이론으로 내린 결정(해상도·증강 등)은 통합문서 §7 에, 우리 측정 수치는 통합문서 §10 에 둔다.
> - 🔒 **출처 관문** — 주장마다 1차 출처(공식 문서·논문) 번호를 붙인다. 출처가 없으면 `⚠️ 미확인` 으로 적고 결론 근거로 쓰지 않는다. 블로그는 1차 자료가 없을 때만 `(블로그)` 로 표시한다.
> - 🔒 **기억으로 채우지 않는다** — 조회한 자료만 적는다.
> - 기존 모델(`console_v1`·`v2`, `tool_v1`~`v4`)은 **「과거에 이렇게 했다」 사례로만** 인용한다 — 결과는 근거가 아니다.
> - 형식 — 절마다 **요점 몇 줄 + 「우리 상황 적용」 한두 줄 + 출처.**
> - 조건 = ESP32 480×640 세로 · Colab CLI(T4) 학습 · Roboflow 라벨링 · Hailo `.hef` 배포
