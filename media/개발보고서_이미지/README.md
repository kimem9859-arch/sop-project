## 채우지 못한 것

- **④ BLOCK(차단) 화면** — FSM에 `State.BLOCK`은 구현돼 있으나 그 상태의 GUI 캡처가 저장소에 없다.
- **① 실콘솔 1인칭 수신 화면** — `test/raw` 세션은 전부 모조(스티커) 레이아웃이거나 작업대다.
- **⑤·⑥·⑦·⑩~⑬** — 실물 촬영 항목이라 이번 수집 대상 아님.
