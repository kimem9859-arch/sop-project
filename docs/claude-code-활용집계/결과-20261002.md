## 기준선을 정한 근거와 함정

1. **`/stats` 누적 통계는 토큰을 약 2.3배 부풀린다** — 응답 하나가 내용 블록마다 한 줄씩 **같은 usage** 로 기록되는데(평균 2.28줄 · 값이 다른 경우 0), 통계는 줄마다 더한다. 중복을 그대로 두고 더하면 통계와 98.5% 일치한다(2026-08-10 ~ 09-22). 그래서 토큰은 대화 기록에서 `(message.id, requestId)` 로 중복을 빼고 센다.
2. **2026-08-10 이전 토큰은 셀 수 없다** — 대화 기록이 지워졌다(보관 50일). 누적 통계로 낸 참고 추정 = 2026-03-28 ~ 08-09 약 5.5억 토큰 · 약 522달러(**초기 폴더·다른 폴더 포함 · 추정**). 발표 값에는 넣지 않았다.
3. **기기 구분** — sop-project·Rpi5 = 작성자 이름이 이 파이 git 사용자. 이 파이의 「만든 커밋」 기록(HEAD reflog)과 대조해 일치했다(Rpi5 458/458 · sop-project 2026-09-04 이후 618/618). **project-docs 는 데스크톱도 같은 이름을 써서** 이 파이의 기록에 있는 커밋 3건만 셌다.
