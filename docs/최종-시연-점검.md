## 2. 설치

1. **공유기를 파이와 다른 콘센트에 꽂는다.** 10/14 에는 같은 멀티탭이라 함께 꺼졌다 켜지며 안경 주소가 바뀌었다.
2. **파이1 · 파이2 를 랜선으로 공유기에 꽂는다.** 파이2 의 LLM 은 유선 주소(`192.168.1.12`)에서만 받는다.
3. **와이파이 비밀번호를 참석자에게 주지 않는다.** 10/14 에 참석자 기기가 안경 주소를 차지한 것으로 추정된다.
4. **주소** — 🔑 공유기 관리자 비밀번호를 몰라 **공유기 주소 예약은 하지 않는다**(10/21). 대신:
   - **파이2 = 파이2 자체에 `192.168.1.12` 고정**(10/21 · 공유기가 주는 주소와 함께 갖는다 · 재부팅해도 유지) — 파이2 의 LLM 은 이 주소에서만 받는다. 되돌리기 = 파이2 에서 `sudo nmcli con mod netplan-eth0 -ipv4.addresses 192.168.1.12/24 && sudo nmcli dev reapply eth0`.
   - **안경 = 공유기가 주는 주소를 그때그때 쓴다**(10/21 = `.14`) — 공유기를 껐다 켜면 바뀔 수 있다. 🔑 **시연 아이콘으로 켤 때마다 파이가 안경을 고유 번호로 찾아 주소를 자동으로 맞춘다**(10/21 · 기록 = `Demo/logs/glass_<날짜>.log` · 10/14 처럼 주소가 바뀌어 카메라가 안 붙는 일을 막는다). 그래서 **안경을 먼저 켜고 시연을 켠다.** 못 찾으면 옛 주소로 켜지고 기록에 「못 찾음」이 남는다.
   - ⚠️ 공유기 와이파이 `iptime` 은 **비밀번호가 없는 열린 망**이고 이름이 흔해, 예전에 다른 `iptime` 에 붙어 본 휴대폰이 저절로 붙는다(10/21 모르는 기기 1대 · 10/14 안경 주소 뺏김 추정). 파이2 를 **안경보다 먼저** 켜 두면 `.12` 를 다른 기기가 받을 일이 줄어든다.
   - 🔑 집에서는 파이1 · 파이2 가 공유기 없이 랜선으로 직결돼 있어 유선 주소가 없다 — **집에서는 음성비서 LLM 이 닿지 않는다.**
5. **부저 선을 연결한다**(측정 때 소음 때문에 빼 두던 선).
5-1. **모니터 두 대** — 🔴 라즈베리파이 5 의 두 마이크로 HDMI 단자는 붙어 있어 플러그가 부딪힌다. **전원 단자에서 먼 쪽에 제우스랩을 먼저 끝까지 꽂고, 가까운 쪽에 TV 를 나중에** 꽂는다(10/21 — 반대 순서면 먼 쪽이 덜 들어가 인식이 안 됐다).
   - 화면 구성은 파이가 켜질 때 저절로 맞춘다(`/usr/share/dispsetup.sh` — 제우스랩을 이름으로 찾아 메인 1920×1280 · 다른 모니터 = 같은 화면을 꽉 채워 복제 · TV 는 가로로 약간 넓어 보인다). 되돌리기 = `sudo cp /usr/share/dispsetup.sh.orig-20261021 /usr/share/dispsetup.sh`.
   - **TV 소리** — 시연 아이콘으로 켤 때마다 소리 출력을 TV 로 맞춘다(TV 기본 출력 · 음소거 해제 · 파이 쪽 40% · 제우스랩 음소거 — `Demo/audience_audio.py`). TV 리모컨 음량 **10** 이 콘솔 반경 2m 에 맞았다(10/21 사용자).
6. 릴레이 차단 — ⏸ 학교에서 실물 작업 뒤 이 줄을 채운다. 🔴 NO 접점으로 바꾸면 **아두이노 USB 가 빠지면 버튼 4개가 모두 먹통**이 된다(설계상 의도 · EMO 는 영향 없음).

## 4. 점검 도구 — 약 30초

**시연 프로그램을 켜기 전에** 바탕화면의 터미널(LXTerminal)에서:

```bash
cd ~/sop-project/Rpi5 && python3 Demo/test/school_check.py --final
```

- **전부 ✅ 이면 다음으로.** ❌ 가 있으면 그 줄 아래 「→ 대처」를 따른 뒤 다시 돌린다.
- 시연이 이미 켜져 있으면 안경 연결 · 받기 · 마이크/명령 포트 · 인터락 · Hailo 쥔 프로세스는 「건너뜀」으로 나온다(안경은 연결을 하나만 받아, 점검이 시연 연결을 끊지 않게). 시연을 닫고 다시 돌린다.
- 대처 문구의 `V1`~`V10` 번호는 10/12 학교 방문 대처표(`docs/superpowers/specs/2026-10-12-학교방문준비-design.md` §8.1)의 번호다. 번호 뒤 설명만 따라도 된다.

| 묶음 | 보는 것 |
|---|---|
| 안경 | 공유기 대역인가 · 5초 받아 본 fps |
| 음성 | 안경 마이크 · 명령 포트 · 답 소리 파일 · **파이2 LLM 이 닿고 시연 모델이 있나** · **관객 소리(TV)** — 기본 출력이 TV · 음소거 아님 · 제우스랩 음소거 |
| Hailo | 장치가 보이나 · 다른 프로그램이 쥐고 있지 않나 |
| 파이 | 온도 · 전압/열 경고 기록 · 남은 공간(1GB 이상) · 메모리 |
| 인터락 | 아두이노가 램프 명령에 답하나 |
| 코드 | 지금 코드 판 · 커밋 안 된 변경 · 남은 `SOP_*` 변수 |
| 파일 | 모델 · 보정 파일 · 안경 펌웨어 백업 |

## 5. 시연 켜고 확인 — 약 3분

1. 바탕화면 **「SOP 가디언 최종 시연」** → 전체 화면이 뜬다.
2. 오른쪽 아래 상태 막대 — 카메라 ● fps · 인터락 ● · 버튼 ● 이 모두 정상인가.
3. **정상 1판** — 「작업 시작」 → B1 → B2(렌치를 쥔다) → B3 → B4 → 결과창 「완주 성공」.
4. **위반 1번** — 1단계에서 B3 위에 손을 가져간다 → 경고(황색 램프 · 「순서가 다릅니다」 · 안경 알림) → 그대로 B3 를 누른다 → 차단(적색 램프 · 부저 · 「버튼 입력 차단」) → 왼쪽 아래 「차단 해제」.
5. **음성 1번** — 「가디언」 → 띠링 → 「지금 몇 단계야?」 → 안경에서 답.
6. 메뉴 → 「작업 초기화」로 처음 상태에 둔다.
7. **시연 안내(참여자가 혼자 할 때)** — 메뉴 → 「설정」 → 「시연 안내」 **켬**(켤 때마다 끔으로 시작한다) → 참여자가 안경을 쓰고 「작업 시작」 → 안경에서 1번 콘솔 안내부터 16번 완료 안내까지 나온다. 끄면 바로 멈추고 알림은 번호(B1~B4)로 돌아간다. 대본 · 시작 조건 = `docs/superpowers/specs/2026-10-18-시연안내모드-design.md` §4 · §4.3.
   - 🔑 **시연 안내가 켜져 있으면 「가디언」은 15번 「지금 바로 "가디언"이라고 불러 주세요」가 끝난 뒤부터 그 장면이 끝날 때까지만 받는다**(10/21 · 관객 말소리 · TV 소리에 흔들리지 않게). 그 밖에 부르면 띠링이 안 나는 것이 정상이다. 시연 안내를 끄면 언제나 받는다.
8. **TV 소리(관객)** — 안경에서 나는 소리(안내 · 알림 · 띠링 · 답)가 TV 에서도 함께 난다. 메뉴 → 「설정」 → 「TV 소리」 **끔**이면 안경에서만(켤 때마다 켬으로 시작).
9. **스침 판정 카드(10/22)** — 오른쪽 아래 「스침 판정」 카드가 틀린 버튼 쪽 손의 머무름 · 손끝 속도와 결과(「스침 인정」 · 「경고 · 느린 진입」 · 「경고 · 머무름」)를 보여 준다. 메뉴 → 「설정」 → 「판정 게이지」 **끔**이면 숨김(켤 때마다 켬). **스침으로 인정되려면** 버튼 바깥에서 출발해 멈추지 말고 한 번에 지나간다 — 버튼 안 손끝이 **600px/s** 보다 느리거나 링에 닿고 0.3초가 지나도 버튼 위에 있으면 경고(통합문서 §7.4 · §12.102). 🔑 발표 자료의 700 은 10/22 현장 시험으로 600 으로 조정하기 전 값이다 — 질문을 받으면 그렇게 답한다.

## 6. 시연을 기다리는 동안

- **안경은 시연 직전까지 충전기에 꽂아 완충 상태를 유지한다.** 충전 뒤 약 30~36분이면 화면에 줄무늬 · 초록빛이 생긴다.
- 화면은 「작업 시작」 버튼이 보이는 처음 상태로 둔다.
- 음성 녹음은 켜지 않는다(사용자 10/15).
- **화면 녹화도 하지 않는다** — 10/22 녹화 중 영상이 초당 약 3장 줄었다(16.5~19.8 → 13.8~17.5). 녹화가 꼭 필요하면 시연이 아닌 연습 판에서.

## 7. 문제가 생기면

| 증상 | 먼저 할 것 | 그래도 안 되면 |
|---|---|---|
| 영상이 멈춤 · 끊김 | 메뉴 → 「점검 (연결)」 → 「재연결」 | 안경 전원 · 배터리 확인(10/14 에 안경이 스스로 재부팅한 일이 있다 · 원인 미상) → 30초 기다린 뒤 재연결 → **안경 주소가 바뀌었으면**(점검 도구 「연결 · 받기」 ❌) 🔴 **메뉴 「프로그램 종료」(또는 ESC)로 닫고 바탕화면 아이콘으로 다시 켠다** — 켤 때 고유 번호로 다시 찾는다(시연은 켤 때 읽은 주소만 쓴다 — 「재연결」은 옛 주소로 다시 붙는다) → 그래도 못 찾으면 안경을 USB 로 꽂고 `bash ~/sop-project/Rpi5/arduino/update_ip.sh` |
| fps 가 평소(약 18~19)보다 크게 낮음 | 안경을 공유기 쪽으로 · 창밖처럼 복잡한 장면을 피한다(10/14 창밖 나무 13.5 fps → 벽 18~19 fps) | 안경 전원을 껐다 켠다(다른 와이파이에 붙었을 수 있다) |
| 음성비서가 답하지 않음 | 경고 · 차단 중에는 원래 답하지 않는다 — 해제 뒤 다시 | 안경 전원 · 배터리 → `Rpi5/Demo/logs/voice_<시각>.log` 의 「준비 상태」 줄. LLM 이 안 돼도 지금 작업 상태로 만든 문장으로는 답하므로 침묵의 원인이 LLM 은 아니다(LLM 은 점검 도구 「파이2 LLM 응답」 줄) |
| 인터락이 끊김 — 상태 막대의 인터락 ● 이 빨강 · 차단 때 「⚠ 인터락 미연결 — 화면에서만 차단 중」(EMO 면 「⚠ 화면에서만 차단 · EMO 복귀 뒤 해제」) | 아두이노 USB 를 다시 꽂는다(장치를 못 찾는 동안은 자동으로 다시 붙는다) | 메뉴 → 「점검 (연결)」 → 「재연결」(장치는 찾았는데 5번 못 열면 자동 재시도를 멈춘다) |
| **TV 소리가 안 남** | 설정 「TV 소리」가 켬인가 · TV 음량 · TV 를 껐다 켰나 | 메뉴 → 「프로그램 종료」 → 아이콘으로 다시 켠다(켤 때 소리 출력을 다시 맞춘다) → 그래도 안 되면 점검 도구 「관객 소리(TV)」 줄 · `Demo/logs/audience_<날짜>.log` |
| **제우스랩 화면이 꺼지거나 TV 가 안 나옴** | 5-1 꽂는 순서(먼 쪽 제우스랩 먼저) · 모니터 전원 | 파이를 다시 켠다(켤 때 화면을 다시 맞춘다) |
| 시연 안내가 안 나옴 | 설정 「시연 안내」가 켬인가(프로그램을 다시 켜면 끔) · 「작업 시작」을 켠 **뒤에** 눌렀나(작업 도중 켜면 다음 회차부터) | `Rpi5/Demo/logs/guide_<시각>.log`(켠 뒤 생김 · 어느 문장을 왜 냈나) · 음성비서 기록의 「📣 안내 →」 줄 · 소리 파일 검사 `python3 Rpi5/Demo/voice/make_guide.py --check` |
| 버튼이 안 먹음 | 차단 중인가(왼쪽 아래 「차단 해제」) · EMO 가 눌려 있나 | |

## 8. 끄는 순서

1. 시연 화면 **메뉴(≡) → 「프로그램 종료」 → 「종료」**(키보드가 없을 때 · 10/21) 또는 **ESC** → 시연 창 · 터미널 · 음성비서 · 시연 안내가 함께 닫힌다(10/21 실물 확인). ESC 는 메뉴 · 결과창 · 로그 · 안내 상자가 열려 있으면 그것부터 닫으니 여러 번 누른다.
2. 파이2: 파이1 터미널에서 `ssh pi@192.168.1.12 sudo poweroff`(처음 접속이면 `yes` 를 한 번 친다)
3. 파이1: 바탕화면 왼쪽 위 메뉴 → 「Shutdown(종료)」(시연 화면 메뉴에는 종료가 없다 · 10/14 개편 때 시연에 필요 없어 뺐다)
4. 화면이 꺼지고 초록 불이 멈춘 뒤 멀티탭 스위치를 끈다 — 바로 뽑으면 SD 카드가 상할 수 있다.
