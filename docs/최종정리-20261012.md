## 4. 10/13 시연 전 점검(새 작업이 아니라 확인만)

1. 바탕화면 「시연」 아이콘으로 기동 → 처리 2a · 속도 문턱 · 음성 알림 켬이 실제로 적용됐는지(10/12 미뤄 둔 확인).
2. 부저 연결 → 차단 때 울리는지.
3. 즉답 — 대본 질문 7종(지금 몇 단계야? · 다음에 뭐 눌러야 돼? · 지금 눌러야 하는 버튼이 뭐야? · 이번 단계에 무슨 공구 필요해? · 앞에 보이는 공구가 뭐야? · 지금 상태 어때? · 작업 결과 어때?)을 한 번씩 물어 답이 맞는지 · **하나라도 틀리면 즉답을 끄고 시연**.
4. 안경 충전 · 화면 검사 · 와이파이 주소(192.168.1.x — 폰 핫스팟이면 안경만 다시 켬).
5. 정상 1판 + 경고 장면 1판 리허설(손을 빠르게 하지 않는다).

## 6. 발표에 옮길 때 지킬 것(`.claude/rules/수치인용.md`)

- 수치에는 **조건(장소1 · 1인 · 실콘솔 · 날짜)**을 같이 적는다 · 세션 하나의 값이 아니라 **통합값**을 쓴다.
- 「검증 완료」로 단정하지 않는다 — 「장소1 · 1인 조건에서 목표 충족」.
- 모조 콘솔 시절 값(개입 감지율 92% · mAP50 0.992 등)과 옛 모델 값은 지금 판정에 쓰지 않는다.
- 음성 알림 0.835초는 옛 목소리(kss) · 10/10 기록이다 — 지금 목소리(Supertonic 2)로는 재지 않았다.
