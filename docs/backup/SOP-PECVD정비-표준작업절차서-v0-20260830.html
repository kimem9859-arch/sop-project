1. 목적

본 절차서는 PECVD(플라스마 화학기상증착) 챔버의 웻클린 정비 작업을 정해진 순서대로 수행하도록 규정하여, 순서 누락·역순으로 인한 잔류 유해가스 노출, 고온 전극 접촉, 잔압 상태의 챔버 개방 사고를 예방하는 것을 목적으로 한다.

2. 적용 범위

  • 적용 대상 — PECVD 챔버 웻클린 정비(PM, make-safe) 작업 1종
  • 적용 인원 — 해당 장비의 정비 자격을 갖춘 작업자 및 감독자
  • 제외 사항
    • 웨이퍼 생산 운전(공정 레시피 수행) 절차는 본 절차서의 대상이 아니다.
    • 챔버 부품 반출 후의 세정조(HF 침적) 작업은 별도 절차서를 따른다.
    • 본 절차서에 부속된 감시 시스템은 버튼 조작의 순서만 판정하며, 가스 누출을 감지하거나 차단하지 않는다.

3. 용어 정의

용어정의
PECVD플라스마 화학기상증착. 플라스마를 이용해 웨이퍼 표면에 박막을 입히는 공정
웻클린
(Wet Clean)		챔버 내부에 쌓인 증착물을 부품 분해·습식 세정으로 제거하는 정비 작업
make-safe정비 착수 전 설비를 안전한 상태(가스 차단·감압·냉각·대기압)로 만드는 일련의 조치
퍼지 (Purge)챔버 내 잔류 가스를 불활성 가스(N2)로 밀어내어 치환하는 것
벤트 (Vent)진공 상태의 챔버에 기체를 넣어 대기압으로 복귀시키는 것
LOTOLockout/Tagout. 위험 에너지원을 차단·잠금하고 표지를 부착해 정비 중 재기동을 막는 절차
EMOEmergency Off. 비상정지 버튼
순서 위반기대되는 단계가 아닌 단계의 버튼을 조작하는 것. 누락(뒤 단계로 건너뜀)과 역순(이미 지난 단계로 되돌아감)으로 나뉜다

4. 책임 및 역할

역할책임
정비 작업자본 절차서의 단계를 순서대로 수행하고, 각 단계의 확인 사항을 점검·기록한다
정비 감독자작업 착수 전 준비 상태와 LOTO 시행을 확인하고, 완료 후 기록을 검토·서명한다
안전 담당자유해가스 관련 위험요인과 보호구 착용 상태를 확인한다
시연 환경에서는 1인이 정비 작업자 역할을 수행하며, 감독자 확인은 생략한다.

6. 위험요인 및 안전 주의사항

단계위험요인안전 조치
1SiH4(실란) — 자연발화성 원료가스. 차단 전 후속 단계 진행 시 잔류·발화 위험가스 차단 밸브 폐쇄 상태를 지시등으로 확인
1CF4/O2 플라스마 클린 부산물 — 불소계 잔류물클린 완료 표시 전 다음 단계로 넘어가지 않는다
2잔류 가스 — 퍼지 미완 시 챔버 내 유해가스 잔존N2 퍼지를 규정 사이클 이상 수행
2N2 자체 — 밀폐 공간 산소 결핍배기 상태 확인
3고온 전극 — 냉각 미완 시 화상온도 하강 완료 표시 확인 후 진행
4잔압 상태 개방 — 챔버 급개방 시 내용물 분출대기압 도달 확인 후 개방
위 위험은 모두 ‘앞 단계를 건너뛰었을 때’ 현실화된다. 각 단계는 다음 단계의 안전 전제이므로, 어떤 이유로도 순서를 바꾸어 수행하지 않는다.

7. 작업 절차

7.1 절차 요약

단계작업 내용조작완료 확인 사항확인
1플라스마 클린(CF4/O2) 및 SiH4 공급 차단B1클린 진행 완료 표시 · 가스 차단 확인☐
2펌프 다운 및 N2 퍼지 (2사이클 이상)B2퍼지 완료 표시 · 스패너 지참☐
3전극 냉각 (약 300℃ 이하)B3온도 하강 완료 표시☐
4챔버 벤트 및 개방B4대기압 도달 · 정비 착수 가능☐

7.2 단계별 상세

단계 1 — 클린·가스차단 (버튼 B1)

① 콘솔에서 B1(클린·가스차단) 버튼을 누른다.
② 플라스마 클린이 진행되는 동안 대기한다. 대기 시간이 경과할 때까지 다른 버튼을 조작하지 않는다.
③ 진행 완료 표시를 확인한다. → 자동으로 단계 2로 진행된다.

버튼을 누르는 것만으로 단계가 끝나지 않는다. ‘버튼 조작 + 후속 대기’가 하나의 단계이며, 대기 중 다른 버튼을 누르면 순서 위반으로 판정된다.

단계 2 — 펌프/퍼지 (버튼 B2)

① B2(펌프/퍼지) 버튼을 누른다.
② N2 퍼지가 2사이클 이상 진행되는 동안 대기한다.
③ 대기 중 스패너(wrench)를 손에 든다. 대기 시간 경과와 공구 지참이 모두 충족되어야 다음 단계로 진행된다.
④ 조건 충족 시 자동으로 단계 3으로 진행된다.

단계 3 — 전극 냉각 (버튼 B3)

① B3(전극 냉각) 버튼을 누른다.
② 전극 온도가 약 300℃ 이하로 내려갈 때까지 대기한다.
③ 온도 하강 완료 표시를 확인한다. → 자동으로 단계 4로 진행된다.

단계 4 — 챔버 벤트·개방 (버튼 B4)

① B4(챔버 벤트) 버튼을 누른다.
② 챔버가 대기압에 도달했음을 확인한다.
③ 챔버를 개방한다. → 정비 착수 준비 완료. 본 절차 종료.

8. 순서 위반 시 조치

본 작업은 1인칭 비전 AI 감시 시스템의 감시를 받는다. 시스템은 작업자의 손이 기대되지 않는 버튼에 접근·체류하면 다음과 같이 개입한다.

상황시스템 동작작업자 조치
잘못된 버튼에 손이 접근화면에 접근 표시손을 뗀다
잘못된 버튼 위에 손이 체류경고 (WARNING)즉시 손을 떼고 현재 단계를 확인한다
잘못된 버튼을 누름차단 (BLOCK) — 작업 정지감독자에게 보고 후, 해제 시 직전에 수행하던 단계부터 다시 수행한다
위반이 발생해도 단계는 진전되지 않는다. 차단이 해제되어도 기대 단계는 그대로 유지되므로, 건너뛴 단계를 반드시 수행해야 한다.

9. 비상 시 조치

① 이상 상황(가스 냄새, 이상음, 화재, 부상) 발생 시 즉시 비상정지(EMO) 버튼을 누른다.
② 작업 구역에서 대피하고 감독자·안전 담당자에게 즉시 보고한다.
③ EMO 조작 시 시퀀스 전체가 중단되며, 재개 시 단계 1부터 다시 수행한다. 중간 단계부터 재개하지 않는다.
