# 파이 홈 폴더 배치·생성 규칙

> Pi#1(`sop-pi`)의 `/home/pi` 최상위를 어떻게 쓰는가. **이 문서가 정본**이고 `~/README.md`는 여기를 가리키는 포인터다.
> 배치 근거·경위 = `docs/superpowers/specs/2026-08-18-파이-홈-폴더정리-design.md`

## 1. 최상위에 새 폴더를 만들지 않는다

아래 5개 + 표준 폴더가 **전부**다. 여기 안 맞는 것이 생기면 폴더를 새로 파지 말고 **이 문서를 먼저 고친다.**

```
~/
├─ sop-project/     프로젝트 정본 (Rpi5 포함)
├─ data/            데이터셋
├─ lab/             실험 산출물
├─ env/             환경·외부 자산
├─ shots/           스크린샷·잡파일
└─ _archive/        끝난 것
```

## 2. 어디에 넣나

| 만든 것 | 갈 곳 |
| --- | --- |
| 데이터셋 (Roboflow export·병합본·네거티브 세트) | `data/` |
| 실험 산출물 (예측 JSON·오버레이 이미지·측정 스크립트) | `lab/<주제>/` |
| 가상환경·외부 repo·툴체인 | `env/` |
| 스크린샷·목업·일회용 파일 | `shots/` |
| 끝나서 안 볼 것 | `_archive/` |
| 프로젝트 코드·문서 | `sop-project/` (repo 안) |

**축은 「이것이 무엇이냐」(역할)다.** 「어떤 실험이냐」나 「언제 했냐」가 아니다.
새 산출물이 생겼을 때 가장 덜 헷갈리는 기준이기 때문이다.

## 3. 이름 규칙

- **`lab/` 아래 새 주제는 케밥케이스 소문자** — `tool-detect`, `neg-screening`, `hoi`
- **그 안의 개별 산출물은 기존 이름을 유지한다** — `tool_eyeball_v2_0.65` 처럼 조건이 이름에 박힌 것은 문서가 그 이름으로 인용하고 있다. 바꾸면 인용이 끊긴다.
- `data/` 의 데이터셋은 `ds_` 접두 유지 — `ds_6tool`, `ds_tool_v3`

## 4. 홈에 파일을 직접 떨구지 않는다

⚠️ **스크린샷은 수동으로 옮긴다.** `Print` 키 바인딩은 `/etc/xdg/openbox/rpd-rc.xml` 의
**시스템 전역 설정**이라 `sudo` 가 필요하고 패키지 업데이트 때 되돌아간다.
자동화하지 않기로 했으므로(2026-08-18 결정), 찍은 뒤 `mv ~/*_scrot*.png ~/shots/` 로 옮긴다.

## 5. 옮기면 안 되는 것 (예외)

| 폴더 | 옮기면 깨지는 것 |
| --- | --- |
| `bin/` | `.profile:20` 이 `$HOME/bin` 을 PATH에 자동 추가 → `arduino-cli` 미검출 |
| `Arduino/` | arduino-cli 스케치북 기본 경로 |
| `Desktop`·`Documents`·`Downloads`·`Music`·`Pictures`·`Public`·`Templates`·`Videos` | XDG 표준. 데스크톱 환경·`Rpi5/scripts/yolo_camera.py` 가 참조 |
| `thinclient_drives` | RDP 세션이 자동 생성 |

## 6. 🔴 코드가 무는 경로 — 옮길 땐 코드도 같이 고친다

아래 폴더를 옮기면 **런타임이 조용히 죽거나 기능이 비활성된다.**
`~/lab/hoi` 가 없으면 손 검출이 **오류 없이** 꺼지므로 눈치채기 어렵다.

| 폴더 | 무는 곳 |
| --- | --- |
| `~/lab/hoi/` | `Rpi5/Demo/config.py:211-212` (`HAND_MODELS_DIR`·`HAND_BLAZE_DIR`) · `Demo/test/hoi_probe.py:33-34` |
| `~/env/rfenv/` | `Rpi5/Demo/config.py:262` (`TOOL_WORKER_PYTHON`) |
| `~/lab/tool-detect/tool_live_shots/` | `Rpi5/Demo/test/tool_live.py:63` (`SHOT_DIR`) |
| `~/Downloads`·`~/Videos` | `Rpi5/scripts/yolo_camera.py:6,13` |

**옮긴 뒤 검증** — 경로 실존 확인만으로는 부족하다. `run_demo.sh` 를 실제로 띄워
로그에 `손 검출(HOI): 사용 가능` · `공구 검출: 사용 가능` 이 찍히는지 본다.

## 7. 지금 없는 것을 새 경로로 적지 않는다

`~/arcad_v9`·`~/ds_mmmxd`·`~/ds_hmqnl` 은 2026-08-12에 **삭제된 데이터셋**이다
(`dev/ai_model/tool_v1/README.md:99`). 문서에 옛 경로로 남아 있는 것이 맞다.
경로 일괄 치환 때 이것들까지 바꾸면 **없는 폴더를 있는 것처럼 가리키는 거짓 경로**가 된다.
