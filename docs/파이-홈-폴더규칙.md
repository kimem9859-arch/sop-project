## 1. 최상위에 새 폴더를 만들지 않는다

아래 6개 + 표준 폴더가 **전부**다. 여기 안 맞는 것이 생기면 폴더를 새로 파지 말고 **이 문서를 먼저 고친다.**

```
~/
├─ sop-project/     프로젝트 정본 (Rpi5 포함)
├─ data/            데이터셋 — 만드는 동안만 · 다 쓴 데이터셋은 데스크톱(9장) · 기록은 파이2 보관함(8장)
├─ lab/             실험 산출물
├─ env/             환경·외부 자산
├─ shots/           스크린샷·잡파일
├─ _archive/        끝난 것 — 파이1 에는 두지 않고 파이2 `~/보관/_archive/` 로 보낸다(8장)
└─ project-docs/     문서 작업 저장소 — hanium-장려상/(한이음 공모전) · 융합프로젝트/(학교 프로젝트 과정 문서) · 제출물 실물은 Documents/한이음-제출문서/
```

## 2. 어디에 넣나

| 만든 것 | 갈 곳 |
| --- | --- |
| 데이터셋 (Roboflow export·병합본·네거티브 세트) | `data/` — 다 쓰면 데스크톱 `~/data/파이자료/데이터셋제작/` |
| 실험 산출물 (예측 JSON·오버레이 이미지·측정 스크립트) | `lab/<주제>/` |
| 가상환경·외부 repo·툴체인 | `env/` |
| 스크린샷·목업·일회용 파일 | `shots/` |
| 끝나서 안 볼 것 · 파이에서만 쓰던 기록(측정 원본 · 쓴 모델) | 파이2 `~/보관/<파이1 홈 기준 경로>`(8장) |
| 프로젝트 코드·문서 | `sop-project/` (repo 안) |
| 제출문서(개발보고서·제작설계서·시연영상) | 실물 = `Documents/한이음-제출문서/` · 작업 = `project-docs/hanium-장려상/` — **별도 저장소**다. Word·PPT 편집은 데스크톱에서 한다(파이는 PDF 를 읽고 대조만) |
| 학교 융합프로젝트 과정 문서 | `project-docs/융합프로젝트/` (같은 별도 저장소) |

**축은 「이것이 무엇이냐」(역할)다.** 「어떤 실험이냐」나 「언제 했냐」가 아니다.
새 산출물이 생겼을 때 가장 덜 헷갈리는 기준이기 때문이다.

## 3. 이름 규칙

- **`lab/` 아래 새 주제는 케밥케이스 소문자** — `tool-detect`, `neg-screening`, `hoi`. 한글 이름도 쓴다(`화면검사` · `리허설` · `음성확인` 등) — 코드 · 기록이 부르는 지금 이름은 바꾸지 않는다
- **그 안의 개별 산출물은 기존 이름을 유지한다** — `tool_eyeball_v2_0.65` 처럼 조건이 이름에 박힌 것은 문서가 그 이름으로 인용하고 있다. 바꾸면 인용이 끊긴다.
- `data/` 의 데이터셋은 `ds_` 접두 유지 — `ds_6tool`, `ds_tool_v3`

## 4. 홈에 파일을 직접 떨구지 않는다

⚠️ **스크린샷은 수동으로 옮긴다.** `Print` 키 바인딩은 `/etc/xdg/openbox/rpd-rc.xml` 의
**시스템 전역 설정**이라 `sudo` 가 필요하고 패키지 업데이트 때 되돌아간다.
자동화하지 않기로 했으므로(2026-08-18 결정), 찍은 뒤 `mv ~/*_scrot*.png ~/shots/` 로 옮긴다.

## 10. 데스크톱 Windows(`C:\` · `D:\`)

**Windows 에는 프로젝트 파일을 두지 않는다** — WSL 9장 자리에 둔다. 예외 = WSL 에서 열거나 실행할 수 없는 것만 `D:\SOP가디언\` 한 곳에.

| 파일 종류 | 갈 곳 |
| --- | --- |
| 한글(`.hwp` · `.hwpx`) · Office(`.docx` · `.pptx` · `.xlsx`) · draw.io(`.drawio`) 원본 — 원본과 그 PDF 는 같이 | `D:\SOP가디언\문서\` |
| Windows 실행 파일(X-AnyLabeling 등) | `D:\SOP가디언\도구\` |
| 그 밖(데이터셋 · 영상 · 사진 · PDF · 모델 · 로그 · 코드 · 글) | WSL(9장) |
| Windows 가상환경(`venv`) | 두지 않는다 — `requirements.txt` · 패키지 목록으로 다시 만든다 |

- 폴더는 쪼개지 않는다 — 폴더 하나는 「주로 무엇으로 여나」로 한 곳에.
- 프로젝트와 관련 없는 폴더 이름 · 개인 파일(사진 · 음악 · 이력서 · 게임 · 앱 바로가기)은 이 규칙 밖이다.
