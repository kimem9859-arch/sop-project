## 매 반복에서 할 일
1. 이 파일의 「진행표」에서 **맨 위의 ☐ 한 항목**을 고른다.
2. 기준(아래)으로 그 항목을 점검하고, 문제가 있으면 문안 파일을 고친다. 인용 문구는 **원문을 다시 열어 대조**한다(scratchpad 에 받기 · 못 열면 그 인용을 약하게 하거나 빼고 기록).
3. 진행표의 그 항목을 ☑ 로 바꾸고 「점검 기록」에 한 줄: `- <항목> — 고친 것 N건: <요약> · 사용자 판단 필요: <없음/내용>`.
4. 경로 지정 add 로 커밋: `docs(정본검토-루프): <항목> — <요약>` + 서명 두 줄(Co-Authored-By: Claude Opus 5 <noreply@anthropic.com> · Claude-Session 줄). push 금지.
5. 모든 항목이 ☑ 이면 「최종 통독」 항목을 수행하고, 통독에서 **고칠 것 0건**일 때만 `<promise>REVIEW COMPLETE</promise>` 를 출력한다. 고칠 것이 있으면 고치고 기록한 뒤 통독을 다시 ☐ 로 둔다.
