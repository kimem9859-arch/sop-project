# 캡스톤 대회 기능 현황 — SOP 가디언

> **이 문서는** 교내 캡스톤 작품대회(본선 2026-10-23) 준비의 **출발점**이다. 지금 시연 프로그램이 무엇을 하는지, 대회 때 어떤 모습이어야 하는지, 그 사이에 남은 일이 무엇인지를 기능마다 한 줄로 놓는다.
>
> - **기준 시점**: 2026-10-15 · 시연 프로그램 Rpi5 `d22f4f3` · 문서 sop-project `56c6971`
> - **근거 원칙**: **코드가 사실이다.** 통합문서 · 성능검증 저널 · 작업로그는 낡았을 수 있어 참고만 했고, 코드로 확인되지 않은 서술은 넣지 않았다. 실물에서 확인하지 못한 것은 ⏸ 로 표시했다.
> - **바탕 문서**: [`프로젝트-최종정리.md`](프로젝트-최종정리.md)(2026-10-12 · Rpi5 `bfba16f`). 그 뒤 시연 프로그램 커밋 37개를 코드로 대조해 바뀐 것을 반영했다 — 3장.
> - 🔴 **정본이 아니다.** 어긋나면 통합문서가 이긴다. 다만 통합문서에 아직 안 적힌 변경이 있다(5장).
> - 「대회 때 목표 형태」 칸은 **제안**이다. 사용자 확인 전까지 확정이 아니다.

### 4.2 문서끼리 어긋나 있는 것 (정본 정리 때 고칠 것)

- **통합문서에 아직 안 적힌 변경** — 단계 · 서브 작업 이름 · 대기 5초(§5.1 · §5.1.1) · 음성 개선 4건(§9) · 경고 상자 해제 버튼 없음 · 메뉴 4개
- **최종정리(10/12)의 `config.py` 줄 번호**가 모두 밀렸다(613줄 → 644줄). 예: 체류 `:181` → `:195`
- **음성 평가 자료가 옛 이름** — `voice/question_set.py` · `voice/llm_gate.py` 는 옛 단계 이름 · 10초 그대로다(커밋이 의도적으로 남김). 그래서 문서의 음성 질문 세트 수치(99문항 · 대체율 · 답이 88% 갈림)는 **옛 이름 · 10초 레시피에서 잰 값**이다.
- **주석에 남은 옛 값** — 「20초」(`voice_lib.py:32·102` · `voice_assistant.py:882`) · 「PANEL_BACKGROUND 기본 끔」(`overlay.py:911`). 동작과는 무관하다.
- **왜곡 보정 파일** `camera_calibration_1024x768.npz` 는 2026-09-23 작성 — 10/10 안경 카메라 교체 뒤 다시 만들지 않았다(최종정리 §12 와 같음).
