## 🔴 1순위 — 근거 없는 수치 (개발보고서 19쪽)

> 「음성 인식 약 0.1 초와 **답변 재생 약 0.3 초**」

**뒷값을 지운다.** 「음성 인식 약 0.1 초」만 남긴다.

| 왜 | 근거 |
| --- | --- |
| 원값이 4ms·3ms 를 포함한다 | `계측.jsonl` 1258·83·**4**·77·86 ms |
| 답변 10 회 **전부 ACK 실패** | `"재생성공": false` ×10 · 로그 「🔴 재생이 확인되지 않았다」×10 |
| 0.3 초의 정체 | **ACK 를 기다리다 포기한 시각**의 평균 |
| 실제 답변 음성 길이 | **1.5~2.9 초** (`Demo/voice/wav/*.wav`) |

🔑 **STT 0.1 초는 살려도 된다** — `transcribe()` 실측(53~211ms)이다.
