## 그대로 옮겨 쓰는 본문

### 2. 오픈소스 라이선스 및 저작권

#### 1) 라이선스 준수 방침

- 본 프로젝트는 외부 서버 없이 장비 안에서 동작하는 엣지 온디바이스 시스템으로, 학습·추론·판정·음성 처리에 사용한 오픈소스와 공개 데이터셋의 라이선스를 사용 전 원문으로 확인하고 조건을 준수함
- 변경을 가한 공개 데이터셋은 원저작자 표시와 변경 사실을 함께 명기함
- 자체 제작한 소스코드·데이터셋·문서의 저작권은 팀에 귀속됨

#### 2) AI 모델 및 학습 프레임워크

| 구분 | 명칭 · 버전 | 라이선스 |
| --- | --- | --- |
| 객체 검출 | Ultralytics YOLOv8 8.4.117 | **AGPL-3.0** |
| 손 검출·관절 | MediaPipe 0.10.18 (BlazePalm, BlazeHandLandmark) | Apache 2.0 |
| 소형 언어모델 | gemma4:e2b-it-qat | **Apache 2.0** |
| 음성 인식·합성 엔진 | sherpa-onnx 1.13.7 | Apache 2.0 |
| 음성 합성 음성 | vits-mimic3 ko_KO/kss_low | **CC0 1.0** (퍼블릭 도메인) |
| 음성 인식 모델 | sherpa-onnx-zipformer-korean-2024-06-24 | 배포처 라이선스 미표기 |
| LLM 실행 런타임 | Ollama 0.32.13 | MIT |

- **Ultralytics YOLOv8 은 AGPL-3.0** 으로, 네트워크를 통해 서비스를 제공할 경우 소스 공개 의무가 발생함. 본 시스템은 장비 내부에서만 동작하고 외부에 배포하지 않으므로 현 사용 범위에서는 해당 의무가 발생하지 않음. **상용화 시에는 Ultralytics 상용 라이선스 취득이 필요함**
- gemma4 는 Gemma 3 까지의 Gemma Terms of Use 와 달리 **Apache 2.0** 이 적용됨 (모델 카드 원문 확인)
- 음성 합성 음성 모델은 배포처가 음성별 라이선스로 **CC0 1.0** 을 명시하고 있으며, 원 음성 데이터 출처는 KSS(Korean Single Speaker Speech Dataset)임

#### 3) 데이터셋

| 데이터셋 | 용도 | 구축 방식 | 라이선스 |
| --- | --- | --- | --- |
| console_v2 · console_v3 | 콘솔 버튼 5종 검출 | 자체 촬영·자체 라벨링 | MIT |
| tool_v3 원본 2종 | 공구 3종 검출 | 공개 데이터셋 병합·재분할·네거티브 보강 | **CC BY 4.0** |

- 공구 데이터셋은 CC BY 4.0 공개 데이터셋 2종을 원본으로 하며, 라이선스가 요구하는 세 가지 의무를 이행함
  - ① **원저작자 표시** — `karthi-zqreo`, `ruri-binnw`
  - ② **라이선스 명기** — CC BY 4.0 (링크 병기)
  - ③ **변경 사실 표기** — 두 데이터셋을 병합하고 학습·검증·시험 세트를 재분할하였으며 네거티브 표본을 보강함
- 버튼 데이터셋은 팀이 직접 촬영·라벨링한 자체 산출물임

| 구분 | 명칭 · 버전 | 라이선스 |

- **PyQt6 은 GPL-3.0** 으로, 프로그램을 외부에 배포할 경우 전체 소스를 동일 라이선스로 공개하거나 Riverbank 상용 라이선스를 취득해야 함. 본 시스템은 배포 없이 자체 장비에서만 실행하므로 현 사용 범위에서는 해당 의무가 발생하지 않음
- NPU 펌웨어는 제조사 사용권 계약에 따라 제공되는 바이너리로, 재배포 없이 장비에 탑재된 상태로만 사용함
- 글꼴은 SIL Open Font License 에 따라 문서·화면에 사용하며 글꼴 자체를 판매하지 않음

#### 5) 저작권 귀속

- 본 프로젝트에서 자체 작성한 소스코드, 자체 촬영·라벨링한 데이터셋, 회로 설계, 3D 외장 설계, 문서의 저작권은 팀에 귀속됨
- 설계와 기술 판단은 팀이 수행하였으며, 구현과 디버깅 가속에 AI 코딩 도구를 보조적으로 사용함
- 형상관리는 GitHub 저장소 2개(문서·설계 / 런타임 코드)로 이원화하여 변경 이력을 관리함
