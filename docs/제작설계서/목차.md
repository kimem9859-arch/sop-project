## 🔴 낡은 문서 주의 — 결선도 초안의 CH5

`dev/interlock/결선도_초안.md` §3.2 는 **(D3)(IN5) = 12V LED 파일럿(PoC 테스트 부하)** 로 적혀 있다.
**2026-09-05 에 바뀌었다** — 지금은 `D3 → IN5 → 버튼 공통 GND 차단` 이다
(`console_interlock.ino:16, :38` · 37쪽 핀 배정표와 일치).
🔴 **결선·핀 관련은 코드(.ino)를 정본으로 본다.**

## 🔴 값 인용 시 주의 — 0.3 초가 두 개다

| config | 값 | 재는 대상 | 코드 |
| --- | :-: | --- | --- |
| `FSM_DWELL_THRESHOLD_SEC` | 0.3 초 | **경고를 낼 기준** — 구역에 들어온 뒤 흐른 시간 | `fsm.py:210` |
| `FSM_GAP_FILL_SEC` | 0.3 초 | **검출 끊김을 견디는 한계** — 넘으면 이탈로 본다 | `fsm.py:174` |

**값이 같을 뿐 서로 다른 것을 잰다.** 슬라이드에서 「0.3 초」로만 쓰면 심사위원이 같은 값으로 읽는다.
또한 체류는 **누적 카운터가 아니라 「들어온 시각」 하나만 기억**한다(`fsm.py:209`) — 짧게 끊긴 동안에도 시계가 흐른 것으로 친다.
견딤 한계를 넘기면 `_reset_dwell()` 로 **0 부터 다시**다(`fsm.py:194`).

### 🔴 음성 실측을 인용할 때 — 「재생 302ms」를 쓰지 않는다

통합문서 `[CURRENT]`·§10.61-(2) 의 **「답변 재생 명령 302~304ms」는 응답 지연이 아니다.**
`계측.jsonl` 원값은 1258·83·**4**·77·86 ms 이고, **10 회 전부 `"재생성공": false`**(로그 「🔴 재생이 확인되지 않았다」 10 회)다.

**302ms 는 「기다리기를 포기한 시각」의 평균**이다.
