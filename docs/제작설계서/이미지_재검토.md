## ✅ 1. 표기가 어긋난다 — **2026-09-07 해결**

**「전기 신호 차단」이 6곳에 남아 있다.** 29·28·36쪽은 **「버튼 입력 차단」**으로 고쳤는데
표 슬라이드는 그대로다. 릴레이가 끊는 것은 장비 전원이 아니라 **버튼 4개의 공통 GND** 다.

| 위치 | 지금 문구 | 고칠 문구 |
| --- | --- | --- |
| `make_tables.py:24` (3쪽 AS-IS/TO-BE) | 인터록으로 전기 신호 차단 | 인터록으로 버튼 입력 차단 |
| `make_tables.py:59` (6쪽 H/W HR-06) | 릴레이를 통한 장비 전기 신호 차단 | 릴레이로 버튼 입력 차단 |
| `make_tables.py:96` (9쪽 UC-05) | 장비로 가는 전기 신호를 차단한다 | 버튼 입력을 끊는다 |
| `make_tables.py:110` (10쪽 목적) | 오조작이 전기 신호로 설비에 전달되지 않게 | 오조작이 장비에 전달되지 않게 |
| `make_tables.py:113` (10쪽 후행 조건) | 장비로 가는 전기 신호가 끊기고 | 버튼 입력이 끊기고 |
| `make_tables.py:160` (14쪽 하드웨어 구성) | 전기 신호를 물리적으로 차단하는 인터록 | 버튼 입력을 물리적으로 끊는 인터록 |

**「인터락」으로 통일했다** (2026-09-07 사용자 확정 — 개발보고서에 맞춤). 생성 스크립트 26곳 교체.
표기 규칙은 `작업규칙.md` §6-5 에 적었다.
