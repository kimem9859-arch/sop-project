# 시연 안내 모드 — 구현 계획서

> **실행 방식:** `superpowers:executing-plans` — Claude 가 이 세션에서 직접(인라인) 한다(`작업갈래` 스킬 · 병렬 없음 · 워크트리 없음). 스텝은 체크박스(`- [ ]`)로 따라간다.

**목표:** 설정 화면 스위치 「시연 안내」를 켜면, 참여자가 「작업 시작」을 누른 순간부터 안경 스피커로 미리 녹음한 안내가 나와 16장면(정상 · 스침 · 틀린 공구 · 머무름 · 순서 위반 · 음성비서)을 혼자 해 볼 수 있다.

**구조:** 새 프로세스 `demo_guide.py` 가 GUI 상태(`state.json`) · 손 · 공구(`hand.json` 새) · 음성 사건(`voice.json` 새)을 **읽기만** 하고, 안내 소리는 기존 길(`req.json` → 음성비서 `CueWatcher` → 안경)로 요청한다. GUI · 음성비서는 `state.json` 의 `안내모드` 칸이 참일 때만 새 파일을 쓰고 알림을 색 이름판으로 낸다. 소리는 파이 Supertonic F2(임시)로 먼저 만들고, 데스크톱 Gemini 3.8 Flash TTS 여성으로 같은 키를 덮어쓴다.

**기술:** Python 3.13 · PyQt6(GUI 기존) · Supertonic 2(`~/env/tts/.venv`) · sherpa 받아쓰기(음성비서와 같은 `build_stt`) · Gemini Interactions REST(데스크톱 · 표준 라이브러리만).

**설계서:** [`docs/superpowers/specs/2026-10-18-시연안내모드-design.md`](../specs/2026-10-18-시연안내모드-design.md) — 문구 · 문장별 시작 조건(§4.3)의 정본. 이 계획서와 함께 읽는다.

## 지킬 것(모든 태스크)

- 문구는 설계서 §4 · §4.3 그대로 — 고치지 않는다(아래 Task 1 의 문장 표가 그 글자를 옮긴 것).
- 소리 키는 모두 `cue_` 로 시작한다(`CueWatcher` 가 다른 키를 버린다) · 알림 색 이름판 키 = 원래 키 + `_c`.
- 소리 하나 = `voice_tts.fits` 통과(펌웨어 한도) · 모노 16비트.
- **`안내모드` 거짓이면 판정 · 알림 · 화면 · 음성비서가 지금과 같다** — 달라지는 것은 `state.json` 의 `안내모드` 칸과 말없이 기다리는 `demo_guide.py` 프로세스뿐.
- 판정 규칙 · 레시피 · 음성비서 답 · 펌웨어는 손대지 않는다.
- 시계 = `measure_log.now_ms()`(단조 ms) — GUI · 음성비서 · 안내가 같은 시계.
- 커밋 — 코드 = `Rpi5` 저장소 · 문서 = `sop-project` · 경로 지정 `git add` · 서명 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 런타임 코드 동결 = **10/20** — 그 뒤에는 소리 파일 교체(Task 8)와 문서만.
