# 판정 기준 안 B 구현 · 다시 재기 계획

> 상태: 실행 중(2026-10-12 · 학교) · 실행 방식 = 에이전트 병렬(Task 1 · 2 · 3 — 파일이 겹치지 않음) + 통합 · 검증은 Claude(사용자 「에이전트를 활용하여 시간을 단축」)

**Goal:** 판정기에 「틀린 버튼 안쪽에서 느린 손끝 → 즉시 경고」(안 B)를 넣고, 오늘 학교에서 다시 재기(①정상 + ②위반 A·B)로 §4.1 을 판정한다.

**Spec:** `docs/superpowers/specs/2026-10-12-판정기준-안B-design.md`(상위 `2026-10-12-처리흐름-판정기준-design.md` §5)

## Global Constraints

- 코드 = `Rpi5/`(별도 저장소) · 경로 지정 커밋 · `git add -A` 금지 · 커밋은 Claude 가 통합 뒤에(에이전트는 커밋하지 않는다).
- 문턱 = `config.FSM_SLOW_ENTRY_PX_S_VGA`(기본 437.5 = XGA 700 · 환경변수 `SOP_SLOW_ENTRY_PX_S_VGA` · 0 = 끔 = 지금 규칙) · 직전 손끝 = `FSM_SPEED_BACK_SEC = 0.25` · `FSM_SPEED_BACK_N = 3`.
- 체류 0.3 · 갭메우기 0.3 · 링 25(VGA) 그대로(`recipe.json` 과 config 일치 시험 유지).
- 사용자에게 보이는 글 · 주석은 한국어.

## 인터페이스(태스크 사이 계약)

- `fsm.SafetyFSM.__init__(…, slow_px_s=None)` — None 이면 config 값. `update_vision(self, roi, now, level=ZONE_INSIDE, tip=None)` — `tip` = (x, y) **VGA 기준 px** 또는 None. 속성 `last_warn_reason` ∈ {"slow", "dwell", None}(경고로 갈 때 세움 · `reset`·경고 해제 때 None).
- `camera_thread.roi_signal = pyqtSignal(str, int, float, float, float)` — (roi, level, t, tip_x_vga, tip_y_vga) · 손끝 없음 = NaN · VGA 기준 = 화면 px ÷ `frame_orient.px_scale(w, h)`.
- `safety_console._on_roi(self, roi, level, t, tx=nan, ty=nan)` — 손 판정 끔이거나 NaN 이면 tip=None · 경고 state 사건 data 에 `"reason": fsm.last_warn_reason`.
- `measure_session.SETTINGS` 에 `FSM_SLOW_ENTRY_PX_S_VGA` 추가.

## 관문

- **① 중단 규칙** — (a) 전체 자가 테스트 fail 이 하나라도 있으면 다시 재기를 하지 않는다. (b) 재생 대조에서 장면별 경고 수가 모의와 2 넘게 다르면 멈추고 원인부터. (c) 다시 재기 ①정상에서 헛경고가 난 판이 3판 이상이면 그 세션 뒤 멈추고 사용자와 정한다(문턱 0 으로 되돌릴지).
- **② 🔒 홀드아웃** — 다시 재기 기록은 **판정 전용**이다. 그 기록으로 문턱 · 체류를 다시 고르지 않는다(고르면 그 세션은 판정에서 뺀다 · 측정 설계 §4.2 사전 고정).
- **③ 검증 관문** — G1 자가 테스트 0 fail · G2 재생 대조(새 판정기 ↔ 모의 SpeedGate 700 · 0.3) 장면별 경고 일치 · G3 최종 리뷰 Critical · Important 고침 · G4 다시 재기 세기 완료 → 공동 확인.

## Review Focus

1. 갭메우기로 채운 장이 속도 경고를 내지 않는가(관측된 장만).
2. 손 판정 끔(공구) · 재연결(`forget_observation`) 뒤 직전 손끝이 남아 거짓 속도를 만들지 않는가.
3. 슬롯 시그니처와 시그널 인자 수가 맞는가(어긋나면 시연이 기동 직후 죽는다).
4. 경고 이유가 체류 경고에도 남는가 · 세기의 정밀도 · 스침이 `_dwell_roi` 를 그대로 읽는가.
5. 실행기 처리 설정 1 · 2 · 3 이 런처 기본(2a 켬)에 끌려가지 않는가.
