## Global Constraints

- 🔴 **FSM·인터락·GPIO 배선을 바꾸지 않는다.** 이번 수정은 전부 표시 계층이다.
- 🔴 **안전 UI 3종을 건드리지 않는다** — BLOCK 해제 거부(EMO 미복귀) · 인터락 폴트 경고창 · 종료 확인창.

- **테스트는 pytest 가 아니다** — `selftest/*.py` 는 `if __name__ == "__main__"` 단독 스크립트다.

## 원인이 계획과 달랐던 것 2건

1. **메뉴 회색 박스 (Task 2)** — 계획은 「스타일시트 상속」을 의심하고 진단 단계를 뒀는데, 실제 원인은 **`apply_theme` 의 `findChildren(QFrame)` 이 `QLabel` 까지 잡은 것**이었다(`QLabel` 은 `QFrame` 의 하위 클래스). 구분선에 칠하려던 `panel_border` 가 제목·「＋」를 덮어썼다. **진단 단계를 넣지 않았다면 엉뚱한 곳을 고쳤을 것이다.**
2. **알림 아이콘이 아예 안 그려짐 (Task 6)** — 이모지로 바꾸자 폭(`advance=17`)은 잡히는데 화면에 없었다. 굵기도 색도 아니고 **시트의 `padding: 10px 12px` 가 자식 라벨에 상속**된 탓이었다. 아이콘은 `setFixedWidth(26)` 이라 좌우 24px 에 눌려 글리프 자리가 남지 않았다. → **크기가 고정된 자식 라벨에는 `padding: 0` 을 명시한다.** `ConnBar` 에도 미리 넣었다.

## 계획에 없던 발견 3건

3. **설정 패널도 「첫 열기 납작」 함정을 갖고 있었다 (Task 4 중 발견)** — `_toggle_settings` 는 `_toggle_sheet` 를 거치지 않아 Task 3 의 재배치가 안 걸렸다. 「작업 중에는 변경할 수 없습니다」 문구가 붙자 **공구 라디오 3개가 눌려 겹쳤다.** 설계 §5 가 예고한 "같은 함정을 가진 곳"이 실제로 나온 것. 회귀 테스트에 「작업 중 설정 패널」 케이스를 추가했다.
4. **✕ 글리프는 같은 pt 의 한글보다 훨씬 작게 그려진다 (Task 5)** — `body`(12pt)로는 8px 남짓이라 누를 자리가 안 보였다. `banner`(16pt)·32px 로.
5. **로그의 ✕ 를 `log_browser` 의 자식으로 두면 아예 안 보인다 (Task 5)** — `QAbstractScrollArea` 는 자식을 **뷰포트 아래**에 둔다(`raise_()` 로도 안 됨). `central` 의 자식으로 옮기고 `_relayout` 이 로그창 우상단에 앉힌다. 스크롤바와 겹치지 않게 58px 안쪽.
