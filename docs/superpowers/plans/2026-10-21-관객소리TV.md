# 관객 소리(TV) · TV 소리 스위치 · 안내 중 호출어 구간 · 메뉴 「프로그램 종료」 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans(인라인 — 이 프로젝트 기본 · `작업갈래` 스킬). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 안경에서 나는 모든 소리를 TV 스피커로도 내고(설정으로 켬/끔), 시연 안내 중에는 15번 장면에서만 호출어를 받으며, 메뉴에서 시연 프로그램을 끌 수 있게 한다.

**Architecture:** 안경 소리의 유일한 출구 `voice_assistant.Speaker` 에 거울(`audience_speaker.AudienceSpeaker`)을 붙여, 안경이 「`[재생]`」을 알린 순간 계속 열어 둔 `pw-cat` 통로로 같은 소리를 흘린다. 출력 장치는 시연을 켤 때마다 `audience_audio.py --apply` 가 TV 로 맞춘다. 호출어 구간은 장면을 아는 안내 프로그램이 `guide_gate.json` 으로 내고 음성비서가 「시연 안내」 켬일 때만 따른다.

**Tech Stack:** Python 3.13(시스템) · 음성비서는 `~/env/tts/.venv` · numpy · PyQt6 · PipeWire 1.4.2(`pw-cat` · `wpctl` · `pw-dump`) · WirePlumber 0.5.8 · 자가 테스트 = `Demo/selftest/test_*.py`(`check()` 방식 · `run_all.py`)

**Spec:** `docs/superpowers/specs/2026-10-21-관객소리TV-design.md`(이하 「설계」) — 코드 = `Rpi5`(별도 저장소 · main 경로 지정 커밋) · 문서 = `sop-project`

## Global Constraints

- 🔴 **안경 쪽 동작 불변** — 거울이 있든 없든 · 실패하든 `Speaker.send/play/chime/close_chime/stop` 의 전송 바이트 · 응답 판정 · 반환값이 같다(설계 4장 8). 유일한 예외 = 「`[재생 완료]`」 뒤 TV 꼬리 기다림(상한 `config.AUDIENCE_TAIL_MAX_SEC = 0.5` · 설계 4장 12).
- 시작 시점: 프레임은 「`[재생]`」 줄을 받은 순간 · 띠링(B)/닫힘음(C)은 전송 성공 직후(설계 4장 2).
- 크기 기준 최고 진폭 `config.AUDIENCE_PEAK = 29162` · 띠링도 같은 최고 진폭(설계 4장 4).
- 띠링 모양 = `arduino/glass_voice/glass_voice.ino` 의 `CHIME_LO` · `CHIME_HI` · `FADE_MS` 를 읽는다 · 구간 30 · 120 · 40 · 180 · 60ms(열림 = LO→HI · 닫힘 = HI→LO) · 못 읽으면 띠링만 뺀다(설계 4장 5).
- 통로 = `pw-cat --playback --raw --format s16 --rate 48000 --channels 1 --latency 40ms -`(기본 출력) 하나를 계속 연다 · 쉴 때는 무음을 흘린다 · 표준 입력 관 크기를 4096 바이트로 줄여(F_SETPIPE_SZ) 쌓이는 지연을 막는다(만드는 사람 판단 · 6장 실측으로 확인).
- 켜고 끄기: `config.AUDIENCE_SPEAKER = True` · 환경 `SOP_AUDIENCE_SPEAKER=0` 이면 통로 자체를 만들지 않는다 · 설정 스위치 = 상태 파일 `관객소리` 칸(없으면 config 값) · 기본 켬 · 저장 안 함(설계 9장).
- 호출어 구간: 「시연 안내」 켬일 때만 · 15-1 묶음이 끝난 때부터 `_voice_ok` 또는 `voice_fails >= 2` 까지 · 파일 없음/유령이면 막지 않음 · 측정 진행 도우미가 돌면(안내가 쉼) 막지 않음 · 막는 것은 호출어로 창 여는 것뿐(설계 10장).
- 메뉴 「프로그램 종료」 = 맨 아래 · `warn` · 아이콘 `power` · 확인 상자(기본 = 취소) · 「종료」 = `[시스템] 메뉴 — 프로그램 종료` 로그 → `self.close()`(설계 8장).

## Review Focus

1. **안경 연결이 소리 도중 끊김**(`Speaker.reset` · 시간 초과 · FAIL) — TV 도 그 자리에서 멈추고, 다음 소리는 정상으로 난다 → Task 3 `test_mirror_stops_on_channel_reset`.
2. **`pw-cat` 이 없거나 죽음 · PipeWire 가 꺼짐** — 음성비서는 그대로(안경 소리 · 답 · 알림), TV 만 빠지고 로그는 한 줄씩만 → Task 2 `test_player_missing_is_silent` · `test_player_dies_restarts_once`.
3. **알림이 안내를 끊음(S)** — TV 안내도 바로 멈추고 이어서 알림이 TV 에서도 난다 → Task 3 `test_stop_cuts_mirror_then_next_plays`.
4. **스위치를 끄는 순간 소리가 나는 중** — TV 가 바로 멈춘다 · 안경은 계속 → Task 2 `test_disable_mid_sound_goes_silent`.
5. **안내 프로그램이 안 돎 · 낡은 `guide_gate.json` 이 남음**(안내 켬 상태) — 호출어를 막지 않는다 → Task 6 `test_gate_missing_or_ghost_allows`.
