머리 docstring 에 **§4.4 의 원리(손이 증인)** 를 반드시 적는다 — 이 파일만 읽고도 왜 이렇게 세는지 알아야 한다.

핵심 알고리즘만:

```python
def update(self, dets, fingertip):
    seen = {d[0] for d in dets}
    hand = fingertip is not None

    if self._phase == "search":
        held = self._held_tool(dets, fingertip) if hand else None
        if held == self._want:
            self._phase = "grasped"; self._miss = 0
            return None
        return held            # 오답이면 그 키, 아무것도 아니면 None

    if self._phase == "grasped":
        if not hand:
            return None                      # 🔑 보류 — 초기화가 아니다
        if self._want in seen:
            self._miss = 0; return None      # 다시 보이면 0
        self._miss += 1
        if self._miss >= self._need:
            self._phase = "placed"
            return self._want
        return None

    return self._want          # placed — 유지
```

`_held_tool()` = 손끝이 들어 있는 박스의 클래스명(없으면 `None`). 여러 박스가 겹치면 **면적이 작은 쪽**을 택한다(큰 박스가 작은 박스를 덮는 경우 대비).
