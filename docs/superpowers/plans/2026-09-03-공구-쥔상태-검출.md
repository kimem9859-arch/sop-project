# 공구 「쥔 상태」 검출 (`tool_v4`) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:executing-plans` 로 태스크 단위 실행. 체크박스(`- [ ]`)로 추적한다.
> 🔴 **`subagent-driven-development` 를 쓰지 않는다** — 이 계획의 병렬성은 「사용자 촬영·라벨링 ↔ Claude 데이터셋 작업」이지 에이전트 병렬이 아니다(CC작업문서 §2.2).

**Goal:** 모델이 「손에 쥔 공구」를 별도 클래스로 검출하게 만들고, 그 클래스를 서브작업 완료의 주 근거로 삼아 **쥐어도 안 넘어가는 문제**를 없앤다.

**Architecture:** 외부 데이터셋(`x-tool-in-hand-videox`)의 in-hand 클래스를 기존 `ds_tool_v3` 에 병합해 **6클래스**(`driver`·`wrench`·`pliers` + 각 `-in-hand`)로 재학습한다. 판정은 `tool_state.ToolState` 에서 **메인(in-hand 박스 + 손 검출) OR 보조(검지끝 ∩ 박스)** 2조건으로 바꾼다. `camera_thread`·`sub_task`·`recipe.json`·FSM 은 건드리지 않는다.

**Tech Stack:** Python 3.13(파이 런타임) / `~/env/rfenv`(ultralytics 추론·데이터셋 빌드) / Colab T4(학습) / Roboflow(홀드아웃 라벨링) / YOLOv8n

**Spec:** `docs/superpowers/specs/2026-09-03-공구-쥔상태-검출-design.md`

## Global Constraints

- 🔴 **부재를 근거로 쓰지 않는다** — 판정 근거는 언제나 **검출된 박스**다(§10.44-(3)(8)).
- 🔴 **측정 수치는 통합문서 §10 이 정본** — 이 계획서·spec 에 확정 수치를 쓰지 않는다. 결과는 §10 새 절 + `[CURRENT]` 표에 기록한다.
- 🔴 **홀드아웃은 전량 수동 라벨**(모델 프리라벨 금지) · **Roboflow 자동 분할 금지**(업로드 시 `test` 명시).
- 🔴 **합격선은 홀드아웃 개봉 전에 확정**한다 — 아래 「관문 3」의 수치가 그것이며 결과를 보고 바꾸지 않는다.
- 🔴 `NEW_NAMES` 순서는 **학습·추론·`recipe.json` 이 공유하는 계약**이다. v3 스키마를 바꾸지 말고 v4 를 **추가**한다.
- 커밋: 코드 → `Rpi5` / 문서·데이터셋 스크립트 → `sop-project`. 서명 `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`. push 는 사용자 요청 시.

```python

BOX = (100, 100, 200, 160)          # 요구 공구 박스
IN_HAND = ("wrench-in-hand", 0.8, *BOX)
PLAIN   = ("wrench", 0.8, *BOX)

def test_main_in_hand_with_hand_completes():
    st = ToolState(WANT)
    assert st.update([IN_HAND], (300, 300)) == WANT   # 손끝은 박스 밖이어도 된다
    assert st.phase == "grasped"

def test_main_needs_hand_visible():

def test_backup_fingertip_in_box_still_works():
    st = ToolState(WANT)
    assert st.update([PLAIN], (150, 130)) == WANT     # 종전 규칙 그대로

def test_wrong_tool_in_hand_warns():
    st = ToolState(WANT)
    other = ("driver-in-hand", 0.8, *BOX)
    assert st.update([other], (300, 300)) == "driver"  # 접미어를 벗겨 돌려준다
    assert st.phase == "search"

def test_want_wins_over_wrong_when_both_seen():
    st = ToolState(WANT)
    other = ("driver-in-hand", 0.9, 300, 300, 340, 340)
    assert st.update([other, IN_HAND], (150, 130)) == WANT
```
