> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 통합문서 §12 의 갈래 저널 5,141줄(측정 절 63개)을 `docs/성능검증-저널.md` 로 **한 글자도 바꾸지 않고** 옮기고, 세 문서(통합문서·저널·작업로그)의 **역할을 문서에 명시**하며, 그 짝맞춤을 `work-close` 의 **기계 검사 관문**으로 지킨다.

**Architecture:** 순수 파일 절단이다. 절단면은 `## 📂 갈래 ① 초기 검증·KPI` 부터 `## Ⅲ. 구현 수단` 직전까지. §12 **머리**(색인·`[CURRENT]`·🔓 미결·🧱 규약)는 통합문서에 남는다 — 「수치는 여기서 먼저 찾을 것」의 자리이기 때문이다. 절 번호(`§12.N`)는 파일이 달라져도 그대로라 **참조 치환이 0곳**이다.

**Tech Stack:** Markdown · bash(`sed`·`grep`·`sha256sum`) · python3(자가 점검 스크립트)

**Spec:** `docs/superpowers/specs/2026-09-19-측정저널-분리-design.md`

## Global Constraints

- 🔴 **저널 본문은 한 글자도 바꾸지 않는다.** 측정 절 63개의 문장·수치·마커·빈 줄까지 전부 그대로. **검증은 눈이 아니라 `diff`/`sha256sum`** 으로 한다.

- `git add` 는 **경로를 지정해서** 한다(`-A`·`.` 금지 — 권한 설정이 막는다).
- 작업 저장소 = `sop-project`. `Rpi5` 는 건드리지 않는다.
