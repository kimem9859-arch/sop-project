**Goal:** 라벨링을 모르는 검토자 3~4명이 혼자 찾아볼 수 있는 안내서를 원본 `labeling_guide.md` 한 곳에 쓰고, 그 원본에서 만든 아티팩트 페이지를 올리고, 묶음마다 들어가는 `안내.txt` 를 그 페이지와 맞춘다.

**Architecture:** 원본은 Rpi5 `Demo/docs/labeling_guide.md` 하나다. 생성 스크립트 `Demo/docs/build_guide_page.py` 가 원본을 `markdown`(시스템 python3 · 3.7)으로 바꿔 **정성 들여 만든 페이지 틀**(목차 · 두 테마 색 토큰 · 그림 확대 · 표 가로 스크롤)에 넣고, 그림은 data URI 로 품어 파일 하나로 낸다. 그 파일을 Artifact 로 올리고(주소 고정), 묶음 안내문이 그 주소를 가리킨다.

**Tech Stack:** 시스템 `python3`(3.13 · `markdown` 3.7) · Artifact 도구(claude.ai 웹 페이지) · X-AnyLabeling v4.0.6(검토자 · Windows)

**Spec:** `docs/superpowers/specs/2026-09-29-라벨링안내서-design.md`

## Global Constraints

- 원본 = Rpi5 `Demo/docs/labeling_guide.md` 한 곳. 페이지·안내문은 원본을 따른다. 규칙 문구를 페이지 틀이나 안내문에 따로 적지 않는다.
- 🔴 **이해하기 쉽게** — 한 문장에 한 가지 · 새 낱말은 처음 나올 때 풀어 쓴다 · 절차는 번호 단계 · 판단은 표와 그림.
- X-AnyLabeling 화면 그림은 **한국어 화면 캡처만** 쓴다(사용자 「이전에 보낸 영어 바탕 이미지는 사용하지 말아줘」). 다운로드 웹페이지 캡처(1~3)는 쓴다. 메뉴 이름은 한국어 화면 그대로(파일 · 편집 · 보기 · 테마 · 언어 · 업로드 · 내보내기 · 도구 · 훈련 · 도움말 / 이미지 설명 · 플래그 · 레이블 · 도형 · 파일 검색).
- 사각형 = 기본 **R 키** · 숫자 단축키는 넣지 않는다 · **「박스 차례로 확대」(Loop Thru Labels) = F** — 먼저 AI 분류의 「Finish Object」 F 를 × 로 비운다(캡처 15) · 설정 창 아래 「Ctrl+0 … Zoom To Original」 빨간 문구는 무시해도 저장된다(캡처 14).
- 「검토함」 칸은 설치 직후 보이지 않는다 → 설정 파일 `C:\Users\<이름>\.xanylabelingrc` 의 `flags: null` 을 `flags:` + `  - 검토함` 으로(프로그램을 끄고 고친 뒤 다시 켠다).
- 검토자 기록은 **검토자 A·B·C·D**(이름 없음) · 주고받기 = 구글 공유 드라이브 · 올리는 것 = 묶음 `images` 폴더의 `.json` 전부 · 사진마다 「검토함」 체크 · 첫 10장은 먼저 올려 사용자 확인.
- 이름 창 목록에는 **그 묶음에 이미 있는 이름만** 나온다(캡처 17) → 공구·`exclude` 는 위 칸에 정확히 입력(철자·대소문자).
- B4 = 검정 버튼 윗면 전체에 파란 테이프를 모양대로 잘라 붙임(사용자).
- 🔴 기계 박스의 알려진 끝선 치우침(아래 끝선이 조금 짧음 · B4 위 끝선이 조금 넘침)은 **고치지 않는다** — 새로 그리는 박스만 규칙 ①.
- 아티팩트 페이지 규칙 — `<title>` 은 이름(「라벨링 검토 안내서」) · 두 테마 색 토큰 · 폰 폭(약 400px)에서 가로 스크롤 없음 · 16MB 이하 · `<html>`/`<body>` 태그를 쓰지 않는다(올릴 때 감싼다).

**② 🔒 홀드아웃 — 바뀌면 안 되는 것**

**③ 검증 관문**
- 자가 시험 — 기준선 → 태스크마다 → 최종(기준선 + 1 파일 `test_guide_page`).

- **사용자 확인** — 올린 페이지를 사용자가 읽고 고칠 곳을 알려 준다(공동 확인) → work-close.

- **원본이 없는 그림을 가리킨다** — 조용히 깨진 그림이 되면 안 된다 → 생성기가 `FileNotFoundError` 로 멈춘다(Task 3 시험 [1]).
- **한국어 제목의 목차 링크** — 한글 제목을 그대로 주소 조각으로 쓰면 아티팩트 링크에서 깨진다(평범한 `#영문` 만 통한다) → 절마다 `s1`, `s2` … 로 붙이고 목차가 그 id 를 가리킨다(Task 3 시험 [2]).
