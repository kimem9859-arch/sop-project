## 4. 되돌리기

| 무엇 | 명령 |
|---|---|
| 처리 2단계 | 실행기 처리 설정 1(엔터) |
| 오늘 코드 전체 | Claude 가 `git -C ~/sop-project/Rpi5 checkout 학교1012-전 -- Demo arduino`(필요한 파일만) |
| 안경 펌웨어(옵션 없이 다시) | `bash arduino/flash_esp32.sh main` |
| 안경 펌웨어 되쓰기(바이트) | `P=$(ls /dev/serial/by-id/*68:EE:8F:4F:5D:38*)` → `esptool --port "$P" --no-stub write-flash 0 <굽기 직전 백업.bin>` → `esptool --port "$P" --no-stub verify-flash 0 <같은 .bin>` — 백업 경로는 굽기 출력의 「되돌리기:」 줄 · 🔴 **시리얼번호 경로만** 쓴다(`ttyACM` 번호 금지) |
| `.camera_ip` | `~/lab/esp32-link/camera_ip.bak-<시각>` 가운데 오늘 것을 되돌려 놓는다 |
