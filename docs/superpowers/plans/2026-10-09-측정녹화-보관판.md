# 측정 중 보관용 녹화 Implementation Plan

> **For agentic workers:** 실행 = `superpowers:executing-plans` **인라인**(프로젝트 기본 · 작업갈래 스킬). 사용자 「진행」(2026-10-09).

**Goal:** 측정 중 세션마다 추가 1판을 1인칭 원본(오버레이 없음) 영상 + 프레임 대응표로 보관하고, 공구 상자 좌표를 기록하며, 세기가 녹화 구간을 값에서 빼고 「녹화 비교」 표를 낸다.

**Architecture:** 녹화기(`raw_recorder.py` · Qt 없음)는 카메라 스레드에서 넣기만 하고 쓰기 스레드가 ffmpeg 파이프로 인코딩 · 대응표 CSV · 세기는 불러올 때 녹화 구간을 한 곳에서 거른다.

**Tech Stack:** Python 3 · PyQt6 · ffmpeg(libx264 · 시연영상 촬영과 같은 `_X264`) · 자가 테스트

**Spec:** `docs/superpowers/specs/2026-10-09-측정녹화-보관판-design.md`(R1~R8)

## Global Constraints

- 카메라 스레드에서 인코딩·파일 쓰기를 하지 않는다 — 넣기만(넘치면 버리고 버린 번호를 남긴다).
- 측정 시각 = 같은 단조 시계 ms(`measure_log.now_ms`) · 프레임 번호 = 측정 프레임 번호(`_m_row["frame"]`), 측정 끔이면 처리 순번.
- 손 뼈대는 남기지 않는다 · 3인칭 없음.
- 커밋 = Rpi5 경로 지정 · `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>` · push 는 work-close.
- 🛑 녹화 중 처리 FPS 가 절반 아래면 멈춘다 · 디스크 여유 0.5GB 아래면 녹화 시작 거부.
