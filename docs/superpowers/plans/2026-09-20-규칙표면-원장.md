## 읽는 법

**판정 6종 + 1**

| 판정 | 뜻 |
| --- | --- |
| 유지 | 그 자리에 그대로 |
| 이동 | 내용 그대로, 다른 자리로 |
| 수정 | 사실이 낡았거나 불완전해 고친다 |
| 병합 | 같은 말이 둘 이상 → 하나로 |
| 승격 | 원래 없던 것을 새로 만든다 |
| 제거 | 본문에서 뺀다 — 🔴 **반드시 행선지가 있다. 그냥 지우지 않는다**(R2) |
| **사례** | Claude 가 정하지 않는다 — **사용자 판단 대기** |

**판정 잣대 5단 (2026-09-21 확정 — A·B 공통)**

🔴 **잣대를 도중에 추가하지 않는다.** 새 잣대가 필요해 보이면 **작업을 멈추고 사용자에게 올린다.** 계획이 두 번 고쳐진 원인이 「진행 중 잣대 추가」였다.

| 단 | 필터 | 묻는 것 | 결과값 |
| --- | --- | --- | --- |
| 1 | 원자화 | 한 줄이 한 규칙인가 | 원장 행 |
| 2 | 축 4개 | 머신 / 로드 시점 / 성격 / 강제 가능 | `[전 머신/매 세션/규칙/안내만]` |
| 3 | **면 배정** | 어느 **로드 면**으로 가나 | `CLAUDE.md` / `rules` / `skill` / `memory` / `문서에 남김` |
| 4 | **면별 공식 기준** | 그 면의 기준에 맞나 | 아래 |
| 5 | 안전판 | 실제 사고에서 나왔나 | `사례` |

🔴 **면 배정(3단)이 검토(4단)보다 먼저다** — 어느 면으로 가느냐가 **어떤 기준으로 볼지를 정한다.**

**4단 — 면별 공식 기준 (공식 근거가 있는 것만)**

| 면 | 적용 기준 | 공식 근거 |
| --- | --- | --- |
| `CLAUDE.md`(양 저장소) | **낡음** · **충돌** · **모호** · 200줄 | memory.md §Write effective instructions — *"concrete enough to verify"* · *"remove outdated or conflicting instructions"* · *"target under 200 lines"* |
| `.claude/rules/` | **한 파일 한 주제** · 상시 필요 없으면 스킬로 · 낡음 · 충돌 | §Organize rules — *"Each file should cover one topic"* · Consistency 가 `.claude/rules/` 를 명시 포함 |
| `.claude/skills/` | 500줄 · **본문 간결 — 로드되면 턴마다 비용** · 상세는 보조 파일 | skills.md — *"every line is a recurring token cost"* |
| auto memory | **코드 파생 금지** · **`CLAUDE.md` 중복 금지** · 색인 200줄·25KB | §Auto memory — *"skips anything it can derive… anything your CLAUDE.md files already say"* |
| 일반 `.md` 에 남는 것 | **기준 없음** | 🔴 공식이 다루지 않는 면이다. **그래서 규칙을 여기 두지 않는다** — 남는 것은 규칙이 아닌 정보뿐 |

🔴 **「모호」는 `CLAUDE.md` 계열에만 적용한다** — `Specificity` 는 `## CLAUDE.md files` 아래 절이라 rules·skills·memory 에 걸 공식 근거가 없다.

**3단 — 면 배정 규칙 (공식 그대로)**

| 이런 규칙이면 | 이 면으로 |
| --- | --- |
| 매 세션 알아야 하는 사실·관례·「항상 X 한다」 | `CLAUDE.md` |
| 특정 파일·폴더를 만질 때만 필요 | `.claude/rules/` + `paths:` |
| 다단계 절차 · 가끔 필요한 참조 자료 | `.claude/skills/` |
| 절대 일어나면 안 되는 것 | `settings.json` deny · 훅 — 🔴 **C 단계**. 여기서는 후보 목록만 |
| 머신 로컬 사실이고 코드·`CLAUDE.md` 가 말하지 않는 것 | auto memory |
| 규칙이 아닌 정보(폴더 지도·실행법·측정 사실) | 일반 `.md` 제자리 |

**「연결」의 정의** — 🔴 **규칙이 다루는 문서를 열면 그 규칙이 자동으로 붙어야 한다.** 포인터로 잇지 않는다. `paths:` 가 기계로 보장한다(*"Path-scoped rules trigger when Claude reads files matching the pattern"*). 검사 = ①글롭이 대상 문서를 실제로 매치하는가 ②원본에 규칙이 남아 있지 않은가.

**행 수 정정 (2026-09-21)** — 판정 행은 **318**이다(A 149 = CM 57·RP 63·MEM 29 / B 169 = T 9·R 19·RM 45·CC1 32·CC2 34·CC3 30). 종전 「338」은 보조표에서 같은 ID 를 인용한 20행을 잘못 합산한 값이다.

**열**

- `ID` — `<약칭>-<번호>`. `CC1`·`CC2`·`CC3` = CC작업문서 §1·§2·§3 · `R` = 통합문서 R1~R12 · `RM` = README 역할·경계표 · `T` = 도구 규칙
- `도구` — 이 설계 자체가 판단 도구로 쓴 규칙(spec §5.1). 🔴 **도구 행은 `프로젝트판정` 을 비운다** — 프로젝트 규칙끼리 서로 판정하면 그것이 순환이다(spec §5.2)
- `행선지` — 새 자리, 또는 `변경이력.md`, 또는 `제자리`, 또는 `보류`
