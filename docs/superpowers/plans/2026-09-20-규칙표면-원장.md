## 읽는 법

**판정 6종 + 1**

| 판정 | 뜻 |
| --- | --- |
| 유지 | 그 자리에 그대로 |
| 이동 | 내용 그대로, 다른 자리로 |
| 수정 | 사실이 낡았거나 불완전해 고친다 |
| 병합 | 같은 말이 둘 이상 → 하나로 |
| 승격 | 원래 없던 것을 새로 만든다 |
| 제거 | 본문에서 뺀다 — 🔴 **반드시 행선지가 있다. 그냥 지우지 않는다**(R2) |
| **사례** | Claude 가 정하지 않는다 — **사용자 판단 대기** |

**열**

- `ID` — `<약칭>-<번호>`. `CC1`·`CC2`·`CC3` = CC작업문서 §1·§2·§3 · `R` = 통합문서 R1~R12 · `RM` = README 역할·경계표 · `T` = 도구 규칙
- `도구` — 이 설계 자체가 판단 도구로 쓴 규칙(spec §5.1). 🔴 **도구 행은 `프로젝트판정` 을 비운다** — 프로젝트 규칙끼리 서로 판정하면 그것이 순환이다(spec §5.2)
- `행선지` — 새 자리, 또는 `변경이력.md`, 또는 `제자리`, 또는 `보류`

| ID | 판정 | 사고 출신? | 조치 |
| --- | --- | --- | --- |
| T-04 | 수정 | ❌ 아님 — 문서 정리 과정에서 만들어진 지도이고, 누락은 사고가 아니라 미완성 | 안전판 불필요. **수정 유지** |
