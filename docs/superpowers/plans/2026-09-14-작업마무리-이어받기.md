**Goal:** 공동 확인·중단 합의 뒤 정본 기록 → 세션 마무리 → push 가 끊기지 않게 하고, 떠난 세션의 마무리 안 된 작업을 다음 세션이 경과 시간·멈춘 지점과 함께 찾게 한다.

**Tech Stack:** Python 3 표준 라이브러리 · bash · git · Claude Code 스킬/커맨드
**Spec:** `docs/superpowers/specs/2026-09-14-작업마무리-이어받기-design.md`
