## Task 2: 측정 도구 — 두 축을 같은 도구로 잰다

**Files:**
- Create: `dev/ai_model/tool_v1/tool_falsepos.py`
- Test: `dev/ai_model/tool_v1/test_tool_falsepos.py`

**Interfaces:**
- Produces:
  - CLI: `tool_falsepos.py --model <pt> --conf 0.65 <세션경로...>`
  - `frame_rate(results, conf) -> (hit_frames, total_frames, ratio)` — 공구가 하나라도 잡힌 프레임 비율
  - `per_class(results, conf) -> {클래스명: 박스수}`

🔑 **한 도구가 두 축을 다 잰다.** 공구가 **없는** 세션에 돌리면 그 비율이 곧 **오검출률**이고, 공구가 **있는** 세션(`tools-baseline`)에 돌리면 **검출 프레임률**이다. 지표 정의가 하나뿐이라 두 축을 섞어 해석할 위험이 없다.

- [ ] **Step 1: 실패하는 테스트를 먼저 쓴다**

```python
# 모델을 올리지 않는다 — 순수 집계 함수만 검증한다(테스트가 수십 초로 늘어나면 안 돈다).
def test_임계미만은_안센다():
    res = [[('wrench', 0.60)], [('driver', 0.70)], []]
    hit, tot, ratio = frame_rate(res, conf=0.65)
    check((hit, tot) == (1, 3), "0.60 은 빠지고 0.70 만 센다")
    check(abs(ratio - 1/3) < 1e-9, "비율 = 1/3")

def test_한프레임에_여러개여도_한번():
    res = [[('wrench', 0.8), ('driver', 0.9)]]
    hit, tot, _ = frame_rate(res, conf=0.65)
    check((hit, tot) == (1, 1), "프레임 단위로 센다 — 박스 수가 아니다")

def test_빈세션은_0으로_나누지_않는다():
    hit, tot, ratio = frame_rate([], conf=0.65)
    check((hit, tot, ratio) == (0, 0, 0.0), "빈 입력에 예외가 없다")

def test_클래스별_박스수():
    res = [[('wrench', 0.8), ('wrench', 0.7), ('driver', 0.6)]]
    d = per_class(res, conf=0.65)
    check(d == {'wrench': 2}, "임계 미만 driver 는 빠진다")
```

```python
def sample_negatives(items, ratio=0.15, seed=0, keep_all_prefixes=()):
    """양성은 전부, 네거티브는 양성 수의 ratio 만큼만 남긴다.

    🆕 keep_all_prefixes(2026-08-14): 그 dataset 접두어의 네거티브는 **샘플링에서
       빼고 전량 유지**한다. 우리 배경 하드 네거티브가 공개 데이터셋 네거티브 풀에
       섞여 비율만큼만 뽑히는 것을 막는다 — 공개 네거티브 후보가 상한보다 많아
       ratio 만 올리면 원하는 만큼 안 들어간다(2026-08-14 확인).
    """
    positives = [i for i in items if i.positive]
    kept = sorted((i for i in items if not i.positive and i.dataset in keep_all_prefixes),
                  key=lambda i: i.src_img)
    pool = sorted((i for i in items if not i.positive and i.dataset not in keep_all_prefixes),
                  key=lambda i: i.src_img)
    k = min(round(len(positives) * ratio), len(pool))
    chosen = random.Random(seed).sample(pool, k) if k else []
    return sorted(positives + kept + chosen, key=lambda i: i.src_img)
```

`main()` 에 `--keep-all <접두어>` 인자를 더한다.
