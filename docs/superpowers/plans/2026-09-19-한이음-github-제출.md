## 마무리 (계획서 밖)

**팀원 이름을 받으면**: README 2항목을 채우고 → `git commit --amend` → `git push -u origin main` → **실제로 확인**(Public 여부 · README 렌더링 · mermaid·썸네일이 보이는지 · 파일 수). 그 뒤 **공동 확인** → `work-close`.

`work-close` 에서 처리할 것 — 통합문서에 제출 저장소 주소를 남길지(§16.1 형상관리·소스가 자리 후보) · `정본검토-기록.md` G1 을 닫기 · 작업로그 ⏸ 의 G1 항목 정리.
