## Task 7: S6 CH5 NC → NO (60~90분 · 맨 끝)

> 절차 정본 = spec `2026-09-05-인터록-물리차단` §11.7. 🔴 **펌웨어 먼저, 가닥은 나중.**

- [ ] **Step 0** 12V 커넥터를 뽑는다. 버튼 공통 가닥은 지금 브레드보드 GND(릴레이 우회) — 그대로.
- [ ] **Step 1** 🔴 테스터 도통 — **CH1 COM ↔ CH5 COM**. 소리 남 = 🛑 여기서 끝(이 모듈로는 못 씀 · 가닥 그대로).
- [ ] **Step 2** 업로드 — 아두이노 USB 를 파이에 꽂고 `cd ~/sop-project/Rpi5/arduino && arduino-cli upload --fqbn arduino:renesas_uno:minima console_interlock`(1200bps 터치 → DFU). 끝 조건 = 업로드 완료 메시지.
- [ ] **Step 3** `RUN` 을 보내고 **CH5 LED 켜짐** 확인 — `python3 -c "import serial,time; s=serial.Serial('<아두이노 포트>',115200,timeout=2); time.sleep(2); s.write(b'RUN\n'); print(s.readline())"` → `ACK` · LED 켜짐(꺼짐이면 Step 2 로).
- [ ] **Step 4** 결선 — 버튼 와고 출력 1가닥 → **CH5 NO** · **CH5 COM** → 파이 물리 25번(GND) · NC 비움 · EMO 건드리지 않음. 12V 다시 연결.
- [ ] **Step 5** §11.5 7항목 — 시연 프로그램 없이 본다(포트·핀을 직접). 창 A = `gpiomon -c gpiochip0 5 6 13 19 26`(B1·B2·B3·B4·EMO — 누를 때마다 줄이 찍힘) · 창 B = 명령 보내기 `python3 -c "import serial,time,sys; s=serial.Serial('<아두이노 포트>',115200,timeout=2); time.sleep(2); s.write((sys.argv[1]+'\n').encode()); print(s.readline())" BLOCK`(또는 `RUN`).
  ①(Step 1) ②`RUN` 에서 B1~B4 를 누르면 창 A 에 각각 찍힘 ③`BLOCK` 에서 B1~B4 를 눌러도 **하나도** 안 찍힘 ④`BLOCK` 중 EMO 는 찍힘 ⑤`BLOCK` → `RUN` 복귀 후 B1 찍힘 × 10회 ⑥**아두이노 USB 를 뽑으면 B1~B4 가 안 찍히고, 다시 꽂으면 찍힘**(부팅 초기값 = 통전) ⑦타워램프 적·황·녹·부저 종전대로(`BLOCK`=적+부저 · `WARN`=황 · `RUN`=녹). 🛑 ②에서 안 찍히면 가닥을 브레드보드 GND 로 되돌리고 끝.
- [ ] **Step 6** 디바운스 — `SOP_VOICE=0 SOP_VOICE_ALERTS=0 DISPLAY=:0 bash ~/sop-project/Rpi5/Demo/run_demo.sh`(창 A 의 `gpiomon` 은 먼저 끈다) · `config.GPIO_BOUNCE_SEC` 0.05 그대로 B1~B4 각 보통 5회 + 짧게 5회 → 로그에 버튼마다 정확히 10줄(합계 40).
