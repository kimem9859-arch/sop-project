# 음성비서 시연 구현 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 글라스 한 대로 「가디언」 호출 → 띠링 → *"앞에 보이는 게 뭐야?"* → 공구 안내가 되는 최소 음성비서를 만들어 시연 영상을 찍는다.

**Architecture:** ESP32-S3 한 보드가 카메라(TCP 8888)·마이크 업링크(8889)·명령/스피커(8890)를 **같은 WiFi 링크**로 낸다. 파이1에서는 GUI(`safety_console`)를 **0줄도 바꾸지 않고**, 별도 프로세스 `voice_assistant.py` 가 마이크를 받아 VAD→STT→호출어/의도 판정을 하고 **미리 합성해 둔 wav** 를 돌려보낸다. 공구 정보는 `tool_worker` 가 이미 쓰는 `/dev/shm/sop_tool/resp.json` 을 읽기만 한다.

**Tech Stack:** Arduino ESP32 core 3.3.10(`ESP_I2S`, `WiFiServer`) · Python 3.13(`~/env/tts/.venv`) · `sherpa-onnx` 1.13.7(STT transducer + hotwords, TTS VITS) · 기존 `esp32_audio.py` 프로토콜(`W`/`P`/`R`/`D`)

**Spec:** `docs/superpowers/specs/2026-09-06-음성비서-시연구현-design.md`

## Global Constraints

- 🔴 **굽기는 반드시 `--fqbn esp32:esp32:XIAO_ESP32S3:PSRAM=opi`** — 빠뜨리면 카메라가 부팅 루프에 빠진다(`flash_esp32.sh`).
- 🔴 **업로드 포트는 `/dev/ttyACM1` 을 쓰지 말고 신원으로 찾는다** — `ttyACM0` 은 Arduino 인터록이다. 확인: `python3 Rpi5/Demo/serial_ports.py`
- 🔴 **`camera_stream_tcp.ino` 의 카메라 코드는 한 줄도 바꾸지 않는다.** 새 스케치에 복사하되 추가분은 `── 오디오 추가분 ──` 주석으로 표시한다(통신경로 과제와의 drift 방지, spec §4).
- 🔴 **mDNS 를 쓰지 않는다.** 접속 주소는 항상 `Rpi5/Demo/.camera_ip` 를 **매번 읽는다**.
- 🔴 **GUI(`Rpi5/Demo/safety_console.py`·`camera_thread.py`)를 수정하지 않는다.**
- 🔴 **PDM 마이크는 DC 오프셋(1000~1600)을 함께 낸다** — 창마다 평균을 빼지 않으면 소리 변화가 안 보인다.
- **파이 쪽 실행 파이썬은 `~/env/tts/.venv/bin/python`**(3.13). `Demo/config.py` 는 `os` 만 import 하므로 어느 venv 에서도 읽을 수 있다.
- **STT 스레드는 2개** — 4개면 Hailo·MediaPipe 와 CPU 를 다툰다.
- **핫워드 가중치 3.0**, 핫워드 파일 `~/lab/tts/hotwords_ko.txt`, BPE vocab `~/lab/tts/bpe.vocab`(§10.52).
- **selftest 는 프로젝트 방식을 따른다** — `python3 Demo/selftest/test_X.py` 로 도는 평범한 스크립트, `check(cond, msg)` + `_fails` 집계. pytest 를 쓰지 않는다.
- 커밋 서명은 `CLAUDE.md` 「4. 커밋」 규칙을 따른다. 코드는 `Rpi5`, 문서는 `sop-project`.

```cpp
// ─────────────── 오디오 추가분 (여기부터) ───────────────
#define MIC_CLK   42
#define MIC_DATA  41
#define SPK_BCLK   1    // D0
#define SPK_LRC    2    // D1
#define SPK_DIN    3    // D2

static const uint32_t RATE = 16000;      // 🔴 마이크 고정 (설계 §8.2)

I2SClass mic;
I2SClass spk;

// 🔑 Serial(USB CDC)과 WiFiClient 는 둘 다 Stream 을 상속한다 —
//    프로토콜 코드는 유선인지 무선인지 모른 채 동작한다(§10.51-(1)).
static Stream *io = &Serial;

/** 한 음을 정해진 시간만큼 낸다. */
void beep(int freq, int ms, int amp = 5000) {
  const size_t frames = (size_t)((uint64_t)RATE * ms / 1000);
  static int16_t buf[256 * 2];
  float ph = 0.0f;
  for (size_t done = 0; done < frames; done += 256) {
    for (size_t i = 0; i < 256; i++) {
      ph += 2.0f * (float)M_PI * freq / (float)RATE;
      if (ph > 2.0f * (float)M_PI) ph -= 2.0f * (float)M_PI;
      buf[i * 2 + 0] = (int16_t)(sinf(ph) * amp);   // 🔴 SD=3V3 라 왼쪽 채널만 난다
      buf[i * 2 + 1] = 0;
    }
    spk.write((uint8_t *)buf, sizeof(buf));
  }
}
// ─────────────── 오디오 추가분 (여기까지) ───────────────
```

- [ ] **Step 2: 8890 서버와 명령 루프를 더한다**

「오디오 추가분」 블록에:

```cpp
WiFiServer cmdServer(8890);
WiFiClient cmdClient;

/** 한 글자 명령을 처리한다 — 유선/무선 공통. */
static void handleCmd(char c) {
  if (c == 'W' || c == 'R') {
    String args = readLine();
    if (c == 'W') cmdWrite(args);
    else          record((uint32_t)args.toInt());
  } else if (c == 'D') { readLine(50); cmdDump(); }
  else if (c == 'P')   { readLine(50); play(); }
  else if (c == 'B')   { readLine(50); beep(1175, 90); delay(40); beep(1568, 140); }
  else if (c == 'r')   { record(3); if (hasRec) { delay(200); play(); } }
  else if (c == 'p')   { play(); }
  else if (c >= '1' && c <= '5') { volIdx = c - '1'; }
}

/** 명령 채널 — 무선 손님이 있으면 그쪽, 없으면 USB 시리얼. */
void audioCmdTask(void *param) {
  cmdServer.begin();
  cmdServer.setNoDelay(true);
  while (true) {
    if (!cmdClient || !cmdClient.connected()) {
      WiFiClient c = cmdServer.accept();
      if (c) { cmdClient = c; cmdClient.setNoDelay(true); io = &cmdClient;
               Serial.println("[audio] 명령 채널 연결됨(8890)"); }
    }
    if (cmdClient && cmdClient.connected() && cmdClient.available()) {
      handleCmd((char)cmdClient.read());
    } else if (Serial.available()) {
      io = &Serial;                    // 🔑 USB 로 오면 그쪽이 임자다
      handleCmd((char)Serial.read());
      if (cmdClient && cmdClient.connected()) io = &cmdClient;
    } else {
      vTaskDelay(pdMS_TO_TICKS(10));
    }
  }
}
```

**Interfaces:**

- [ ] **Step 1: 업링크 태스크를 더한다**

「오디오 추가분」 블록에:

```cpp
WiFiServer micServer(8889);

/** 마이크 상시 업링크 — 손님이 있을 때만 읽어 보낸다.
 *
 *  🔑 DC 오프셋을 여기서 빼지 않는다. 창을 어디서 자르느냐에 따라 평균이
 *     달라지는데, 파이는 발화 구간을 알고 자르므로 **거기서 빼는 편이 정확하다.**
 *  🔴 손님이 없으면 읽지도 않는다 — 안 읽으면 I2S DMA 가 알아서 덮어쓴다.
 */
void micUplinkTask(void *param) {
  micServer.begin();
  micServer.setNoDelay(true);
  static int16_t buf[512];
  WiFiClient c;
  while (true) {
    if (!c || !c.connected()) {
      c = micServer.accept();
      if (c) { c.setNoDelay(true); Serial.println("[audio] 마이크 업링크 연결됨(8889)"); }
      else   { vTaskDelay(pdMS_TO_TICKS(100)); continue; }
    }
    size_t n = mic.readBytes((char *)buf, sizeof(buf));
    if (n == 0) { vTaskDelay(pdMS_TO_TICKS(5)); continue; }
    if (c.write((uint8_t *)buf, n) != n) { c.stop(); Serial.println("[audio] 업링크 끊김"); }
  }
}
```

`setup()` 의 오디오 태스크 등록 옆에:

```cpp

```

```python
#!/usr/bin/env python3
"""답변 wav 사전 합성 — 시연용 정형 답변은 문장이 유한하다.

실행: ~/env/tts/.venv/bin/python Demo/voice/make_answers.py

🔑 미리 만들어 두는 이유 세 가지:
   ① 응답이 0.4초 빨라진다(합성 시간이 사라진다)
   ② **명료도를 미리 들어보고 나쁘면 다시 만들 수 있다** — ⛔ 미판정으로 남은
      §10.49 위험을 시연 범위에서만 덮는다
   ③ 런타임 TTS 를 안 띄워도 되어 메모리·CPU 가 빈다

⚠️ 이것은 「유연한 LLM 답변」 방향을 바꾸는 것이 아니다. 템플릿 답변(A안)에서만
   성립하는 최적화이고, LLM(B안)으로 갈 때 런타임 TTS 로 되돌린다.
"""
import array
import os
import time
import wave

import sherpa_onnx

D = os.path.expanduser("~/env/tts/vits-mimic3-ko_KO-kss_low")
OUT = os.path.join(os.path.dirname(os.path.abspath(__file__)), "wav")

# 🔴 키는 voice_lib.answer_key() 가 돌려주는 값과 정확히 같아야 한다.
ANSWERS = {
    "driver":  "앞에 드라이버가 보입니다.",
    "wrench":  "앞에 렌치가 보입니다.",
    "pliers":  "앞에 플라이어가 보입니다.",
    "none":    "지금은 공구가 보이지 않습니다.",
    "notstep": "지금은 공구를 확인하는 단계가 아닙니다.",
    "ack":     "네, 말씀하세요.",
}


def main():
    os.makedirs(OUT, exist_ok=True)
    cfg = sherpa_onnx.OfflineTtsConfig(
        model=sherpa_onnx.OfflineTtsModelConfig(
            vits=sherpa_onnx.OfflineTtsVitsModelConfig(
                model=f"{D}/ko_KO-kss_low.onnx",
                tokens=f"{D}/tokens.txt",
                data_dir=f"{D}/espeak-ng-data",
            ),
            num_threads=2, provider="cpu",
        ),
        max_num_sentences=1,
    )
    t0 = time.time()
    tts = sherpa_onnx.OfflineTts(cfg)
    print(f"모델 적재 {time.time() - t0:.2f}s")

    for k, text in ANSWERS.items():
        t = time.time()
        a = tts.generate(text, sid=0, speed=1.0)
        el = time.time() - t
        path = os.path.join(OUT, f"{k}.wav")
        with wave.open(path, "w") as w:
            w.setnchannels(1)
            w.setsampwidth(2)
            w.setframerate(a.sample_rate)
            w.writeframes(array.array(
                "h", [int(max(-1, min(1, x)) * 32767) for x in a.samples]).tobytes())
        print(f"  {k:8s} {len(text):2d}자 · 합성 {el:.2f}s · "
              f"{len(a.samples)/a.sample_rate:.2f}초 · {a.sample_rate}Hz → {path}")


if __name__ == "__main__":
    main()
```

```python
"""음성비서 판정 로직 — 소켓·모델에 의존하지 않는 순수 함수만 둔다.

정본: ../docs/superpowers/specs/2026-09-06-음성비서-시연구현-design.md

🔑 왜 갈라 두나 — 소켓·모델이 붙은 코드는 HW 없이 못 돌린다. 판정만 빼 두면
   1초 안에 도는 selftest 가 되고, 촬영 현장에서 고칠 때 근거가 된다
   (tool_state.py 와 같은 철학).
"""
import json
import math
import os
import time

# 🔑 실측된 오인식을 그대로 받아들인다 — §10.51 에서 「가디언」이 이렇게 튀었다.
#    이 목록 덕에 호출어 적중이 3/4 → 사실상 4/4 가 된다.
WAKE_WORDS = ("가디언", "가디건", "가디얀", "가디현")

# 공구 질문 — 「보이다」 계열 또는 「공구」가 있으면 공구를 묻는 것으로 본다.
_TOOL_HINTS = ("보이", "보여", "공구")
_WHAT_HINTS = ("뭐", "무엇", "뭔")

_TOOL_KEYS = ("driver", "wrench", "pliers")
TOOL_SHM = "/dev/shm/sop_tool/resp.json"
FRESH_SEC = 3.0          # 🔴 스캔은 wait_tool 동안에만 돈다 — 낡으면 「단계 아님」


def _norm(text):
    return "".join(c for c in (text or "") if not c.isspace() and c not in ",.?!·")


def is_wake(text):
    """호출어가 들어 있는가."""
    n = _norm(text)
    return any(w in n for w in WAKE_WORDS)


def is_tool_question(text):
    """「지금 보이는 공구가 무엇인가」를 묻는가."""
    n = _norm(text)
    return any(h in n for h in _TOOL_HINTS) and any(h in n for h in _WHAT_HINTS)


def rms(samples):
    """DC 오프셋을 뺀 실효값.

    🔴 PDM 마이크는 1000~1600 의 오프셋을 함께 낸다 — 빼지 않으면 무음도
       커 보여 VAD 가 늘 켜진다(2026-08-26 에 실제로 물렸다).
    """
    if not samples:
        return 0.0
    dc = sum(samples) / len(samples)
    return math.sqrt(sum((s - dc) ** 2 for s in samples) / len(samples))


def find_utterance(samples, rate, start_th=600, end_th=300,
                   min_ms=300, tail_ms=500):
    """말이 시작된 지점과 끝난 지점을 돌려준다. 없으면 None.

    프레임 20ms 단위로 RMS 를 보고, start_th 를 넘으면 시작,
    end_th 아래가 tail_ms 만큼 이어지면 끝으로 본다.
    """
    fr = max(1, int(rate * 0.02))
    tail_frames = max(1, int(tail_ms / 20))
    start = None
    quiet = 0
    for i in range(0, len(samples) - fr, fr):
        v = rms(samples[i:i + fr])
        if start is None:
            if v >= start_th:
                start = i
                quiet = 0
        else:
            quiet = quiet + 1 if v < end_th else 0
            if quiet >= tail_frames:
                end = i - quiet * fr
                return (start, end) if end - start >= rate * min_ms / 1000 else None
    if start is not None and len(samples) - start >= rate * min_ms / 1000:
        return (start, len(samples))
    return None


def read_tool_dets(path=TOOL_SHM, fresh_sec=FRESH_SEC, now=None):
    """(dets, fresh) — 공구 검출과 그것이 신선한지.

    🔴 공구 추론은 `wait_tool` 서브 작업 동안에만 돈다(camera_thread.py:242).
       그래서 파일이 낡았으면 「지금 확인하는 단계가 아니다」로 답한다 —
       **부재를 근거로 지어내지 않는다.**
    """
    try:
        st = os.stat(path)
    except OSError:
        return [], False
    age = (now or time.time()) - st.st_mtime
    if age > fresh_sec:
        return [], False
    try:
        with open(path, encoding="utf-8") as f:
            raw = json.load(f).get("dets") or []
    except (OSError, ValueError):
        return [], False
    # dets = [(클래스명, 점수, x1, y1, x2, y2), ...] — tool_gate.py:145 와 같은 모양
    return [tuple(d) for d in raw], True


def answer_key(dets, fresh):
    """재생할 wav 키를 고른다 — make_answers.ANSWERS 의 키와 같아야 한다."""
    if not fresh:
        return "notstep"
    best, best_score = None, -1.0
    for d in dets or []:
        # 🔑 tool_v4 부터 `wrench-in-hand` 처럼 접미어가 붙는다 — 벗긴다.
        name = str(d[0]).split("-in-hand")[0].strip()
        if name not in _TOOL_KEYS:
            continue
        score = float(d[1])
        if score > best_score:
            best, best_score = name, score
    return best or "none"
```

```python
#!/usr/bin/env python3
"""음성비서 데몬 — 「가디언」 → 띠링 → 「앞에 보이는 게 뭐야?」 → 공구 안내.

실행: ~/env/tts/.venv/bin/python Demo/voice_assistant.py
정본: ../docs/superpowers/specs/2026-09-06-음성비서-시연구현-design.md

🔑 GUI 를 0줄도 건드리지 않는다 — 별도 프로세스이고, 공구 정보는 tool_worker 가
   이미 쓰는 /dev/shm/sop_tool/resp.json 을 읽기만 한다.

🔴 접속 주소는 Demo/.camera_ip 를 매번 읽는다 — mDNS 를 쓰지 않기로 했고
   (통신경로 설계 §6-②), 그 덕에 iptime·폰·파이AP 어느 폴백에서도 그대로 돈다.
"""
import array
import os
import socket
import struct
import sys
import time

import sherpa_onnx

_DEMO_DIR = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, _DEMO_DIR)

from voice_lib import (answer_key, find_utterance, is_tool_question, is_wake,
                       read_tool_dets)

IP_FILE   = os.path.join(_DEMO_DIR, ".camera_ip")
WAV_DIR   = os.path.join(_DEMO_DIR, "voice", "wav")
MIC_PORT  = 8889
CMD_PORT  = 8890
RATE      = 16000

STT_DIR   = os.path.expanduser("~/env/tts/sherpa-onnx-zipformer-korean-2024-06-24")
HOTWORDS  = os.path.expanduser("~/lab/tts/hotwords_ko.txt")
BPE_VOCAB = os.path.expanduser("~/lab/tts/bpe.vocab")

WINDOW_SEC = 6.0      # 판정에 쓰는 최근 구간
LISTEN_SEC = 8.0      # 🔑 호출 뒤 질문을 기다리는 시간 — 없으면 영원히 깨어 있다
LAG_LIMIT  = 2.0      # 🔴 이보다 밀리면 오래된 오디오를 버린다(최신 우선)


def log(msg):
    print(f"[{time.strftime('%H:%M:%S')}] {msg}", flush=True)


def esp_ip():
    return open(IP_FILE, encoding="utf-8").read().strip()


def build_stt():
    """🔴 스레드 2개 — 4개면 Hailo·MediaPipe 와 CPU 를 다툰다."""
    return sherpa_onnx.OfflineRecognizer.from_transducer(
        encoder=f"{STT_DIR}/encoder-epoch-99-avg-1.int8.onnx",
        decoder=f"{STT_DIR}/decoder-epoch-99-avg-1.onnx",
        joiner=f"{STT_DIR}/joiner-epoch-99-avg-1.int8.onnx",
        tokens=f"{STT_DIR}/tokens.txt",
        num_threads=2,
        decoding_method="modified_beam_search",
        hotwords_file=HOTWORDS,
        hotwords_score=3.0,          # §10.52 에서 고른 잠정값
        modeling_unit="bpe",
        bpe_vocab=BPE_VOCAB,
    )


def transcribe(rec, samples):
    st = rec.create_stream()
    st.accept_waveform(RATE, [s / 32768.0 for s in samples])
    rec.decode_stream(st)
    return st.result.text


def send_cmd(ip, payload):
    """8890 에 한 번 붙어 명령을 보내고 응답 로그를 흘려버린다."""
    with socket.create_connection((ip, CMD_PORT), 10) as s:
        s.settimeout(20)
        s.sendall(payload)
        time.sleep(0.2)
        try:
            while s.recv(4096):
                pass
        except OSError:
            pass


def play_wav(ip, key):
    """미리 합성해 둔 답변을 보내 재생한다."""
    import wave
    path = os.path.join(WAV_DIR, f"{key}.wav")
    with wave.open(path) as w:
        rate = w.getframerate()
        raw = w.readframes(w.getnframes())
    a = array.array("h")
    a.frombytes(raw)
    chk = sum(v & 0xFFFF for v in a) & 0xFFFFFFFF
    body = (f"W {len(a)} {rate}\n".encode() + a.tobytes()
            + struct.pack("<I", chk) + b"P\n")
    send_cmd(ip, body)
    log(f"재생 → {key} ({len(a)/rate:.1f}초)")


def main():
    ip = esp_ip()
    log(f"ESP32 = {ip}")
    log("STT 적재 중...")
    rec = build_stt()
    log("STT 준비됨")

    mic = socket.create_connection((ip, MIC_PORT), 10)
    mic.settimeout(5)
    log(f"마이크 업링크 연결됨 ({MIC_PORT})")

    buf = array.array("h")
    awake_until = 0.0
    last_txt_at = 0.0

    while True:
        try:
            chunk = mic.recv(16384)
        except socket.timeout:
            continue
        if not chunk:
            log("🔴 업링크 끊김 — 3초 뒤 재연결")
            mic.close()
            time.sleep(3)
            ip = esp_ip()
            mic = socket.create_connection((ip, MIC_PORT), 10)
            mic.settimeout(5)
            buf = array.array("h")
            continue

        a = array.array("h")
        a.frombytes(chunk[:len(chunk) // 2 * 2])
        buf.extend(a)

        # 🔴 최신 우선 — TCP 재전송으로 밀리면 오래된 것을 버린다.
        #    카메라가 CAMERA_GRAB_LATEST 로 같은 문제를 푸는 것과 같은 처방.
        limit = int(RATE * (WINDOW_SEC + LAG_LIMIT))
        if len(buf) > limit:
            del buf[:len(buf) - int(RATE * WINDOW_SEC)]

        if len(buf) < RATE * 1.0 or time.time() - last_txt_at < 0.4:
            continue

        seg = find_utterance(buf.tolist(), RATE)
        if seg is None:
            continue
        s, e = seg
        if e - s < RATE * 0.3:
            continue
        # 발화가 아직 끝나지 않았으면(끝이 버퍼 끝에 붙어 있음) 더 기다린다
        if len(buf) - e < int(RATE * 0.4):
            continue

        text = transcribe(rec, buf[s:e].tolist())
        del buf[:e]
        last_txt_at = time.time()
        if not text.strip():
            continue
        log(f"들림: {text}")

        now = time.time()
        awake = now < awake_until

        if is_wake(text):
            send_cmd(ip, b"B\n")            # 띠링 — 즉시
            awake_until = now + LISTEN_SEC
            log("호출어 인식 → 띠링")
            # 🔑 한 문장에 질문까지 있으면 바로 답한다(상태기계 폴백)
            if not is_tool_question(text):
                continue
            awake = True

        if awake and is_tool_question(text):
            dets, fresh = read_tool_dets()
            key = answer_key(dets, fresh)
            play_wav(ip, key)
            awake_until = 0.0


if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        print()
```
