# ESP32 통신 경로 재설계 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ESP32 영상이 폰 핫스팟을 지나지 않고 콘솔 내부 iptime 공유기를 거쳐 파이1 에 유선으로 들어오게 한다 — 무선 2홉을 1홉으로 줄이고 폰을 영상 경로에서 뺀다.

**Architecture:** 파이1 은 통로가 둘이다. 무선(wlan0)은 인터넷 전용으로 그대로 두고, 랜포트(eth0)로 공유기에 붙어 ESP32 를 만난다. ESP32 는 `WIFI_CREDS` 우선순위만 바꿔 공유기에 먼저 붙고, 공유기가 없으면 폰으로 자동 폴백한다. 파이 런타임 코드는 0줄 바뀐다.

**Tech Stack:** Arduino ESP32 core 3.3.10 (`XIAO_ESP32S3:PSRAM=opi`) · arduino-cli · bash · Python 3(측정 도구 `Demo/test/link_probe.py`)

**Spec:** `docs/superpowers/specs/2026-09-06-esp32-통신경로-design.md`

## Global Constraints

- 🔴 **장비를 사지 않는다.** 여행용 라우터·USB 동글 구매 금지(spec §3).
- 🔴 **파이 런타임 로직 0줄.** `Demo/*.py` 의 동작 코드를 바꾸지 않는다(spec §2 비목표).
- 🔴 **mDNS 를 쓰지 않는다.** 이 파이에서 `.local` 이 DNS 로 새어 인터넷 IP(`218.38.137.27`)로 해석된다(spec §8-⑥).
- 🔴 **폰 폴백을 없애지 않는다.** `WIFI_CREDS` 에 폰 SSID 를 2순위로 반드시 남긴다 — 이것이 유일한 안전판이다(spec §5).
- 🔴 **수치를 인용할 때 조건을 병기한다.** 확정 측정의 정본은 통합문서 §10 이며, 이 계획서에 수치를 새로 박지 않는다.
- ⚠️ `arduino/wifi_credentials.h` 는 **gitignore 대상**이다(비밀번호 보호). 커밋되지 않으므로 **변경 전 사본을 남긴다.**

### Task 2: `read_esp32_ip.sh` 의 대역 비교를 실제 경로 기준으로

**문제** — 지금은 ESP32 IP 의 대역을 **wlan0** 과 비교한다(`read_esp32_ip.sh:51`). 이 설계 후 ESP32 는 **eth0 대역**에 있게 되어, **정상인데도 「다른 네트워크입니다」라고 경고**하고 엉뚱한 조치(`nmcli connection up Jason`)를 안내한다.

**Files:**
- Modify: `Rpi5/arduino/read_esp32_ip.sh:50-62`

**Interfaces:**
- Consumes: 없음
- Produces: 없음 (스크립트 내부 동작만)

- [ ] **Step 1: 현재 동작을 재현해 실패를 확인한다**

```bash
IP=192.168.1.19   # 공유기 경유 시 ESP32 가 받을 대역
PI_IP=$(ip -4 -o addr show wlan0 | awk '{print $4}' | cut -d/ -f1)
[ "${PI_IP%.*}" = "${IP%.*}" ] && echo "같은 대역" || echo "🔴 다른 대역 → 지금 로직은 여기서 오경고"
```
Expected: `🔴 다른 대역 → 지금 로직은 여기서 오경고`

- [ ] **Step 2: 커널에 실제 경로를 물어 비교하도록 고친다**

`read_esp32_ip.sh` 의 서브넷 확인 블록(현재 50~62행)을 아래로 교체:

```bash
# ESP32 로 실제로 나가는 경로를 커널에 묻는다 — 인터페이스를 고정하지 않는다.
# 🔴 2026-09-06 이전에는 wlan0 과 비교했는데, ESP32 가 공유기(eth0 대역)로
#    옮겨간 뒤로는 정상인데도 「다른 네트워크」라고 오경고했다.
ROUTE=$(ip -4 -o route get "$IP" 2>/dev/null)
PI_IP=$(echo "$ROUTE" | grep -oE 'src [0-9.]+' | awk '{print $2}')
IFACE=$(echo "$ROUTE" | grep -oE 'dev [^ ]+'  | awk '{print $2}')
if [ -n "$PI_IP" ]; then
  echo "✅ 파이($PI_IP, $IFACE)에서 ESP32($IP)로 가는 경로가 있습니다."
else
  echo
  echo "⚠️  파이에서 ESP32($IP)로 가는 경로가 없습니다!"
  echo "    이대로는 카메라 연결이 안 됩니다."
  echo "    ESP32가 붙은 망에 파이도 연결되어 있는지 확인하세요"
  echo "    (공유기 경유라면 랜선, 핫스팟 경유라면 같은 SSID)."
fi
```

- [ ] **Step 3: 고친 로직을 검증한다**

```bash

```
Expected: `구문 OK` · `✅ 경로 판정 동작`

- [ ] **Step 4: 커밋**

