## Global Constraints

- 판정 6종 = 유지 / 이동 / 수정 / 병합 / 승격 / 제거. **「제거」의 행선지는 반드시 `docs/변경이력.md`**(spec §3.3 · R2).
- 🔴 **도구 규칙(T1~T9)은 공식 문서(spec §3.1)만으로 판정한다.** 프로젝트 규칙끼리 서로 판정하지 않는다(spec §5.2).
- 🔴 **공식 기준으로 「제거·수정」이 나와도 그 규칙이 실제 사고에서 나온 것이면 제거하지 않고 「사례」로 표시**해 사용자 판단으로 올린다(spec §5.2).
- 🔴 공식↔프로젝트 **충돌은 건별로 사용자에게 올린다.** 일반 규칙을 세우지 않는다(spec §5.3).
- 원장의 모든 행은 **「새 자리」 또는 「변경이력.md」** 중 하나를 가져야 한다. 어느 쪽도 아닌 행은 허용하지 않는다.

```bash
python3 - <<'PY'
import re,collections
off,prj=collections.Counter(),collections.Counter()
for l in open("docs/superpowers/plans/2026-09-20-규칙표면-원장.md",encoding="utf-8"):
    if not l.startswith("| ") or l.startswith("| ID"): continue
    c=[x.strip() for x in l.split("|")]
    if len(c)<10 or set(c[1])<=set("- "): continue   # 표 구분선 제외
    if c[5]: off[c[5]]+=1
    if c[6]: prj[c[6]]+=1
print("공식 기준:",dict(off)); print("프로젝트 기준:",dict(prj))
for n,cc in (("공식",off),("프로젝트",prj)):
    t=sum(cc.values())
    if t: print(f"  {n} 「유지」 비율 {cc.get('유지',0)/t*100:.0f}%")
PY
```
