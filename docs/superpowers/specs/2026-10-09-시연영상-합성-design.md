- 단계·버튼·공구 = 정본 §5 시연 공정 시나리오(B1 클린·가스차단 → B2 펌프/퍼지 + 렌치 → B3 전극 냉각 → B4 챔버 벤트). 틀린 공구는 **다른 공구 경고가 바로 뜨고, 맞는 공구를 연속으로 여러 번 쥔 것이 보여야 확인**된다(횟수 = 세션 설정 `confirm_scans` · `Rpi5/Demo/tool_state.py` 머리말).
- 「차단」은 **화면 표시 · 램프 · 부저까지**만 보인다 — 버튼 전기 차단(CH5)은 실물에서 동작하지 않는다(통합문서 §4.2). 「전기 차단」 표현을 쓰지 않는다.
