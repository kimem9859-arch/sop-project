## 2. 목표 / 비목표

**목표** — 구성 사실을 한 곳에서만 고치게 하고, §10 에서 한 주제의 절 전체와 살아 있는 미결을 머리에서 바로 찾게 한다. 다음 작업이 이 구조를 지키도록 규칙에 박는다.

**비목표** — §10 절 번호 변경(1,700여 곳 인용이 깨진다) · §10 저널 본문 수정 · ③ 사실 추가 · 절차 개선(관문·훅 — 09-08 응답 29 의 「다음 판」).

## 3. 결정

### 3.1 G — 구성 사실 정본 위치 (사용자 결정)

| 사실 | 정본 | 담는 것 |
|---|---|---|
| **부품** | **§11.1** 확정 하드웨어 사양 | 모듈 이름·채널 수·active LOW·아두이노 기종 |
| **배정** | **§12** 하드웨어 상세 설계(핀맵) | 아두이노 핀 → 릴레이 채널 → 부하(타워램프 적·황·녹·부저 · **CH5 버튼 공통 GND 차단**) · 버튼 B1~B4 → GPIO5/6/13/19 · EMO → GPIO26(NC) · CH5 접점(펌웨어 NC · NO 개정 확정) |

- 나머지 절(§3·§4 FR-3·§5.1·§5.2·§5.3·§8·§9·§14.2)은 **「부품 §11.1 · 배정 §12」 포인터**만 둔다. 색↔단계 대응(B1 노랑 …)은 콘솔 사양이라 §5.3 에 남긴다.
- **현황**(CH5 실물 미동작 등)은 정본 위치가 아니라 **3.2 미결 표**로 간다. §3·FR-3·§8·§9 의 「현황 = §11.1」 포인터는 「현황 = §10 🔓 미결」로 갈아 끼운다.
- §5.1 블록도 「릴레이 8채널」 → 「릴레이 모듈」(채널 수도 부품 사실). *Claude 결정*
- §12 의 2026-07-15 통합 작동 테스트(4채널) 행·인용 블록은 **날짜 붙은 이력**이라 유지. 「최종 4채널 사용 / 8채널 모듈은 테스트·확장용」 서술은 현행 사실이 아니므로 배정 표로 대체. *Claude 결정*
- 글라스 마이크 핀(§11.3 GPIO42/41)은 콘솔 인터락과 별개라 범위 밖. *Claude 결정*
- §10 저널 안의 핀·채널 서술(§10.32·§12 인용 등 당시 기록)은 고치지 않는다.

### 3.2 F — 🔓 살아 있는 미결 표 (사용자 결정)

위치 = §10 머리 「⛔ 확정값으로 쓰면 안 되는 것」 **다음**. 열 = `미결 | 분야 | 막힌 이유·조건 | 근거 | 기록일`.

**② 에서 넣는 행 — 근거가 이미 정본에 있는 것만** *(Claude 결정 — 근거가 ③에서 생기는 항목은 ③에서 행 추가)*

| 미결 | 분야 | 근거 |
|---|---|---|
| CH5 버튼 입력 차단 실동작 · 접점 NO 개정 미실행 | HW | §11.1 · §12 · spec `2026-09-05-인터록-물리차단` §11 |
| 인터락 결선도 문서(`dev/interlock/결선도_초안.md`) 8채널·CH5 미반영 | 문서 | §12 |
| 카메라 세로 전환(480×640)의 검출 정확도 영향 미측정 | 비전 | §7.1 프레임 방향 |
| QVGA 검토 미실시(결정 규칙 발동 조건은 충족) | 비전 | §7.1 입력 해상도 |
| HOI 이중 신뢰도 0.70/0.55 의 지위(재정의 또는 폐기) | 비전 | §7.1 주석 |
| 실콘솔 2차 test 미실시(console_v2 최종 판정) | 비전 | §10.16 · §10.20 |
| `tool_v5` 재학습 가능성 · 직접 학습 모델 학습 코드 전수 검사 | 비전 | §10.63 |
| 음성비서 재생 구간 미측정 · 답변 소리 여부 미확인 | 음성 | §10.61 정정 |
| 음성비서 V2(링크 30분)·V7(배터리 90분) 미실시 · V6 부분 | 음성 | §11.3 |
| OV3660 카메라 예비 0개 | HW | §11.3 |

- **③ 으로 넘긴 행** — `gpio_input.available` 거짓 양성 · 버튼 디바운스 0.2초 임시 확정(런타임 0.05) — 통합문서 근거 0회(「거짓 양성」·「디바운스」 검색, spec 검토 중 확인). ③ 에서 사실을 정본에 넣으면서 행을 추가한다.
- 반영 시 **행마다 근거 절을 열어 사실을 재확인**하고, 근거가 정본에 없으면 그 행은 ③으로 넘긴다(표에 넣지 않는다).
- 표는 한 줄 요약 + 근거 포인터만. 수치는 쓰지 않는다(수치는 [CURRENT] 표·해당 절).
