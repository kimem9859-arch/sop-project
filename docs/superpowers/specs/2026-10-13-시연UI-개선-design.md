### 3.1 인식 상자 이름표 그리기
- 지금처럼 **영상 장면 위에 OpenCV 로 그린다**(처리 스레드 · 매 장면). 꺾쇠 = `cv2.line` 8개 · 이름표 = 채운 사각형 + `putText`(영문 · 숫자).
- ✓ · ✕ · 자물쇠는 Hershey 글꼴에 없다 → **선으로 직접**(✓ 2줄 · ✕ 2줄 · 자물쇠 = 사각형 + 호). 장면당 선 몇 개 추가라 비용은 지금 글자 그리기 수준.

### 3.2 경고 해제 규칙 — 안 A(사용자 10/13)
- 🔴 **판정 규칙이 바뀐다.** 지금은 경고를 「해제 버튼」 또는 「정답 버튼」으로만 푼다(`fsm.py:246` · 비전 틱 자동 전이 없음).
- 새 규칙: **경고가 시작된 뒤 `WARN_AUTO_RELEASE_SEC`(3.0초)가 지났고, 손이 틀린 버튼에서 떠나 있으면** 저절로 풀린다(`release_warning()`). 손이 그대로면 경고 유지 · 정답 버튼은 지금처럼 즉시 해제 + 단계 진행.
- 구현 자리: `SafetyFSM.update_vision` 의 상태 게이트(③) 앞 — WARNING 이고 `roi != 경고 대상` 이 일정 시간 이어지면. 「손이 떠남」 판정은 기존 진짜 이탈(갭메우기 0.3초) 규칙을 그대로 쓴다.
- 측정 기록: 자동 해제도 `release`(what=warning, ok=True, how=auto) 로 남긴다 — 측정 진행 도우미(`measure_guide.py:83`)가 「해제」로 읽는다. 시연(`run_demo.sh`)에는 측정이 돌지 않아 영향 없음.
- 끄기 스위치 `SOP_WARN_AUTO_RELEASE=0`(종전 동작 · 해제 버튼 복구는 하지 않는다 — 그때는 정답 버튼으로만 풀린다는 점을 설정 문구에 적는다).

### 3.3 가장자리 불빛 위치 바로잡기
- `GlowFrame` 이 75% 상수(x 240~1680)에 그려 **실제 영상 가장자리보다 133px 안쪽**에 나온다 → 영상 사각형(`camera_label.geometry()`) 기준으로 바꾼다. 번짐(안쪽 60px) 대신 **선명한 테두리만**(그리는 양이 줄어든다).

## 6. 지금 코드의 어긋남(함께 고친다)
1. **영상 칸 비율** — 오버레이 75% 상수 ↔ 실제 4:3 영상 칸. 불빛 · 상태 막대 · 버튼 위치를 영상 사각형 기준으로(§3.3).
2. ~~ESC = 창 닫기~~ — **어긋남 아님(10/14 정정)**. ESC 는 이미 열린 시트 · 로그 · 안내부터 닫는다(`safety_console.py:1830`). 10/13 캡처 때 창이 닫힌 것은 캡처 스크립트가 ESC 를 **두 번** 눌렀기 때문(첫 번째 = 시트 닫기 · 두 번째 = 창 닫기). 새 확인 상자(§4.6)도 시트 목록에 넣어 같은 길로 닫힌다.

## 7. 성능 관문
- **방법**: 같은 녹화를 가짜 카메라(`test/fake_camera.py --unorient`)로 흘려 수정 전 · 후 각 60초 × 3번 — 로그의 `[FPS]` 중앙값 비교 · 처리 설정 4(`SOP_INFER_MODEL=1`) · 측정 기록 끔.
- **기준**: 처리 FPS 감소 **3% 이내**(전환 애니메이션 판정 10% 보다 엄격 · 사용자 「성능이 제일 중요」). 넘으면 그 부품을 되돌리거나 그리기 횟수를 줄인다.
- **추가 관찰**: 경고 · 차단 · 메뉴를 연 상태 각 20초의 FPS · CPU 사용률(`top`)도 남긴다.
