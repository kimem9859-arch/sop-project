- ~~한 절씩: 조사 → 작성 → 대화로 짧게 요약 → 사용자 확인 → 다음 절.~~ → **2026-09-15 변경(사용자): `/goal` 루프로 전 절 초안을 수집**한 뒤 **끝에 전체 요약 보고 → 사용자 검토·확정.** 루프 중 절 결과는 확정이 아니다. 완료는 별도 판정 모델이 체크리스트(계획서 「/goal 완료 조건」)로 판정한다. 대안 비교(ralph-loop·`/loop`·`/deep-research`·워크플로)는 이 결정 때 대화에서 했다 — `/goal` = 완료 판정이 작업자와 독립.
