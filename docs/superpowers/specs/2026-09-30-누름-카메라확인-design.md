> 상태: 🛑 중단(2026-10-01) — 실물 확인(plan Task 6) 전 사용자 중단 「작업 중단 하자 작업 마무리 해줘」 · 설계 승인(2026-09-30 「설계서를 써줘」 · 계획·구현 「진행」) · Task 0~5 완료(구현·관문·최종 리뷰 반영) · 재개 = 통합문서 §12 🔓 「누름 카메라 확인」 행
> 근거 = 2026-09-30 실HW 확인(세션 `1328ae7c`) — 카메라가 콘솔을 보지 않는데도 맞는 버튼만 누르면 끝까지 진행됐다. 로그 `Rpi5/Demo/logs/20260930_162924_log.txt` 의 누름 14번 모두 직전 5초 안에 그 버튼 손 관측 줄이 없다(로그는 관측이 바뀔 때만 적어 과소일 수 있다).

## 1. 목적과 결정

**목적** — 지금은 카메라가 딴 곳을 봐도 맞는 버튼만 누르면 시연이 끝까지 간다. 비전 AI 가 확인하지 못한 누름을 **드러내고 센다.** EMO 선이 빠지면 차단하듯 「확인하지 못한 것은 확인하지 못했다고 말한다」는 같은 원칙이다.

**사용자 원문**
- 「작업을 시작하고(작업 버튼을 누른 후) 카메라가 버튼과 손을 보지 않는 상태에서는 작업이 안되어야 할 것 같은데 너 생각은 어떄? 하지만 키보드 입력 진행은 강행 진행으로 해줘」
- (못 봤을 때 반응) 「다음 단계로 진행은 하나 다음 단계 시작 전 안내를 띄우는 방식으로 진행하자」
- (안내 방식) 「안내만, 바로 이어짐」

| 결정 | 내용 | 누가 |
| --- | --- | --- |
| D1 | **판정 규칙은 바꾸지 않는다** — 맞는 버튼이면 카메라가 못 봤어도 단계가 진행된다. 오답 = 지금처럼 즉시 차단 · EMO = 지금 그대로 | 사용자(「진행은 하나」) |
| D2 | ⛔ 2026-10-07 사용자 변경 → **누른 뒤 +0.5초까지의 프레임이 처리되는 즉시 안내**(「못 보고 누른 그 순간 바로」 · 처리된 프레임 기준 · 집계는 단계가 끝날 때 그대로 · 통합문서 §8.2). 아래는 처음 결정: 못 본 누름은 **다음 단계가 시작될 때 안내**한다 — 화면 가운데 안내 박스를 몇 초 띄웠다가 **저절로 닫는다.** 확인 버튼 없음 · 다음 단계는 바로 시작 | 사용자(「안내만, 바로 이어짐」) |
| D3 | **결과창에 「카메라 미확인 N건」** — 「완주 성공」 판정에는 넣지 않는다(위반이 아니다) | 설계 승인 |
| D4 | **키보드 입력은 확인을 건너뛴다(강행)** — 로그에만 남긴다 | 사용자 |
| D5 | 확인 기준 = 누르기 전 **2.0초** 안에 손이 **그 버튼 구역(링 또는 박스 안)** 에서 한 번이라도 관측 — **잠정값**, 실HW 확인에서 조정 | 설계 승인(값은 잠정) |
| D6 | 음성비서 · 측정 도구 · 판정기 상태 전이는 바꾸지 않는다 | 설계 승인 |

**버린 대안**
- 판정기 안에 「미확인 누름」 상태를 새로 두는 방식 — 서브 작업이 있는 단계는 화면이 누름을 먼저 받고 판정기에는 서브가 끝난 뒤 전달된다(`safety_console._press_button` → 10초 뒤 `_commit_button`). 판정기 전이를 건드리면 측정 도구(🛑 정합 대기)도 같이 바뀐다.
- 못 본 누름을 막기(진행 안 함) · 경고 · 차단 — 사용자가 「진행은 하나」로 정했다.
- 기존 알림(`_notify`)만 쓰기 — 종 아이콘 뒤 목록에 쌓일 뿐 화면에 뜨지 않는다(배지 숫자만 는다). 「안내를 띄운다」가 되지 않는다.

## 2. 확인 기준

| 항목 | 값 · 규칙 |
| --- | --- |
| 무엇을 봤나 | 카메라 처리 결과 `roi_signal`(손이 들어와 있는 버튼 구역) 이 **누른 버튼과 같다** — 구역 단계는 링(접근)·박스 안 둘 다 인정 |
| 시간 범위 | **누른 시각 − 2.0초 ~ 누른 시각 + 0.5초** 안에 한 번이라도. 뒤쪽 0.5초 = 카메라 처리 지연(누른 순간 이미 받은 프레임이 아직 처리 중일 수 있다) |
| 시계 | 둘 다 `time.monotonic()` — 관측 시각은 이미 「카메라가 프레임을 다 받은 시각」(C16)이다. 누른 시각도 같은 시계로 찍는다 |
| 관측 기록 | **실제 관측만** — 갭메우기로 유지한 값은 넣지 않는다(「본 것」만 확인으로 인정) |
| 판정 시점 | 그 단계가 **끝나는 순간**(= 다음 단계 시작 · 서브 작업 단계는 약 10초 뒤라 뒤쪽 0.5초가 늘 채워진다). 서브 작업이 없는 단계는 누르는 즉시 끝나므로 그때까지의 관측으로 판정한다 — 지금 레시피에서는 마지막 B4 뿐이다 |
| 설정 | `config.PRESS_CONFIRM_WINDOW_SEC = 2.0` · `PRESS_CONFIRM_GRACE_SEC = 0.5` · `PRESS_CONFIRM_NOTICE_SEC = 4.0` · 창 0 = 확인 끔 |

## 3. 적용 범위

| 누름 | 확인 |
| --- | --- |
| GPIO 로 누른 **맞는 버튼** — 그 단계를 인정받는 누름(서브 작업을 시작한 누름 · 서브 없는 단계는 바로 끝낸 누름) | ✅ 확인한다 |
| 경고 중 맞는 버튼(2026-09-25 규칙 변경 ① — 경고 해제 + 평소대로) | ✅ 같다 |
| 서브 진행 중 같은 버튼 재입력(무시) · 경고로 멈춘 서브를 잇는 재입력 | ❌ 새로 확인하지 않는다 — 처음 누름의 확인을 쓴다 |
| 오답 · EMO | ❌ 지금처럼(즉시 차단) |
| 키보드 입력(1~4) | ❌ 건너뜀 — 로그 「[시험] 키보드 B2 — 카메라 확인 생략」 |
| 누른 단계가 차단(취소) · 작업 초기화 · EMO 로 끝나지 못함 | 그 확인 기록을 버린다 — 다시 누를 때 새로 확인 |

## 4. 안내 · 기록

| 자리 | 내용 |
| --- | --- |
| 화면 안내 박스 | 경고·차단 박스와 **같은 자리·크기**(화면 가운데 · 사용자 결정 2026-09-25). 제목 「카메라가 B2 누름을 확인하지 못했습니다」 · 둘째 줄 「다음 버튼은 보면서 누르세요」 · 해제 버튼 없음 · **4초 뒤 저절로 닫힘** · 색은 경고·차단과 구별되는 안내색 |
| 우선순위 | 차단 > 순서 경고 > 공구 경고 > **안내**. 안내가 떠 있는 동안 경고·차단이 나면 그쪽으로 바뀌고, 안내는 다시 뜨지 않는다 |
| 알림 목록 | 같은 내용을 알림 목록(종)에도 남긴다 — 박스가 닫힌 뒤에도 볼 수 있게 |
| 로그 | 판정 때마다 한 줄 — 미확인 「[확인] B2 누름 — 카메라 미확인(누르기 전 2.0초 손 관측 없음)」 · 확인 「[확인] B2 누름 — 카메라 확인(누르기 0.6초 전 관측)」. 🔑 확인 쪽도 적는다 — 2.0초 잠정값을 조정할 근거가 된다 |
| 결과창 | 새 칸 「카메라 미확인 N건」 · 줄 「1. 18:05:31 — 2단계 B2」 · 없으면 「없음」 |
| 마지막 단계(B4) | 다음 단계가 없어 안내 박스는 띄우지 않고 결과창에만 남긴다 |

## 5. 코드 배치

| 파일 | 바뀌는 것 |

## 6. 시험

**자가 테스트(실패 먼저)**
1. 판정기 — 관측 기록·조회: 범위 안/밖 · 다른 버튼 · 30초 지난 기록은 버림 · 갭메우기 유지값은 기록 안 함.
2. 콘솔 — GPIO 누름 · 관측 없음 → 단계가 끝날 때 안내 박스·알림·로그·집계 / 관측 있음(링·박스 안 각각) → 안내 없음, 「카메라 확인」 로그 / 키보드 → 안내 없음, 「확인 생략」 로그 / 누른 뒤 0.5초 안의 관측도 인정 / 차단으로 취소 → 기억 버림 / 마지막 단계 → 결과창에만 / 안내 중 경고 → 경고가 이김 / 4초 뒤 닫힘.
3. 기존 자가 테스트 전체 통과(`run_all.py`).

**실물 확인(콘솔 앞 · 공동)**
- 카메라로 버튼을 보면서 누르기 → 안내 없음 · 로그 「카메라 확인(n초 전)」.
- 카메라를 돌리고 누르기 → 다음 단계 시작 때 안내 박스 4초 · 결과창 「카메라 미확인 N건」.
- 키보드로 진행 → 안내 없음.
- 🔑 로그의 「n초 전」 분포로 2.0초가 맞는지 본다 — 보면서 눌렀는데 미확인이 자주 나오면 값 또는 기준을 다시 정한다(사용자와).
- 같은 실행에서 Rpi5 `98efd41` 최종 리뷰 반영분(작업 초기화로 켤 때 차단을 벗어난 뒤 EMO = 「비상정지」 · 알림 제목 「EMO 신호 없음」)도 본다.

## 7. 되돌리기

- 설정 `PRESS_CONFIRM_WINDOW_SEC = 0` → 확인·안내·집계가 모두 꺼지고 지금과 같다.
- 코드는 커밋 단위로 되돌린다.
