# 옛 세기(계산) 도구 정리 — 버릴 것은 백업 폴더, 가져갈 함수는 한 곳

> 2026-10-09 · 세션 `974c36cf` · **상태 = ✅ 사용자 승인(「이대로 진행」 · 10/8 폴더 「옮겨서 보존」) · 실행함** — 관문 ①~④ 결과는 작업로그
> 요청(사용자 원문) — 「세기 계획을 지금 미리 하자 단 진행 전 정리 먼저 했으면 해 이전 측정 도구 정리와 같이 옛 세기 도구에 대해서 버릴것과 가지고 갈것을 분류하여 별도 폴더 안에 넣어줘」 · 「가져갈 것에 대해서는 함수에 대해서 자세히 파악해서 측정 결과 데이터을 계산하는 방법에 맞는 함수인지 잘 확인해줘」
> 앞선 정리 = `specs/2026-10-07-도구정리-design.md`(백업 8개 · `Rpi5/백업/도구-20261007/`) — 그때는 옛 데이터 전용 도구를 「1단계-나(세기) 전까지 근사로도 쓴다」는 이유로 옮기지 않았다(§3). 이번에 세기를 만들기 직전이라 그 이유가 끝난다.
> 🔴 측정 수치는 쓰지 않는다 — 도구가 무엇을 세는지와 쓰임만.

## 2. 범위 — 옛 세기 도구

파이 전체(Rpi5 · sop-project `dev/` · `~/lab/` · `~/data/`)에서 기록을 읽어 수치를 내는 도구 약 90개 가운데 **새 세기가 대신하는 것**만 다룬다.

- ① `Rpi5/Demo/test/` 의 측정값 계산 도구 — 이 설계의 대상.
- ② 시연 기록을 읽어 센 일회성 스크립트 — `Rpi5/조사/` 는 그 조사 기록의 근거라 그대로 · git 밖 `~/lab/시연확인-20261008/` 만 저장소로 옮긴다(§4).
- 🔴 **음성과 모델은 측정 대상이다** — 아래 둘은 「측정에서 뺐다」가 아니라 「세는 도구가 세기로 바뀌지 않는다」는 뜻이다.
  - **음성 V1~V10**(설계 D12 — 9/27 D2 「음성 제외」를 10/7 에 뒤집었다) — 새 세기가 `voice_events.csv`·`events.csv`·대본으로 센다 · §4.1 목표 = V1 알림 지연. 이 값을 세던 옛 도구는 거의 없었다(데몬 로그를 사람이 읽음 · V9 일회용 수신 `조사/실콘솔-20261006/측정스크립트/drain_B.py` · 10/8 `demo_log_eval.py` 의 알림 지연) — 앞의 둘은 조사 기록이라 그대로, 뒤의 것은 §4 로 보존. 음성 쪽 나머지 도구(`voice/eval_questions.py` 질문 세트 평가 · `llm_gate.py` 프롬프트 관문 · `gate_check.sh` 촬영 직전 관문 · `~/lab/tts`·`voice-capture` 호출어 시험 · `dev/llm_bench`·`dev/tts`)는 세션 값을 세는 도구가 아니라 시험·관문이라 그대로 둔다.
  - **모델 9 · 10ⓐ · 11** — 9 는 §4.1 목표(버튼 mAP50)다. 시연 기록이 아니라 **정답 라벨 사진으로 채점**한다(설계 D4 · 비전 모델 재정립 ③) → 채점 도구(`score_*` · `학습/scoring.py` · `b3emo_score` · `조사/c001채점` 등)는 세기로 바뀌지 않고 그대로 쓴다. 같은 「인식」 무리라도 10ⓑ · 17 · 29 는 시연 기록으로 세기가 센다.

| `~/lab` 의 다른 스크립트(음성 · 공구 조사)도 옮기기 | 이번 범위(세기가 대신하는 것) 밖 |

## 8. 범위 밖

- 세기 자체(1단계-나) — 이 정리 뒤 계획서로.
- 음성 시험·관문 도구 · 모델 채점 도구(§2 — 측정 대상에서 뺀 것이 아니다) · 데이터 폴더 · 조사 스크립트 수정.
- 세기 계획에서 정리할 설계 어긋남 2건 — ①11(공구 검출)이 측정 설계 §4.3 「세기」 표에는 있는데 같은 절의 1단계 범위와 「9 · 10ⓐ · 11 은 모델 채점」 줄에는 빠져 있다 ②V6·V7 의 「지금 도구」가 측정 설계(`LLM관문.md` 절차 · 데몬 로그)와 도구목록 §0.2(`eval_questions` · `llm_gate`)에서 다르다.
