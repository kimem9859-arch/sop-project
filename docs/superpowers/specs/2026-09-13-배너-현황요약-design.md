## 1. 배경

| 증거 | 문제 |
|---|---|
| 사용자: 「현재 배너는 작업 내용을 넣어, 작업이 쌓이면 지저분해진다」 | 화면이 **목록**이라 ⏸ 가 늘면 같이 늘어난다. 사용자는 배너를 보지 않게 됐다 |
| 09-13 19:34:24·25 세션 시작 훅 2회 실행(`scan.log` scanned + skipped-lock) | 두 실행이 고정 임시 파일 `.claude/.startup-sync.tmp` 를 함께 비우고·쓰고·지운다 → 🔄 행 중복·누락 |
| 이 세션 기록에 `SessionStart:startup`·`resume`·`fork` 3회 | 훅은 시작·재개·분기마다 돈다 — 중복 실행은 정상 동작이고 막을 수 없다 |

## 2. 목표

사용자가 **세션 시작 때 화면 배너만 보고 프로젝트 현황을 한눈에** 파악한다. 기존 목록형 배너는 화면에서 없애고 **Claude 입력(`additionalContext`)으로만** 쓴다.

## 3. 결정

### 3.1 화면(`systemMessage`) = 현황 요약 최대 4줄

공식 문서(`code.claude.com/docs/en/hooks.md`): SessionStart 의 `systemMessage` 는 transcript 에 사용자에게 보이고, **여러 줄을 지원한다**.

```
🚀 SOP 가디언 · 2차 평가 D-41 (10-24)
📅 09-13 기록 · ⏸ 대기 7 · 🔴 인터락 결선 미복구
▶ 다음 인터락 NO 개정 실행
⚠️ Rpi5 로컬변경
```

| 줄 | 원천 | 규칙 |
|---|---|---|
| 1 | `$PROJ/../hanium-docs/CLAUDE.md` 일정표(`\| 이름 \| YYYY-MM-DD… \|`) | 오늘 이후(당일 포함) 첫 마감의 이름·D-day·`MM-DD`. 파일·표가 없으면 `🚀 SOP 가디언` 만 |
| 2 | 작업로그 최신 블록 | 블록 날짜 `MM-DD` · ⏸ 줄 수 · 🔴 가 붙은 ⏸ 의 제목(첫 ` — ` 앞, `**` 제거). 여럿이면 첫 제목 + ` 외 N`. 🔴 없으면 생략 |
| 3 | 같은 블록 ▶ | `①` 항목만(`②` 앞까지). 번호가 없으면 값 전체. ▶ 없으면 줄 생략 |
| 4 | 동기화 행 · 미기재 세션 행 | **조건부** — sop-project 는 `behind N` 만(커밋 안 한 변경·안 올린 커밋은 상태표시줄이 이미 보여 준다), 다른 저장소는 `동기화됨` 이 아니면 상태 전체, `미기재 세션 N`. 해당 없으면 줄 없음. ` · ` 로 잇는다 |

- 긴 제목·항목은 **글자 단위 30자**에서 자르고 `…`(바이트 단위 자르기는 한글을 깬다 — CC작업문서 함정).
- **공백은 한 칸** — 연속 공백을 만들지 않는다(사용자 지정).

### 3.2 Claude 입력(`additionalContext`) = 기존 전체 행 그대로

동기화 · 📌 출처 · ⏸·▶ 전체 · 📭 미기재 세션 · 🆔. 변경 없음.

### 3.3 조립 위치 = `_banner.py`

`_banner.py` 가 이미 받는 T/R/N 행에서 요약을 뽑는다. 새 입력은 `H<TAB>마감표 경로` 한 줄뿐. 오늘 날짜는 환경변수 `BANNER_TODAY`(시험용)가 있으면 그것, 없으면 시스템 날짜. → 쉘 스크립트 변경 최소, 시험은 입력만 바꿔 한다.

### 3.4 경합 수정 = 실행마다 개인 임시 파일

`session-worklog-brief.sh` 가 `mktemp` 로 만든 경로를 `session-sync-check.sh` 의 첫 인자로 넘기고 `trap` 으로 지운다. 인자가 없으면 sync-check 는 종전 고정 경로를 쓴다(단독 실행 호환) — 그러므로 `.gitignore` 의 `.claude/.startup-sync.tmp` 줄은 **남긴다**(계획 작성 중 자기검토로 정정 — 대화 설계는 삭제였다). 잠금은 버렸다 — 두 번째 실행의 배너가 비거나 기다려야 한다.
