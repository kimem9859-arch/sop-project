# 규칙 표면 전면 재작성 — 설계

> 사용자 요청(2026-09-20): **"기존 규칙과 지시사항을 버리는 것이 아닌 분류·제거·수정·보완하여 다시 작성한다."**
> 기준은 **Claude Code 공식 문서**(`code.claude.com/docs/en/memory.md`)와 **이 프로젝트의 기존 규칙**(통합문서 R1~R12 · CC작업문서 §3.0) 둘 다이다.
> 🔴 **이 설계 자체가 재작성 대상인 규칙을 판단 도구로 썼다** — 그 순환을 끊는 규율이 §5 다. 읽는 순서는 §5 를 먼저 본다.

## 1. 무엇을·왜

규칙이 11곳에 흩어져 자라면서 세 가지가 동시에 났다.

- **낡음** — 정본 구조재편(§10→§12)이 통합문서 안 1,149곳은 치환했으나 **문서 바깥**(CLAUDE.md·memory)은 빠졌다. 낡은 참조 16건.
- **저널화** — 규칙 문서에 작업 경위(날짜·커밋 해시·spec/plan 경로)가 섞였다. CLAUDE.md 가 2026-07-30 에 걷어낸 병이 **CC작업문서 §1 에서 재발**했다.
- **도달 불일치** — 규칙이 **필요한 곳에 안 가고**, 필요 없는 곳에 간다. auto memory 는 머신 로컬이라 데스크톱 전용 규칙 5건이 파이1에만 있고, 파이1 전용 함정은 데스크톱에도 전부 로드된다.

세 번째가 근본이다. **「무엇을 쓰나」는 대체로 맞았고 「어디에 두나」가 틀렸다.**

## 3. 판정 기준

### 3.1 공식 문서에서 (확인 원문)

- CLAUDE.md 계층 — managed policy → **user(`~/.claude/`)** → **project(`./`)** → **local(`./CLAUDE.local.md`, gitignore)**. 하위 디렉터리 CLAUDE.md 는 **그 폴더 파일을 읽을 때만** 로드.
- `.claude/rules/` — `paths:` 없으면 매 세션, **있으면 매칭 파일을 읽을 때만**. 머신 기준 스코프는 **지원하지 않는다.**
- auto memory — 4타입(`user`/`feedback`/`project`/`reference`)은 공식 규격. **머신 로컬이며 머신 간 공유되지 않는다.**
- 🔴 **중복 금지** — *"It also skips anything your CLAUDE.md files already say."*
- 🔴 **파생 금지** — *"Claude skips anything it can derive from the codebase."*
- 🔴 **강제 아님** — *"context, not enforced configuration. To block an action … use a PreToolUse hook."*
- 권장 크기 **200줄 미만**.
- 작업별 지시는 rules 가 아니라 **skill** 로(rules 는 항상 또는 매칭 시 로드).

### 3.2 이 프로젝트 규칙에서

- **R2** 폐기는 **옮긴다** — `변경이력.md` 로. *"옮기지 않고 그냥 지우지 않는다."* ← 사용자 요구 「버리지 않는다」와 같은 말이다.
- **R5** 사실은 한 곳에만. **R9** 경위는 본문이 아니라 커밋·작업로그에.
- **CC작업문서 §3.0** 훅 제1원칙 — *"보험이 지급된 실적을 먼저 측정하라. 실적 0이면 만들지 마라."*
- **CLAUDE.md §3** 작업 기록·현황·수치를 규칙 문서에 쓰지 않는다.

## 4. 방법 — 보존 원장

「버리지 않는다」를 말이 아니라 **구조로** 보장한다.

1. **원자화** — 대상 1~11 을 «규칙 한 개 = 원장 한 행»으로 쪼개고 고유 번호를 준다(예: `루트-§5-측정-03`).
2. **판정** — 행마다 6종 중 하나 + 행선지를 적는다.
3. **집행** — 새 자리에 쓰거나, `변경이력.md` 로 옮긴다. **어느 쪽도 아닌 행은 허용하지 않는다.**
4. **대조** — 원장의 모든 행이 둘 중 하나에 있음을 기계적으로 확인한다.

원장은 `docs/superpowers/plans/2026-09-20-규칙표면-원장.md` 에 두고 작업이 끝나도 남긴다(전례 = `docs/미기록작업-점검-20260911.md`).

### 5.3 충돌은 **건별로 사용자에게 올린다** (사용자 결정 — 일반 규칙을 세우지 않는다)

## 6. 관문 (계획서에 박는다)

- 🔴 **누락 0** — 원장의 모든 행이 「새 자리」 또는 「변경이력.md」에 있다. **하나라도 행방불명이면 중단.**
- 🔴 **참조 무결** — 재작성 뒤 문서 간 `§`·경로 참조가 전부 실재한다. **재작성이 새 drift 를 만들면 실패.**
- 🔴 **도달 검증** — 단계마다 `/context` 로 실제 로드 목록을 확인한다. 설계한 도달과 다르면 배치가 틀린 것이다.
- 🔴 **§3.0 실적 관문(hookify 전용)** — 규칙을 만들기 전에 「그 규칙이 없어서 실제로 잃은 것」을 먼저 제시한다. **실적을 못 대면 만들지 않는다.**

### 중단 규칙

원자화 결과 **판정이 「유지」인 행이 8할을 넘으면**, 문제는 내용이 아니라 배치뿐이다 → 재작성을 **이동·수정에 한정**하고 전면 재작성은 폐기한다. 고쳐 쓸 이유가 없는 것을 고쳐 쓰는 것이 이 작업의 가장 큰 위험이다.

🔴 **이 8할은 기준별로 따로 집계한다** — 공식 문서로 판정한 것과 프로젝트 규칙으로 판정한 것을 섞으면 의미가 없다. **규칙을 그 규칙 자신으로 판정하면 「유지」가 많이 나오기 때문이다**(§5.2). 두 집계가 크게 어긋나면 그 자체가 신호이므로 사용자에게 보고한다.

## 8. 목표 구조 — **원자화 결과로 도출한다** (사용자 결정)

구조를 미리 못 박지 않는다. B 단계 원자화가 **실제 분포**(전 머신 / 파이1 / 데스크톱, 매 세션 / 작업별)를 내놓은 뒤 그 분포에 맞춰 정하고, 사용자 승인을 받는다.

후보는 셋이며 배타적이지 않다.

- **작업 종류로 나누기** — 전 머신 공통 → `CLAUDE.md` / Rpi5 코드 → `.claude/rules/` + `paths:` / 촬영·측정, 제출문서 → `.claude/skills/`. 머신 분리와 memory 도달이 동시에 풀리고 공식 메커니즘만 쓴다.
- **머신 태그** — 절 제목에 `[파이1]`/`[데스크톱]`/`[전 머신]`. 경로·작업으로 안 잡히는 것에 쓴다.
- **`CLAUDE.local.md`** — 머신 전용. git 밖이라 **잃어도 되는 것**(경로·개인 환경)에만.

🔴 **결정 관문** — 구조를 고른 근거는 원장의 분포 수치로 제시한다. "그래 보인다"로 정하지 않는다.

## 10. 버린 대안

- **git 으로 머신별 배포 차단**(sparse-checkout·브랜치 분리·규칙 전용 repo) — git 은 브랜치 단위 전부/전무다. sparse-checkout 은 머신 로컬 설정이라 "규칙으로 강제"가 되지 않고 조용히 원복된다. 브랜치 분리는 정본 동기화를 깬다.
- **auto memory 디렉터리를 저장소로**(`autoMemoryDirectory`) — 머신 간 공유는 되나, Claude 가 자동으로 쓰는 디렉터리가 정본 저장소에 들어와 단일정본 체계와 충돌하고, **공모전 제출 저장소라 개인정보 금지 관문에 29개가 새로 걸린다.**
- **전역 `~/.claude/CLAUDE.md` 신설** — 머신 로컬이라 파이1에만 생긴다. 양 머신 일관성이라는 목적을 달성하지 못한다.
- **`hanium-docs/CLAUDE.md` 를 라우터로** — 데스크톱 cwd 가 `sop-project` 라 애초에 로드되지 않는다. 전제가 틀렸다.
- **요약 문서 1장**(`docs/데스크톱-작업규칙.md`) — 정본이 둘이 된다. R3 이 금지한 사본 패턴.

### 12.4 2층 — 원본 대조 (사람이 판정 · **A안**)

**입력** = ⑦의 `행방불명` **전수** + `이사함` **30% 표본** + ⑨가 지적한 곳.

원문과 새 글을 나란히 놓고 **세 가지만** 묻는다.

| 질문 | 대응하는 실물 |
| --- | --- |
| ① 조건이 빠졌나 | `R-06` 조건 증발 |
| ② 수치·예외가 바뀌었나 | 「헤딩 네 모양」 → 실제 여섯 |
| ③ 뜻이 약해졌나 | 금지 → 권장 |

- 🔴 **원문으로 판정한다. 요약으로 판정하지 않는다** — 요약만 보고 충돌 판정을 냈다가 철회한 일이 있다(원장 §13.2).
- 🔴 **규칙만이 아니라 「사실」의 소실도 본다** — ⑥⑦이 못 가른 것은 여기서 가른다.
- **표본을 고른 이유(버린 대안)** — `이사함` 전수(290줄)는 값을 못 한다고 판단했다. ⑨가 한 겹 받친다. `행방불명`만 보는 안은 **`R-06` 유형을 구조적으로 놓치므로** 기각했다.
