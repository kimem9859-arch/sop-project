## 2. 지금 상태 — 근거

- **대본** = `Demo/measure/시나리오/*.csv`(`판,행동,대상,기대,메모`) — 사람이 노트북(파이에 SSH)으로 읽으며 진행한다. 메모 문장이 판마다 「1단계 차례 · 대기 중 · 대기 끝나 2단계 차례 · 렌치 내려놓고 1초 뒤」처럼 때를 달리 적는다.
- **NG** — 기록 어디에도 표시가 없다. 10/10 ②A 의 NG(10·11·16번째)는 이 세션에서 **누른 버튼 순서를 대본과 맞대어** 다시 찾았다(작업로그의 「한 칸 어긋남」은 실제로 12번째부터 두 칸 · 17번째부터 세 칸).
- **세기** `test/measure_count.py` 는 **실제 판 번호 = 대본 판 번호**로 가정한다(`normal_run_ids` · `v_wrong_tool` · `v_graze` 등) → NG 판이 하나만 섞여도 그 뒤가 전부 어긋난다.
- **소리 영향(진단)** — 폐기 ②A·②B 에서 안경 스피커가 알림을 받고·재생하던 구간 vs 그 밖: 카메라가 받은 FPS 차이 없음 · 처리 간격 +4~8ms · 받기→판정기 +3~11ms(같은 때 화면이 경고·차단 배너를 그려 이것이 상한). 안내 소리는 알림보다 훨씬 짧다 → 사용자 기준 「영향이 크면 다른 방식」에 걸리지 않는다.
- **알림** — V1(§4.1 목표)은 폐기 세션 알림 72건으로 판정이 분명하다(재생까지 중앙값이 목표의 약 2.8배 · 원인 = 소리 파일을 다 보낸 뒤 재생). 다시 재도 같은 구조라 판정이 바뀌지 않는다 → 내일은 알림을 끈다(D9).
- **TTS** — 파이1 은 kss(sherpa-onnx). 사용자 선택 = Supertonic 2 원본 · F1 · 4단계 · 빠르기 1.25(통합문서 🔓 「파이 TTS 교체」 · 저널 §12.94-(8)). 파이2 에 모델(256MB) · `supertonic 1.3.1` · `onnxruntime 1.31.0` · `numpy 2.5.3` 이 있다. 파이1 디스크 여유 약 0.7GB.

### 4.2 Ⓑ1 대본 `누름` 칸 — 문법

공백으로 나눈 낱말을 **그 줄에서 일어나는 차례대로** 적는다.

| 낱말 | 뜻 | NG 판정에 쓰나 |
| --- | --- | --- |
| `B2` | 기대 버튼이 B2 일 때 B2 를 누름(맞는 누름) | ✅ |
| `B3@B1` | 기대 버튼이 B1 일 때 B3 를 누름(위반 — 「1단계 차례」·「B1 대기 중」 모두 기대 = B1) | ✅ |
| `EMO` | 비상정지 누름 | ✅ |
| `~B4@B3` | 기대 = B3 일 때 B4 위에 **머묾**(누르지 않음) — 경고 해제 또는 4초 뒤 다음으로 | ❌ 안내만 |
| `#렌치` | 그 공구를 쥠 — B2 대기가 시작되면 안내 | ❌ 안내만 |
| 끝의 `?` | 그 낱말부터는 판이 먼저 끝나도 된다(③장갑 「안 되면 작업 초기화」) | — |

- 예(②A 1판) — `위반,B2` 줄 `B2@B1 B1` · `위반,B2` 줄 `B2@B1 B1` · `틀린공구` 줄 `B2 #플라이어`.
- 말하는 줄(호출 · 질문 · 비상질문)은 비운다 — 화면에 메모를 보이고, 다음 낱말이 오면 넘어간다.
- 모든 대본(장소1 ①~④ · 장소3 ①②)에 넣는다 — ①·④ 를 새 세기로 다시 셀 때도 쓴다(§6.3).

### 4.3 Ⓑ2 판 맞춤 — `Demo/measure_script.py`(순수 · 의존 없음)

- `parse_tokens(칸)` · `script_runs(대본 줄)` → 대본 판마다 낱말 목록.
- `Matcher` — 사건을 하나씩 받는다(`run_start` · `press` · `sub` · `release` · `state` · `run_end` · `run_reset` · 수동 NG). 판마다 결과 = `(실제 판 번호, 대본 판 번호 또는 None, 상태 ✅/NG/대본 밖, 이유)`. 무시할 누름(D4) · 다음 기대 낱말 · 「지금 안내할 낱말」(D8 조건)을 알려 준다.
- NG 판 다음 판 = 같은 대본 판 다시. 대본을 다 끝낸 뒤의 판 = 「대본 밖」(뺀다). 대본 없는 세션 = 수동 NG 만.

### 4.4 Ⓑ3 진행 도우미 — `Demo/measure_guide.py` · `Demo/run_guide.sh`

## 6. 관문

### 6.1 중단 규칙

1. Supertonic 설치 뒤 STT·kss import 실패나 numpy 충돌 → 설치를 되돌리고(전 `pip freeze` 로) 멈춘다 · 사용자에게 INT8(sherpa · 이미 설치) 대안 여부를 묻는다.
2. 파이1 에서 비전을 켠 채 60자 답 합성 > 2.0초 또는 합성 동안 처리 FPS 가 10% 넘게 떨어짐 → 멈추고 보고(갈래 = 사용자).
3. 시험 판에서 안내 재생 구간의 받기→판정기 지연이 그 밖보다 10% 넘게 크거나 카메라가 받은 FPS 가 떨어짐 → 멈추고 다른 안내 방식(화면만)을 사용자와 정한다(사용자 「영향이 크다면 다른 방식」).

### 6.2 🔒 홀드아웃

- **판 맞춤** — `누름` 칸과 `Matcher` 는 폐기 ②A 로만 맞춰 보고, **②B 폐기 기록은 마지막에 한 번** 돌린다. 기대 = NG 1번째(첫 위반 B2 · 대본 B3) · 4번째(머묾 대신 B4 누름)(10/10 작업로그). ②B 결과를 보고 규칙을 고치지 않는다 — 틀리면 원인을 적고 사용자와 정한다.
- **시연 프로그램 지문** — 시작 전 sha256 을 남긴다: `camera_thread.py` · `fsm.py` · `safety_console.py` · `interlock.py` · `gpio_input.py` · `hand_tracker.py` · `detector.py` · `roi_zones.py` · `frame_orient.py` · `tool_gate.py` · `sub_task.py` · `overlay*.py` · `state_publisher.py` · 펌웨어 2개. 끝에 같은지 대조. `config.py` 는 TTS 줄만 바뀐다(diff 로 확인).

### 6.3 검증

- 자가 테스트 전부 통과(새 시험: 낱말 문법 · Matcher 무시 규칙·NG·대본 밖 · 안내 조건 D8 · 세기 입력 거르기 · V1 짝짓기 · 음성비서 안내 경로 = 가짜 안경 · TTS 갈래 = tts venv).
- 폐기 ②A 재생 — NG = 6 · 10 · 11 · 16번째(6 = D4 엄격 규칙 · 대본에 없는 B4 한 번 더) · 맞춘 판 = 대본 1~9 → 실제 1~9 · 대본 10~14 → 실제 12 · 13 · 14 · 15 · 17.
- ①정상 `185933` · ④음성끔 `191404` 를 새 세기로 다시 세어 바뀐 값을 보고(빠진 판 · 이유).
- 진행 도우미를 폐기 ②A 기록을 **빨리 돌려 재생**하는 모드로 돌려 화면·안내 요청 순서를 확인(`--replay`).

### 6.4 실물 공동 확인(측정 전)

1. 안경으로 새 목소리 — 알림 문장(꺼 두지만 시연용) · 답 몇 개 · 안내 소리 전부 · 문구·빠르기 확정(사용자).
2. 시험 세션(실행기 세션 0)에서 ②A 1~2판 — 안내 소리 · 화면 · 자동 NG(일부러 한 번 틀리게) · 수동 NG · 부저 뺀 상태 · 알림 꺼짐.
3. 그 시험 세션 기록으로 중단 규칙 ②·③ 수치 확인.

## 8. 버린 대안

| 대안 | 버린 이유 |
| --- | --- |
| 시연 화면(콘솔 디스플레이) 안에 대본 표시 | 측정 대상 프로그램이 바뀐다(S6) · 화면 그리기가 FPS 에 끼어든다 |
| 대본을 행동 종류별 세션으로 다시 짜기 | 측정 설계 §4.2 의 때(작업 시작 직후 · 대기 중 · 대기 끝)를 섞어 재는 뜻이 줄어든다 · 추적 부담은 도우미가 덜어 준다 |
| 메모 문장에서 누름 순서를 자동으로 뽑기 | 문장이 판마다 달라 틀리기 쉽다 → 명시 칸(D2) |
| 안내 소리를 노트북·파이 모니터로 | 노트북은 SSH 만이라 소리 길이 없다 · 모니터 스피커는 확인 안 됨 · 안경은 이미 귀에 있다 |
| 대본에 없는 누름이 있어도 판을 살리기 | 판 맞춤이 어긋난다(D4) |
| 부저를 펌웨어 명령으로 끄기 | 아두이노를 다시 구워야 한다 → 선 하나 빼기(D9) |
| Supertonic 2 INT8(sherpa · 이미 설치) | 사용자 선택은 원본 4단계 1.25 · INT8 4단계는 재지 않았다 → 중단 규칙 ① 의 대안으로만 |
| 내일 V1 다시 재기 | 같은 구조라 판정이 바뀌지 않는다(D10) |

## 9. 되돌리기

- TTS — `config.TTS_ENGINE = "kss"` · 고정 wav = `voice/wav_kss/` 를 `voice/wav/` 로 · 패키지 = 전 `pip freeze` 기준 `pip uninstall supertonic onnxruntime`.
- 안내 소리 — 진행 도우미를 안 띄우면 요청이 없다(음성비서는 요청 파일이 없으면 아무것도 안 한다).
- 알림 · 부저 — 실행기 질문에 1 · 선을 다시 꽂는다.
- 세기 — 대본 `누름` 칸이 비면 판 맞춤을 건너뛰고 지금처럼 센다.
