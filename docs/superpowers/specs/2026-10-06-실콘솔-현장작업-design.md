## 1. 목적과 성공 기준

- **목적** — 실콘솔(버튼 B1~B4·EMO · 아두이노 인터락 · 타워램프)과 카메라 안경을 펼치는 **하루 한 번**에, 그것이 있어야만 할 수 있는 대기 작업을 빠뜨리지 않고 끝낸다.
- **성공 기준**
  1. 장소2·3 사진이 현장 장수 세기에서 모두 ✅(정본 = `capture_dataset.py` 의 `MIN_KEEP`).
  2. §2 「넣은 것」마다 결과가 **통과 / 미달 / 못 함(이유)** 중 하나로 남는다. 미달·못 함도 결과다.
  3. 통합 펌웨어(카메라 XGA·9ms + 마이크 + 스피커)가 도는지 · 성능이 지금 펌웨어와 비교해 어떤지가 **같은 날 같은 조건의 숫자**로 남고, 철수할 때 남길 펌웨어를 그 결과로 정한다(사용자).
  4. 결과 자료가 커밋되고, 공동 확인 뒤 `work-close` 로 정본에 들어간다.

## 3. 통합 펌웨어 (`Rpi5/arduino/glass_voice/glass_voice.ino` 수정)

- **무엇** — `camera_stream_tcp` 의 2026-09-22~23 카메라 변경을 옮긴다: ①해상도 XGA(1024×768) ②부팅 때 노출 상한 밴드 2(`0x3A0E=2` → 최대 약 9ms) ③부팅 센서 모델 기록 ④노출 기록(부팅 + 5초마다 · 읽기만).
- **안 옮기는 것** — 시리얼 진단 명령 `R:`·`W:`·`EXP:` ✋. `glass_voice` 는 같은 USB 시리얼로 음성 명령(`R`=녹음 · `W`=소리 적재)을 받아 글자가 겹친다. 노출 값은 이미 확정이다.
- `camera_stream_tcp` 는 그대로 둔다(촬영·처리 속도 A·되돌리기용).
- 굽기 = `arduino-cli upload -p <5E:58 포트> --fqbn esp32:esp32:XIAO_ESP32S3:PSRAM=opi arduino/glass_voice`(🔴 `PSRAM=opi` 빠뜨리면 부팅 루프).
- **되돌리기** = 오늘 백업 `~/lab/esp32-link/mainboard_full_20261006_104423.bin` 을 `--no-stub write-flash` → 파티션별 대조(RESTORE.md).
- **남길 펌웨어**(철수 전 · 사용자) — 기능·성능 통과면 통합 펌웨어(시연 정본 = 「글라스 한 장」 통합문서 §9) · 미달이면 백업으로 되돌린다.

## 4. 제약

- **🔴 촬영(A·B)과 처리 속도 A 는 지금 펌웨어로** — 장소1 사진과 같은 펌웨어여야 한다(촬영지시서 §1). 통합 펌웨어 굽기는 그 뒤.
- **음성** — C·D·E 는 `SOP_VOICE=0 SOP_VOICE_ALERTS=0`(지금 펌웨어에 마이크·스피커 통로가 없어 음성 데몬이 헛돈다) ✋. V 는 음성을 켠다(`run_demo.sh` 기본). E2 는 음성 데몬 없이 마이크 업링크만 따로 붙인다(펌웨어 부하만 보려고) ✋.
- **앰프·스피커는 아직 안경에 연결되지 않았다**(사용자 2026-10-06) — 현장에서 결선한다(§6 P 앞). 결선표 = `glass_voice.ino` 머리 주석 · 🔴 `SPK−`(OUT−)를 GND 에 대면 칩 파손(BTL) · 앰프 전원은 `3V3` 금지 · 여유 앰프가 없다(DFR0954 ×1). 안경은 파이 USB 급전 상태로 시험한다 ✋.
- **실HW 는 한 번에 하나** — 카메라(8888 손님 하나) · Hailo · GPIO · 아두이노 포트가 각 하나다.
- **🔴 CH5 는 펌웨어 먼저, 가닥은 나중 · 맨 끝** — 실패하면 버튼이 전부 죽어 V(버튼으로 경고·차단·해제)를 못 한다.
- **디스크** — 출발 전 9.0G(2026-10-06 조사 값).

| F — 가닥을 옮긴 뒤 정상에서 버튼이 안 옴 | 🛑 가닥을 브레드보드 GND 로 되돌리고 끝 |

### ② 🔒 홀드아웃

- **장소3 사진 = 시험 전용 봉인** — `~/data/capture_장소3/` 에만. 장수 세기 말고는 열지 않는다(학습·검증·초벌 모델·문턱 결정 금지).
