## 1. 목표

- **공통 기준** — 1단계 `기본.yaml`(공식 기본값 + 함정 고침)을 출발점으로 함수·값을 사용자가 확인한 결과(§3)를 `기본.yaml` 에 반영한다. 버튼·공구가 같은 공통 기준에서 출발한다.
- **버튼 기준** — 공구(E0c)와 같은 조건으로 버튼 기준을 시드 3회 다시 잡고, 버튼에만 있는 이유로 고른 후보(§5)를 하나씩 판정한다.
- **성공 기준** — ① 공통 기준의 값마다 출처(공식 기본 · 함정 고침 · 사용자 결정 · 환경)가 적혀 있다 ② 버튼 기준 3회와 후보별 판정이 **차이를 가릴 수 있는 평가**(§4)로 나온다 ③ 결론이 2단계(장소2·3)의 출발점으로 기록된다.

## 2. 범위

- **안** — `기본.yaml` 개정 · 버튼 평가 만들기(§4) · 버튼 기준 3회 · 버튼 후보 4개 × 3회 · 판정 · 기록.
- **밖** — 공구 재실험(공구는 1-2단계 결론 E0c 를 그대로 쓴다 — 공통 기준이 E0c 설정과 같다) · 장소2·3 · 입력 해상도 · HEF 변환(1-2단계 결론을 그대로 쓴다) · 시연 배치.
- **시기** — 1-2단계의 **학습**이 끝난 뒤(공통 기준을 1-2 학습 중간에 바꾸면 그 결과끼리 비교할 수 없다) — 사용자 「바꿔줘」 2026-10-05: 1-2 의 남은 일(변환·채점·리뷰·공동 확인)과 나란히 진행.

## 3. 공통 기준 — 1단계 기준에서 확인한 결과 (사용자 승인)

- **표 1 — 그대로** — 출발 `yolov8n.pt`(사용자) · 배경 10%(사용자) · 입력 640 늘리기(시연과 같게) · AdamW · lr0 0.001(함정① — `auto` 는 적은 lr0 무시) · momentum 0.9 ✋(auto 와 같게) · warmup_bias_lr 0(함정④) · warmup 3 · weight_decay 0.0005 · lrf 0.01 · 직선 · 손실 7.5/0.5/1.5 · 증강 공식 기본(hsv 0.015/0.7/0.4 · translate 0.1 · scale 0.5 · fliplr 0.5 · mosaic 1.0 · close_mosaic 10 · 회전·기울이기·원근·상하 0 · mixup·copy_paste 0) · batch 16 · seed · 재현 · 반정밀도 · workers 2 · cache disk(환경).
- **표 2 — 바꿈** — epochs **120 끝까지** · patience **끔** · 포화 멈춤 **끔**. 근거 = 함정⑤(학습률 감소·close_mosaic 이 epochs 에 묶임) · 저널 §12.87(일찍 멈춤 조건의 「0.0005 우세」 · 「768×1024 우세」는 끝까지 학습하면 사라짐).
- 결과 — 공통 기준 = 공구 E0c 설정과 같다. 이상 종료 장치(10 에폭 점수 0 · 15분 진행 없음 · 시간 2배)는 그대로.
- ⚠️ **환경이 1-2단계 중에 바뀌었다** — albumentations 2.0.8 설치(Task 10) → 학습이 증강 목록을 명시해 넘기고(빈 목록 = 기본 묶음 끔) 요약 「판」이 달라진다. 그래서 1-3 의 모든 비교는 **설치 뒤 같은 판**으로 다시 돈 기준끼리 한다(공구 E13 과 같은 이유).

## 4. 버튼 평가 — 차이를 가릴 수 있게 ✋

- **문제** — 지금 채점 292장은 세션마다 마지막 20% 프레임이다 → 학습 사진과 같은 장면이라 버튼이 천장(531개 중 놓침 0~2 · 잘못 찾음 1~4)이고 부풀려졌을 수 있다(저널 §12.84). 이대로는 버튼 설정을 가릴 수 없다.
- **방법** — 버튼만 있는 세션 하나를 **통째로 학습에서 뺀다**(학습·검증에 쓰지 않고 채점에만 = 「처음 보는 세션」). ✋ 세션 = `0923-185802`(버튼 사진 253장 · 상자 1,215개 = 버튼 상자 5,483개의 22% · 공구 없음 · 배경 세션 아님).
  - 버튼 전용 나눔 새 판(가칭 `place1_v2b`) — 그 세션을 버튼 학습·검증에서 빼고 「세션 보류 채점」으로 둔다. 나머지 나눔(세션 안 앞뒤 나누기 · 기존 채점 292장)은 그대로.
  - 공구는 나눔을 바꾸지 않는다(공구 상자는 전부 한 세션이라 세션을 뺄 수 없다).
- **판정** — 채택 판정 규칙(후보·기준 3회 · 어떤 지표에서 후보 최저 > 기준 최고 · 아래로 갈린 지표 없음)을 **세션 보류 채점**으로 한다. 기존 292장은 참고로 나란히 적는다.
- **지표** — 기존 채점 도구 그대로: 종류별 맞게 찾은 수(재현율) · 잘못 찾음 · 정밀도 · 혼동표(특히 **B3↔EMO**).
- **한계** — 장소1 의 다른 세션일 뿐이다(같은 날 · 같은 장소) → 장소2·3 만큼 다르지 않다. 그래도 「같은 장면」 부풀림은 걷어낸다.

## 5. 버튼 실험 (사용자 승인 표 3 · 한 번에 하나만 바꾼다)

| 이름 | 바꾸는 것 | 이유(버튼 상황) | 값 |
|---|---|---|---|
| B0 기준 | 없음(공통 기준) | — | 표 1+2 |
| B1 색 | hsv_h · hsv_s | 버튼은 색이 곧 종류(B3 분홍 ↔ EMO 빨강) — 기본은 색상 ±5° · 채도 0.3~1.7배를 흔든다 | ✋ hsv_h 0 · hsv_s 0.3(1단계 E2 와 같은 값) |
| B2 좌우 | fliplr | 라벨링 가이드 「B3 ↔ EMO 는 자리로 구분」 — 뒤집은 사진은 실제 콘솔에 없는 좌우 배치(추론) | 0 |
| B3 가림 | cutmix | 누를 때 손이 버튼을 가린다(§12.67) | 0.3(공구 Task 9 와 같은 값 · 공구는 기각) |
| B4 흐림 | 흐림(albumentations) | 1인칭 흔들림 | Blur · MotionBlur p 0.1(공구 Task 10 과 같은 값) |

- 각 3회(시드 0·1·2) → 15회 · 1회 약 12~13분 · 2개 동시 → 약 1.5시간.
- 채택된 후보가 둘 이상이면 하나로 합친 설정을 한 번 더 3회(합쳐도 유지되는지) ✋.
- 하나도 없으면 새 버튼 기준 = B0.
