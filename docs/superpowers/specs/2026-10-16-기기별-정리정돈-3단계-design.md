드라이브는 노트북의 `G:`(구글 드라이브 데스크톱 앱)로 다룬다 — 내 소유 파일을 지우면 드라이브 휴지통으로, 팀원 소유 파일을 지우면 내 폴더에서 빠진다(실행 전 시험 파일 1개로 두 동작을 확인).

## 7. 지키는 규칙

1. **지우기는 데스크톱 받은 쪽 지문이 모두 같고 홀드아웃(도구가 쓰지 않은 지문 · 받은 자리 `md5sum` 표본)이 같을 때만**(2단계 도구 · 관문 그대로).
2. 라벨링 사본은 **3.1 관문(사용자 확인)** 뒤에만 지운다.
3. 「이미 있음」 = 크기 · md5 같음(휴지통 · 캐시 · 학습 바탕 · `.claude` · `.git` 자리는 사본으로 치지 않음).
4. 가상환경(`venv*` · `.venv`)은 옮기지 않는다(패키지 목록만).
5. 데스크톱 안 옮김은 같은 파일 시스템 안 이름 바꾸기(내용 복사 없음) · 하드 링크 — 옮기기 전 · 뒤 데스크톱 전체 내용 지문 집합이 줄지 않음을 확인(의도한 지움만 빠짐).
6. 런타임 · 가상환경 · 설정이 부르는 자리는 옮기지 않는다 — 옮기기 전 「무는 곳 찾기」(데스크톱 학습 도구 `Rpi5/학습` 의 데스크톱 자리 · Hailo 가상환경 · `.bashrc`).
7. 커밋 문서 · 지도에는 개인 이름 · 학교 · 학과 · 팀원 이름 · 이메일을 쓰지 않는다.

## 8. 검증

- 묶음마다 지문 대조 다름 0 → 🔒 홀드아웃 다름 0 → 그때만 노트북 · 드라이브 원래 자리를 지움.
- 🔒 내용 보존 — 3단계 전 「데스크톱 + 노트북 + 드라이브」 프로젝트 파일 지문 집합 ⊆ 3단계 뒤 데스크톱 지문 집합 + 의도한 지움 목록(파이 원본 사본 · 2차 검토판이 있는 팀원 검토판 · 사용자가 확인 폴더에서 뺀 것) — 다름 0.
- 데스크톱 기준(학습 가상환경 · Hailo import · `학습.py 이름표` · 여유 공간)이 전 · 뒤 같음.
- 노트북 · 드라이브에 「손대지 않음」 밖 프로젝트 파일이 남지 않음(뒤 목록).

## 9. 되돌리기

- 노트북 묶음 = 2단계 도구 `되돌리기 <묶음>` · 데스크톱 안 옮김 = 기록을 거꾸로.
- 드라이브 내 소유 = 드라이브 휴지통에서 30일 안에 복원. **팀원 소유는 내 폴더에서 빼면 내가 되돌릴 수 없다**(팀원이 다시 공유해야) — 그래서 검토 후 묶음 확인(3.1 관문) 뒤에 뺀다.
- 노트북 설정(SSH 서버 · 절전 안 함 · WSL `G:` 붙이기)은 3단계가 끝나면 되돌린다(절전 원래 = 전원 연결 5분 · 배터리 3분).
