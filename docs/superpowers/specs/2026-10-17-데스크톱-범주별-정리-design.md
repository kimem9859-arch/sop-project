## 1. 목적과 원칙(사용자 결정)

1~3단계에서 노트북 · 드라이브 · 다운로드 · 퀵쉐어에서 받은 파일을 **가져온 곳 이름의 폴더째** 데스크톱에 놓았다. 그래서 같은 종류의 파일이 `노트북/` · `드라이브/` · `다운로드/` · `퀵쉐어/` · `프로젝트 백업/` · `프로젝트인지 확인/` 같은 폴더로 흩어져 있다(예: `D:\SOP가디언\문서` 에 9갈래 242개).

| 원칙 | 사용자 말(2026-10-17) |
| --- | --- |
| 같은 종류(범주) 파일은 **범주 폴더 한 곳**에 모은다 | 「카테고리 별로 나눠서 카테고리 폴더 한 곳에 흩여져 있는 폴더들을 모아두고 싶은거 뿐이야」 |
| 범주 안은 **날짜나 내용**으로 하위 폴더를 나눈다 — 가져온 곳 이름으로 나누지 않는다 | 「카테고리 폴더 안 하위 폴더로는 날짜 또는 다른 구분으로 폴더별로 구분이 되어야 하고」 |
| 문서는 **판(최종본 · 중간본 · 초안)** 이나 **달**로 나눈다 | 「문서에 대해서 최종본과 초안, 중간본을 나눠 한 폴더안에 여러 폴더로 구분 한다거나 달별로 나눠 구분했으면해」 |

**바뀌는 옛 규칙** — 폴더 규칙 9장 「Windows 에서 온 묶음은 원래 폴더 이름을 그대로 둔다(어디서 왔는지 바로 알게)」는 이번 원칙과 맞지 않아 없앤다. 어디서 왔는지는 **이동 기록**(6장)이 답한다.

├─ 한이음\
│  ├─ 개요서·수행계획서\{최종본, 초안}

- **판 판정**(파일 이름 · 원래 폴더 이름의 낱말): `최종` · `최최종` · `final` · `제출` → 최종본 / `N차 수정` · `수정본` · `_v2` 같은 판 번호 · `(1)` 사본 → 수정본 / `초안` · `draft` → 초안 / 빈 서식 · `양식` → 양식. 한 행사에 파일이 하나뿐이거나 판이 하나뿐이면 판 폴더를 만들지 않는다.
- **판 낱말이 없는 행사**(예: `하반기 프로젝트 시작 발표.pptx` · `_v2` · `_v3` · `4월 프로젝트 중간 발표` · `…수정본`) = 가장 큰 판 번호 → 판 번호가 없으면 가장 늦게 만든 판을 최종본으로 두고 나머지는 수정본(✋ Claude 결정 · 수정 날짜는 드라이브에서 다시 저장된 날일 수 있어 판 번호 · 이름을 먼저 본다). 고른 근거를 분류 표에 적고 **실행 전 보고에 행사별 「최종본으로 고른 파일」 표**를 넣어 사용자가 고칠 수 있게 한다.
- **행사(달)** = 그 문서가 쓰인 발표 · 제출의 달 — 파일 이름 · 원래 폴더 이름의 달(예: `6월 중간점검 발표 백업`) → 없으면 수정 날짜.
- 이미 안이 정리된 묶음(수행일지 · `5월 … 백업/초안/{pdf, ppt, word, excel}` 등)은 묶음 안 구조를 그대로 두고 묶음째 옮긴다(판 폴더 아래로).

## 6. 안전 · 기록

- 옮김 = 같은 디스크면 이름 바꾸기 · WSL → `D:` 는 복사 → 바이트 대조 → 원래 자리 지움(저장소 자리 점검의 `정리.py` 와 같은 방식).
- **이동 기록** 한 장(옛 자리 → 새 자리 · 결과) — 되돌리기 = 거꾸로 옮긴다. 1~3단계 대응표는 고치지 않고 이 기록으로 이어 준다(대응표의 받은 자리 → 이동 기록 → 지금 자리).
- 전 · 뒤 지문 대조 — 뒤 목록의 지문 집합 = 전 목록 − (승인받은 지움 · 같은 것과 합침), 설명되지 않는 빠짐 0.
- **실행 시점** = 승인 즉시(10/19 전 · ✋). 영상 도구 · 다른 세션이 경로로 부르는 자리(2장)만 빼고 최근 파일도 옮긴다 — 파이 · 데스크톱 저장소를 찾아 그 밖에 이 경로를 쓰는 곳이 없음을 확인했다. Windows 프로그램이 열고 있어 옮겨지지 않는 파일은 건너뛰고 끝 보고에 적는다(다음에 다시).
- 다른 세션이 쓰는 자리(2장)는 손대지 않는다. 그 세션 문서가 적은 옛 경로(예: `D:\SOP가디언\문서\다운로드` 의 구매 목록)는 이동 기록으로 찾게 하고, 끝 보고에 알린다.
- 분류는 규칙(4장)으로 초안 표(옛 → 새)를 만들고, 규칙에 안 맞는 파일은 하나씩 정해 표에 적는다 — 실행 전 표 전체를 한 번 훑어 사용자에게 **범주별 개수 · 폴더 나무 · 행사별 최종본으로 고른 파일 · 지움 후보 목록**으로 보고한다.

## 8. 검증(관문)

1. 이동 기록의 모든 「옮김」 줄 — 새 자리에 있고 지문이 옛 지문과 같다.
2. 전 · 뒤 지문 대조 — 설명되지 않는 빠짐 0.
3. 범위 안 범주 폴더에 가져온 곳 이름 폴더(`노트북` · `드라이브` · `다운로드` · `퀵쉐어` · `프로젝트 백업` · `프로젝트인지 확인`) 0 · `~/data/문서` · `~/data/드라이브자료` 없음.
4. 영상 도구가 부르는 촬영 폴더 · `intro_logo` 와 `사진/융합프로젝트_최종발표_사진` 은 전과 같다(목록 · 지문).

## 9. 버린 대안

- **문서를 달로만 나누기** — 같은 발표의 초안 · 수정본 · 최종본이 여러 달에 흩어진다 → 주제 → 행사(달) → 판.
- **문서를 지금처럼 두 곳(WSL · D:)에** — 사용자 원칙 「범주 한 곳」과 어긋난다.
- **1~3단계 대응표를 다시 쓰기** — 이동 기록 한 장으로 이어도 찾을 수 있고, 작업량이 크다.
- **영상 촬영 폴더도 날짜 폴더 아래로** — 영상 도구의 경로(`footage/<촬영>`)가 깨지고 다른 세션이 10/19 제출 영상을 만드는 중이다.
