## 1. 목적과 원칙(사용자 결정)

**목적** — 1단계로 정리된 모습을 바탕으로, 파일을 **쓰는 곳**에 맞는 기기로 옮기고 같은 내용은 한 기기에만 둔다.

| 원칙 | 사용자 말(2026-10-16) |
|---|---|
| **쓰는 곳 기준** — 파이에서만 쓰는 기록 → 파이2 보관함 · 데스크톱에서 학습 · 라벨링 · 편집할 재료 → 데스크톱 | 「추천에는 동의」 · 「파이2에 기록을 보관해주고 데스크탑에는 보내지 않는 것으로」 |
| 학습 가중치 — 파이에는 실제로 쓰는 · 쓴 모델만 · 실험 가중치는 데스크톱 학습 기록과 함께 | 「나」 |
| 같은 내용은 한 기기에만 · 다른 기기 사본은 지운다 | 「중복된 파일은 한 기기에만 보관」 |
| 발표 자료는 파이1 에 그대로 · 폴더 안만 정리 | 「파이에 있는 사본 파일을 지우는 것이 아닌 발표 자료만 있는 폴더 안이 정리」 |
| 파이2 보관함을 구글 드라이브에 한 벌 더 두지 않는다 | 「3단계에서 파이2 보관함을 드라이브에 한 벌 더 두진 말아줘」 |

**모르는 것** — 프로젝트 뒤 파이1 · 파이2 를 계속 갖고 쓸지 반납할지(사용자 「몰라」). 반납 · 초기화가 정해지면 그때 파이2 보관함을 다시 옮긴다(9장).

**파이2 를 기록 보관함으로 고른 근거** — 파이2 에 파이1 과 같은 **Hailo-8** 이 있어 측정 원본을 파이 측정 도구로 그대로 다시 돌릴 수 있다 · 파이1 과 랜선 직결이라 다시 가져오기가 빠르다 · 측정 원본 7.3GB 는 데스크톱에서 쓸 일이 거의 없다(라벨링 재료로 쓴 몫 1.1GB 는 이미 데스크톱에 있다). 대신 **SD 카드 한 벌**이다 — 드라이브 백업은 하지 않기로 했다(사용자).

## 2. 지키는 규칙

1. **옮김 = 보내기 → 받은 쪽에서 md5 대조 → 같을 때만 원래 자리를 지운다**(1단계와 같음 · 기기 사이는 tar 흐름).
2. **받는 기기에 같은 내용이 이미 있으면 보내지 않는다** — 대응표에 그 자리를 적는다. 캐시 · 가상환경 · 휴지통 · Temp · Downloads 안 사본은 치지 않는다(언제든 지워진다). 판정은 **이름이 아니라 내용(크기 + md5)** 으로 한다.
3. **파이 안에서 겹치는 사진은 한 번만 보낸다** — 같은 기기로 가는 두 묶음이 같은 사진을 가지면(예: `capture` = `label_batches` 1.3GB) 뒤 묶음은 앞 묶음이 보낸 자리를 가리킨다.
4. **예외 — 쓰임이 다른 묶음의 같은 사진은 둘 다 남긴다** ✋ — 파이2 로 가는 측정 세션(`test/raw`)과 데스크톱 라벨링 묶음(`~/data/라벨링` · `label_batches`)이 같은 프레임 약 1.1GB 를 갖는다. 세션째 · 묶음째 온전해야 각자 쓸모가 있다(측정 도구는 세션 폴더를 통째로 읽는다).
5. **바로가기(링크)는 링크 그대로 옮긴다** · 절대 경로(`/home/pi/…`)는 받은 쪽 `README.md` 에 「파이 경로 → 새 자리」 대응을 적는다(링크를 고쳐 쓰지 않는다). 하드 링크는 기기 사이에서 이어지지 않는다 — 두 기기로 갈리면 각각 한 벌씩 남는다(파이1 `label_train` 사진 일부 = `test/raw` 하드 링크).
6. **받는 곳에 같은 이름의 다른 파일이 있으면 그 묶음은 멈춘다** — 덮어쓰지 않는다.
7. **코드가 무는 자리는 폴더를 남긴다** — `Demo/recordings` · `scenario` 는 10/16 전 파일만 옮기고 폴더는 그대로 · `test/raw` · `test/videos` 는 폴더째(측정 도구가 쓸 때 다시 만든다).
8. **지우기 = 대조와 홀드아웃을 통과한 묶음만** · 데스크톱 쪽 `console_v1.pt` 는 파이2 대조 뒤에 지운다.

## 6. 검증

| 시점 | 확인 |
|---|---|
| 묶음마다 | 받은 쪽 md5 대조 전부 같음 → 🔒 홀드아웃(도구가 쓰지 않은 지문 — 10/15 · 10/16 지문 목록 · 받은 쪽 `md5sum` 표본) → 지우기 |

## 7. 되돌리기

- 묶음마다 대응표(「원래 자리 → 새 자리 · 이미 있던 사본이면 그 자리」)가 남고 도구의 `되돌리기` 로 원래 자리에 다시 놓는다.
- 지우기는 대조 · 홀드아웃 통과 뒤에만 한다.

## 8. 버린 대안

| 대안 | 버린 까닭 |
|---|---|
| 모두 데스크톱(초안) | 데스크톱에서 쓸 일 없는 측정 원본 · 파이 전용 환경 약 9GB 까지 보낸다(사용자 「파이2에 기록을 보관」) |
| 모두 파이2 | 학습 · 라벨링 · 편집 재료가 데스크톱에 없게 된다 · 파이2 SD 공간(38GB)이 모자란다 |
| 파이2 보관함을 드라이브에 한 벌 더 | 사용자 「두지 말아줘」 |
| `test/raw` 에서 데스크톱과 겹치는 프레임을 빼고 보냄 | 세션이 쪼개져 측정 도구로 다시 돌릴 수 없다 |
| 파이 안 겹치는 사진도 묶음마다 보냄 | 같은 사진이 데스크톱에 두 벌 생긴다 |
| 발표 자료를 원격 공유(Samba) | 사용자 「설치할 필요는 없어 보여」(초안에서 이미 뺌) |
