# 데이터셋·라벨링

파이프라인 전체 = `Demo/docs/dataset_pipeline.md` · 라벨링 기준 = `Demo/docs/labeling_guide.md`.

## 🔴 Roboflow 함정 3개

1. **`annotation_labelmap` 이 없으면 클래스가 숫자("0","1")로 올라간다.**
2. **`annotation_overwrite=True` 가 없으면** 이미지 해시 캐시 때문에 `already annotated` 로 넘어간다.
3. **올린 이미지를 JPEG(환산 품질 75)로 재압축해 둔다** — PNG 로 올려도 내려받으면 JPEG 다(§12.73-(3)). 실제 시연 입력은 한 번 압축(≈53)이라 **내려받은 이미지로 학습·평가하면 두 번 압축된 그림을 쓴다** → 라벨만 받아 로컬 원본과 짝짓는다.

## 분할

- ⚠️ **분할은 업로드 시점에 명시한다** — Roboflow 자동 랜덤분할 금지. 프레임을 섞으면 **누출 → mAP 거짓 상승**이다. 세션 단위 분할이 기본이나 **세션마다 촬영 변화 축이 다르므로** 무엇을 기준으로 나눴는지 함께 적는다.
- 🔴 **평가용 test 셋의 정답은 사람이 만든다 — 초벌은 보조 도구다.** 평가 대상 모델의 초벌도 쓸 수 있다. 🔑 이유 — 사람이 혼자 그리면 빼먹거나 잘못 그린 상자가 반드시 나오고, 초벌은 그것을 막는다. 조건:
  - ① **초벌을 정답으로 보지 않는다** — 상자를 하나하나 고치거나 지우고, 초벌이 그리지 않은 객체는 사람이 추가한다.
  - ② **사진마다 여러 사람(2명 이상)이 검토한다** — 🔑 이유: 검토가 놓친 초벌의 실수는 초벌을 그린 모델의 실수와 같은 모양이라(못 그린 가려진 공구 · 어긋난 채 넘어간 상자) **그 모델을 채점할 때만 유리하게** 남는다. 다중 검토가 이것을 막는다. 교대 검토(사진마다 1명)는 이 조건을 채우지 못한다.
  - ③ **재검할 사진을 모델로 고르지 않는다** — 전부 검토한다. **시험 사진으로 기계 검토를 맞추지 않는다**(시험 문제로 공부하는 셈이다).
  - ④ 점수를 인용할 때 **「채점 라벨 = <초벌 모델> 초벌 + 사진마다 N명 검토」** 를 병기한다.
  - 다른 모델 초벌 + **기계 검토**(사람 검토 일부를 기계가 맡는 흐름)는 **초벌 없이 그린 검증 표본**으로 그 장소에서 기계 흐름의 오류를 재어 통과해야 채택한다.
