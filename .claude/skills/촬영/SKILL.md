# 촬영할 때

## 🔴 촬영 직전에 반드시

- **`arduino/read_esp32_ip.sh` 를 한 번 돌린다(10초).**
  - `192.168.1.x` = 공유기(정상) / `10.47.16.x` = **폰 핫스팟으로 샜다** → ESP32 만 전원 재투입.
  - 이유 — 우선순위 스캔은 **부팅 시 연결에 성공하면 끝나고 다시 돌지 않는다.** 공유기(무선 30~60초)보다 ESP32(약 2초)가 먼저 뜨면 폰에 붙어 **그날 내내 고착**된다.
  - 🔴 **이 고장은 조용하다** — 영상도 GUI 도 정상으로 보이고 FPS 만 떨어진다.

## 구도·지시

- ⚠️ **카메라를 낮게 두면 콘솔이 화면 위쪽에** 잡힌다(높게 두면 아래쪽). **직관과 반대다.**
- ⚠️ **촬영 지시는 「주기를 끝까지 반복」으로** — 「횟수 지정」은 혼선을 낳아 재촬영을 부른다.
- ⚠️ **GPIO 로그가 정본이다** — 촬영 주기·횟수에 대한 기억·기대값이 틀린 적이 있다.

## `run_scenario.sh` (기능 검증 촬영 런처)

🔴 **발표용 시연 녹화가 아니라 「HOI·FSM 이 의도대로 도는가」를 눈으로 확인하는 도구**다.

`./run_scenario.sh <번호>` — GUI + 화면녹화 + 웹캠(3인칭)녹화를 한 번에 띄우고, GUI 를 닫으면 녹화도 정리한다.

🔴 **함정 2개 (둘 다 실제로 물렸다)**
1. **GUI 가 USB 웹캠을 점유한다** — `UsbCameraThread.run()` 이 CCTV 버튼과 무관하게 시작 즉시 `/dev/video0` 을 연다. 웹캠을 외부 녹화에 쓰려면 `config.USB_CAMERA_ENABLED=False`.
2. **OpenCV 로 웹캠을 열면 1080p 가 5fps** — 기본 GStreamer 백엔드에서 FOURCC 설정이 무시돼 YUYV 로 떨어진다. **`cv2.VideoCapture(0, cv2.CAP_V4L2)` 를 명시**해야 MJPG 가 잡힌다.

※ `SOP_FULLSCREEN=1` 은 `showMaximized` 다. `showFullScreen` 은 쓰지 않는다 — 제목표시줄이 사라져 창을 못 닫는데 **녹화 종료가 GUI 종료에 묶여 있다.**

## 검증·정리

- 🔴 **`run_demo.sh` 실기동 확인을 검증에서 빼지 말 것** — `@pyqtSlot` 시그니처 불일치처럼 **import 검사로 못 잡는 런타임 오류**가 있다. 실제로 GUI 가 기동 즉시 죽은 적이 있다.
- 🔴 **무효 세션 산출물은 무효 표시가 아니라 삭제한다** — `test/raw/<세션>/` · `test/logs/<세션>_*.csv` · `test/videos/<세션>_*.mp4`. 남겨두면 같은 `condition` 세션이 둘이 되어 분석 도구가 잘못 집고, raw 는 세션당 약 100MB 다. **삭제 대상을 먼저 나열해 보여준 뒤** 지우고 재촬영한다.
