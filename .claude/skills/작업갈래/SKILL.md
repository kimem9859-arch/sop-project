# 이 프로젝트의 표준 작업 갈래

🔴 **절차 정본은 superpowers 스킬 원문이다.** 여기는 **이 프로젝트의 갈래와 제약**만 담는다 — 스킬 본문을 복제하지 않는다(복제하면 어긋난다).

## 갈래

```
brainstorming → writing-plans → executing-plans(인라인)
  → 최종 리뷰 1회(requesting-code-review) → 공동 확인 → work-close
```

- **매 단계 전** `verification-before-completion` — 주장 전에 **출력으로** 확인한다.
- **끝은 `work-close`** — `finishing-a-development-branch` 를 이것으로 대신한다(main 경로 지정 커밋 · 브랜치 미사용).
- **마지막 태스크 = `work-close` 실행**을 계획서에 넣는다.
- 🔴 **spec 에서 멈추지 않는다** — 설계만 하고 끝난 것이 8건 있었다.

## 병렬성 — 기본이 아니다

- 🔴 **`subagent-driven-development` 는 기본이 아니다.** 파일·데이터가 겹치지 않는 병렬성이 **실제로 있을 때만** 쓴다.
  - 근거 — SDD 실행이 **18시간 30분 · 에이전트 21개 · 리뷰 52%** 를 쓰고 수확은 Critical 1 이었다. 관문 3개는 전부 계획서 문장으로도 잡혔다.
- ⚠️ **병렬을 막는 건 HW 만이 아니다** — 태스크가 DB·모듈 의존으로 사슬을 이룬다. 같은 파일을 쓰는 태스크는 병렬이 아니다.
- **실HW 검증은 직렬만** — Hailo VDevice · 카메라 · GPIO 각 1개다.
- **워크트리 미사용** — 코드가 별도 저장소(`Rpi5`)라 따라오지 않는다.
