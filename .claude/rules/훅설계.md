# 훅을 만들·고칠 때

## ⭐ 제1원칙 — 만들기 전에 「사람 규율로 이미 되는 일인가」를 묻는다

전수 검증의 결론이다. 폐기한 훅 3개는 **타이밍·구현이 틀려서가 아니라, 사람 규율(세션 마무리·단일정본)이 이미 하던 일을 기계로 중복해서** 죽었다.

- **값을 한 것** = 사람이 **못 하는** 일 — 세션 시작 시점의 원격 동기화 조회, 앱이 흘린 스텁 청소.
- **죽은 것** = 사람이 **이미 하는** 일 — 커밋 매핑, 문서 모순 점검.
- **판별 질문: 「이 훅이 없으면 실제로 무엇을 잃나?」** 답이 「사람이 잊었을 때의 보험」이면 → **보험이 지급된 실적을 먼저 측정하라. 실적 0이면 만들지 마라.**
- 훅에도 **유지비가 있다**(중복 산출물·자기증식·스텁 쓰레기·양 머신 설정 마찰). 값을 못 하면 순손실.

### 폐기 이력 — 같은 목표에 3번 시도, 훅으로는 해결 안 된다는 결론

| 훅 | 실측 | 왜 죽었나 |
| --- | --- | --- |
| `doc-consistency-check.sh`(SessionStart) | — | 타이밍상 예방 불가 · 중복 |
| `.githooks/pre-commit`(LLM diff 대조) | **12회 실행 · 적발 0건** | 재설계판. **같은 목표의 두 번째 실패.** 매 호출이 세션 스텁을 흘려 prune 이 뒤처리하는 **닫힌 루프**까지 형성 |
| `session-worklog-commit.sh`(SessionEnd 커밋 자동매핑) | **45건 중 고유정보 6건 · 구제 사례 0건** | 역할을 「세션 마무리」가 이미 전부 수행. **자기참조 증식**(기록 커밋이 다음 매핑 대상이 됨) |

→ **문서 drift 방어는 훅이 아니라 단일정본 규칙 + 편집 규율이 전담한다.**
→ **문서 커밋에 자동 점검이 없는 것은 의도된 것이다.**

## 이벤트별 타이밍 — 「무엇을 막고 싶은가」의 시점에 건다

- **SessionStart** — 브리핑·컨텍스트 주입용. stdout 이 모델 컨텍스트에 주입된다. **drift 예방엔 부적합**(이미 벌어진 뒤).
- **SessionEnd** — 로깅·정리용. **best-effort · 차단 불가.** 발동 조건이 넓다(`clear`·`resume`·`logout` 등 전부).
- **Stop** — 매 응답 종료라 너무 잦다.
- **pre-commit(git)** — 커밋되는 순간 = 예방·검증의 올바른 타이밍. ⚠️ **타이밍이 맞아도 탐지할 게 없으면 무의미**(12회 0적발).

## 탐지 설계

- 하드코딩 grep = brittle · 의미 모순 못 잡음 · **감시값을 박으면 훅 자신이 stale**.
- 의미 판단은 `claude -p`(헤드리스) + **diff 앵커**로 초점↑·비용↓.
- 🔴 **오탐 억제가 최우선** — 개방형 「다 찾아줘」는 과탐 → 노이즈 → 훅 무시 → 폐기.
- 보수적 프롬프트 — **실제 두 문장이 직접 모순 + 양쪽 인용 가능할 때만.** 「빠진 언급」은 모순이 아니다.
- warn-only · 비차단 + 바이패스 env.
- 🔴 **문서 헤딩에 문자열로 의존하는 검사는 헤딩이 바뀔 때마다 같이 깨진다** — 구조를 문자열이 아니라 **패턴(정규식)으로 느슨하게** 잡는다.

## 구현 관례 (bash)

- `set -uo pipefail` · **`jq` 비의존**(이 파이에 없다) · `timeout` · **실패해도 exit 0**(fail-open).
- **한글·비ASCII 경로** — `git -c core.quotepath=false`. 안 하면 이스케이프로 매칭이 실패한다.
- **세션 ID** — `$CLAUDE_CODE_SESSION_ID` 우선 + stdin JSON fallback.
- **경로 이식** — 하드코딩 금지. `git rev-parse --show-toplevel` · `$HOME` · env override.
- **마커 추출은 줄 맨 앞에서만** (`^-? *(⏸|▶)`) — 본문 속 글자 오탐 방지.

## 배포

- 범용은 전역 `~/.claude/`(모든 폴더 자동) / 프로젝트 전용은 그 repo `.claude/`(**pull 하면 자동 적용**).
- ⚠️ git 훅은 `.githooks/` + `core.hooksPath` 지만 **머신마다 수동 1회**가 필요해 마찰이 크다 — 실제로 Pi#1 이 설정 누락으로 **2주간 안 돌았다**. **`.claude/` 쪽을 택한다.**

## 실전 함정

- 🔴 **`git fetch` 는 네트워크가 막혀도 스스로 포기하지 않는다 — 건 `timeout` 을 꽉 채운다.** 저장소마다 걸면 **합이 곧 최악값**이다. 🔑 **부모 훅의 예산보다 작게** 잡는다 — 합이 예산과 같으면 배너가 통째로 잘린다(실측: 정상 0.5초 · 막히면 정확히 타임아웃값).
- 🔴 **예산 가드는 「지키려는 것」보다 앞에 둔다.** 뒤에 두면 이미 예산을 다 쓴 뒤라 건너뛰기밖에 못 한다.
- ⚠️ **느려진 원인을 소요 시간 **분포**로 가른다** — 값이 특정 숫자(타임아웃값) 근처에 뭉치고 중간 구간이 비면 **하드 타임아웃**이고, 고르게 퍼지면 **작업량**이다. 「최대값이 크다」만으로 원인을 지목하지 않는다.
- SessionStart 는 예방 못 함 → pre-commit 재설계 → **그것도 0적발로 폐기.**
- 측정값·네이밍을 하드코딩하면 **훅 자신이 stale.**
- best-effort 이벤트는 강제종료 시 누락 — ※ 실측상 **「누락 세션」은 애초에 커밋이 없어 훅도 무력했다.** 보험이 필요한 상황에서 작동 안 하는 보험.
- 오탐을 억제하려 엄격화했더니 **탐지력이 0으로 수렴**했다.
- 🔴 **훅이 훅의 쓰레기를 치우는 루프** — 자동 프룬 9건이 전부 자기 집 뒤처리였다. **인프라끼리 일감을 만들면 바깥에서 값이 안 보인다.**
- 🔴 **자기참조 증식** — 기록 훅의 산출물을 커밋하면 그 커밋이 다음 매핑 대상이 되어 안 끝난다.

## 세션 추적의 본체는 사람 요약이다

⭐ 기계 매핑은 폐기됐다. 실측 — **사람 블록 17개가 서사를 전부 생산**한 반면 기계 45건 중 고유정보는 6건. **의미 없는 색인보다 의미 있는 요약.**
보존·색인은 이와 충돌하지 않는다 — 대화 기반(커밋 기반 아님) · 저장소에 쓰지 않음(자기증식 없음) · 세션 마무리가 **못 하는** 병행 세션 판정.
