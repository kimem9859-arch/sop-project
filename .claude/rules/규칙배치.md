# 규칙을 어디에 두고 어떻게 관리하나

> 🔴 **자리가 곧 「언제·어느 머신에서 읽히는가」를 정한다.** 이 파일 자신도 이 규칙의 적용 대상이다.

## 규칙 공간 — 무엇이 언제 읽히나

| 공간 | 언제 읽히나 | git 공유 | 쓰는 것 |
| --- | --- | --- | --- |
| `CLAUDE.md` | **매 세션** | ✅ | 매 세션 알아야 하는 관례·「항상 X 한다」 |
| `Rpi5/CLAUDE.md` | `Rpi5/` 파일을 읽을 때 | ✅ | 런타임 코드 맥락·함정 |
| `.claude/rules/*.md` (`paths:` 있음) | 그 글롭에 맞는 파일을 읽을 때 | ✅ | 특정 문서·폴더에만 걸리는 규칙 |
| `.claude/rules/*.md` (`paths:` 없음) | **매 세션** — `.claude/CLAUDE.md` 와 같은 우선순위 | ✅ | 항상 걸리는 주제별 규칙 |
| `.claude/skills/` | **이름·설명은 매 세션**, 본문은 호출할 때 | ✅ | 다단계 절차 · 가끔 쓰는 참조 |
| `.claude/settings.json` | **항상 — 사람이 아니라 기계가 강제** | ✅ | 권한 deny · 훅 |
| auto memory | 색인(`MEMORY.md`)만 매 세션, 본문은 필요할 때 | 🔴 **안 됨 (머신 로컬)** | 그 머신 고유 사실 |
| `hanium-docs/CLAUDE.md` | **그 폴더에서 세션을 열 때** | ✅ (private) | 제출문서 작업 규칙 |

🔴 **auto memory 는 머신 로컬이다** — 파이1에 저장한 것을 데스크톱은 보지 못한다. **양 머신이 지켜야 할 규칙은 git 에 올라가는 곳**에 둔다.
🔴 **`hanium-docs` 는 sop-project 세션에서 로드되지 않는다**(형제 폴더). 제출문서 규칙만 그쪽에 두고, 전 머신 규칙은 두지 않는다.

## 규칙을 쓸 때

- 🔴 **경위를 쓰지 않는다** — **변경 시점**(「○○부터 바뀐다」·`🆕` 표지) · **`spec`/`plan` 경로** · **커밋 해시** 세 가지는 커밋 메시지와 작업로그에 둔다. 🔑 **근거(왜 이 규칙인가)는 본문에 남긴다** — 그 밖의 날짜는 근거의 일부다.
- 🔴 **같은 규칙을 두 곳에 쓰지 않는다** — 한 곳을 정본으로 두고 나머지는 **포인터 한 줄**만. 절차 정본은 스킬 원문이고 **복제하면 어긋난다**(실제로 어긋난 적이 있다).
- 🔴 **뺀 규칙은 `docs/변경이력.md` 「규칙」 절로 옮긴다.** 그냥 지우지 않는다. 이관처에 같은 내용이 이미 있으면 중복만 걷어내되 원본 위치를 커밋 메시지에 적는다.
- **길이** — `CLAUDE.md` 200줄(공식) · `SKILL.md` 500줄(공식, 넘으면 보조 파일) · `MEMORY.md` **색인** 200줄 또는 25KB 중 먼저(공식, **토픽 파일은 한도 없음**) · `.claude/rules/`·설명서 200줄(🔎 **공식 수치 없음 — 프로젝트 재량**).
  - 🔴 **줄 수만 재면 실제 분량을 놓친다** — 같은 80줄이라도 평균 줄 길이가 두 배면 읽는 양도 두 배다(`Rpi5/CLAUDE.md` 80줄·7,045자 ↔ `CLAUDE.md` 70줄·4,288자). **`wc -m` 을 같이 본다.**
- **`.claude/rules/` 는 한 파일 한 주제**(공식). 상시 컨텍스트에 있을 필요가 없으면 스킬로 내린다.
- 🔴 **`paths:` 의 첫 패턴에 와일드카드를 반드시 넣는다** — 첫 패턴이 리터럴(`docs/통합문서.md`·`CLAUDE.md`)이면 **뒤에 글롭이 있어도 목록 전체가 안 걸린다.** `**/통합문서.md` 처럼 쓴다. 🔑 **어긋나도 오류가 안 난다** — 규칙이 조용히 죽는다(실측 5/5 ↔ 0/2). 붙었는지 확인하는 법 = `cc인프라.md`.

## 소급 — 이미 쓰인 본문도 고치러 갈 것인가

🔴 **규칙은 필요할 때마다 만들어진다 — 그래서 규칙이 생기기 전에 쓰인 본문은 그 규칙을 모른다.** `paths:` 는 *「앞으로 이 파일을 열면 붙는다」* 만 말하고 **과거는 말하지 못한다.** 아래에 「소급」이라 적힌 것만 본문을 고치러 간다.
