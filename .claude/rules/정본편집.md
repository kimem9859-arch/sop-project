# 정본 문서를 읽거나 고칠 때 (📐 문서 규칙)

> 대상 = **현행 사실** `docs/통합문서.md` · **시간순 측정 기록** `docs/성능검증-저널.md` · **폐기된 사실** `docs/변경이력.md`.
> 🔴 **규칙마다 걸리는 문서와 소급 여부가 다르다** — 표는 `규칙배치.md` 의 「소급」 절이 정본이다.

## 어디에 쓰나

- **R1 편집 우선순위** — ①모순 없음 ②폐기·현행 구분 ③Claude Code 가 작업하기 쉬움. 내용은 **시간순이 아니라 주제에 맞는 자리**에 기록한다. 저널은 「갈래」, 이력은 「주제 절」이 주제 자리다.
- **R3 나누는 축은 성격 하나 · 갈래는 셋** — 문서를 **주제로는** 나누지 않고 **사본도 만들지 않는다**(grep 대상이 주제로 갈리면 한쪽만 읽고 놓친다). 같은 사실을 둘 이상에 두지 않는다.
- **R5 사실은 한 곳에만** — 측정 수치 = §12 `[CURRENT]` 표 · 설계값 = 해당 절 · 부품 = §14.1 · 핀·채널·차단 대상 = §15. 다른 곳은 「§X 참조」만 둔다.
- **R12 새 사실을 더하는 자리** — 새 소절은 **맨 뒤 번호로 덧붙이고** 지운 번호는 재사용하지 않는다. 기능 장은 **현행 동작만** 담는다. 미구현·검토 중은 **장 끝 `⏸`** 에만.

## 폐기·정정

- **R2 폐기는 옮긴다** — 폐기된 사실은 `변경이력.md` 로 옮기고 본문에는 **현행만** 둔다. **옮기지 않고 그냥 지우지 않는다.** 🔴 **예외 = §12** — 측정 절은 본문에 남기고 머리에 `⛔ SUPERSEDED-BY §12.N` 마커를 단다.
- **R9 정정 경위는 본문 밖** — 날짜·출처·이유는 **커밋 메시지와 작업로그**에 남기고 본문에는 바뀐 사실만 둔다. 🔴 **근거(왜 이 규칙·값인가)는 남긴다.**

## 측정을 기록할 때 (형식)

> 🔴 **절차**(세 문서를 함께 고치기 · 기계 검사 · 이관)는 `work-close` 스킬이 정본이다. **여기는 형식만** 정한다 — 서로 베끼지 않는다.

- 새 측정은 `성능검증-저널.md` 의 **해당 갈래 끝**에 새 절로.
- 절 제목은 **평문** `### 12.N <주제> (<조건·날짜>)` — **이모지를 쓰지 않는다.**
- 제목 **다음 빈 줄 뒤 인용문 한 줄**로 유효성 마커 — `> ✅ **CURRENT-AS-OF <날짜>** — <한 줄>`
- 하위 블록은 `#### (N) 이름` 으로 번호를 붙이고 🔴 **번호는 맨 뒤로만 늘린다** — 다른 곳에서 `§12.N-(M)` 으로 가리키므로 중간에 끼우면 이미 나간 참조가 틀어진다(끼워야 하면 `(3-b)` 처럼 하위 번호).
- 절 번호 `§12.N` 은 바꾸지 않는다. **표를 고치지 않은 측정은 확정값이 아니다.**

## 읽고 인용할 때

- **R4 grep 으로 읽힐 것을 전제로** — 수치는 **조건과 같은 줄**에 적는다. 같은 지표에 값이 여럿이면 구분 표시(`[CURRENT]` 등)를 붙인다.
- **R7** — 통독하지 않고 grep 으로 범위만 읽는다. 수치는 `[CURRENT]` 표부터, §12 절은 마커부터 확인한다. **인용할 때 조건을 함께 옮긴다.** 표와 절이 어긋나면 **절이 옳고 표를 고친다.**

## 표기

- **R8 헤딩은 여섯 모양뿐이다** — `## N. 제목`(장) · `## 이름`(번호 없는 구조 블록 — `## 목차`·`## 부록`) · `## <이모지> 갈래 이름`(**저널 전용**) · `### N.M 제목`(`§N.M` 으로 가리킨다) · `### <이모지> 이름`(번호 없는 고정 블록) · `####` 이하. 🔴 **`§12` 절 제목에는 이모지를 쓰지 않는다** — 유효성은 마커 줄이 말한다. 문서 표제부는 적용 밖.
- 폐기는 `⛔` 하나다.
- **R10 목차** — 셋째 열은 **「이 장에서 답을 찾는 질문」 한 문장**(물음표로 끝남)만. 날짜·상태·수치·버전은 넣지 않는다. 저널·이력에는 목차가 없다.
- **R11 과장된 표현을 쓰지 않는다.** 수치를 인용할 때의 조건 병기는 `수치인용.md` 가 정본이다.

## 외부 소스로 갱신할 때

- 🔴 **덮어쓰지 않고 보존·부가·연결한다** — 발표자료 등 외부 소스의 내용을 가져올 때 기존 서술을 지우지 말고, 달라진 부분을 **근거와 함께** 더한다. 덮어써야 하면 R2 대로 `변경이력.md` 로 먼저 옮긴다.
