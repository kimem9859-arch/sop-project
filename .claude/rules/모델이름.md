# 모델·실험을 부를 때

- 🔴 **범위 = 1단계(2026-10-03)부터 만든 모델** — 이미 이름이 정해진 것(`E0b-…` 실험 · 변환 `model.hef`·`MZ`·`UL` 등)은 **파일·문서·기록을 고치지 않고** 대조표(`Rpi5/학습/이름대조표.md` · 통합문서 §6.4)에서만 새 이름을 준다. 1단계 이전 모델(`console_v1`·`console_v2`·`tool_v*`·`button_r1`·`tool_r*`)은 이름 그대로 — 예외 = 흔해 겹치던 `best.pt` → `person_v1.pt`. 근거 = 사용자 범위 결정(문서·기록을 넓게 고치지 않는다).
- 🔴 **보고·대화에서는 대조표의 새 이름으로 부른다** — 실제 파일 경로를 적을 때만 옛 이름. 근거 = 사용자가 `E0b`·`E0c` 같은 이름으로는 무엇인지 구분하지 못했다.
- 🔴 **B·T 바로 뒤에 숫자를 붙이지 않는다** — `B1`~`B4` 는 버튼 종류 이름이다.
- 새로 만드는 실험 설정 파일 이름 = 새 꼴 id(`<B|T>-<early|full|check>-<바꾼 것>[-<꼬리>]-s<시드>`) — 옛 꼴은 시험이 막는다.
- 설정·결과·변환 기록이 늘면 `python3 학습/학습.py 이름표` 로 대조표를 다시 만든다(시험이 낡은 대조표를 잡는다).
