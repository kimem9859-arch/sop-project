# 모델·실험을 부를 때

- 🔴 **보고·대화·새 문서에서는 새 이름으로 부른다** — 규칙·목록 정본 = 통합문서 §6.4 · id 하나하나 = `Rpi5/학습/이름대조표.md`. 옛 이름(`E0b-…` · `console_v2` · `best.pt` · `tool_v*` · 변환 `U2`·`MZ`·`UL` · 후보 `B0~B4`)은 실제 파일 경로를 적을 때만 쓴다. 근거 = 사용자가 `E0b`·`E0c` 같은 이름으로는 무엇인지 구분하지 못했다.
- 🔴 **B·T 바로 뒤에 숫자를 붙이지 않는다** — `B1`~`B4` 는 버튼 종류 이름이다. 후보 이름도 낱말로(기준 · 색 · 좌우 · 가림 · 흐림).
- 새 실험 설정 파일 이름 = 새 꼴 id(`<B|T>-<early|full|check>-<바꾼 것>[-<꼬리>]-s<시드>`) — 옛 꼴은 시험이 막는다.
- 변환 모델은 「학습 모델 · 방식」(`B-early-base-s0 · zoo`)이나 파일 이름(`B-early-base-s0_zoo.hef`)으로 부른다.
- 설정·결과가 늘면 `python3 학습/학습.py 이름표` 로 대조표를 다시 만든다(시험이 낡은 대조표를 잡는다).
