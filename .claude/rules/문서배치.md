# 쓸 내용을 어디에 두나

> 각 문서는 자기 주제만 담는다. **무엇이 어디 있나(위치·경로)** 는 [`README.md`](../../README.md) 가 답한다 — 이 파일은 **쓸 곳**만 정한다.

| 쓸 내용 | 갈 곳 |
| --- | --- |
| 규칙·절차·금지사항·**함정** | `CLAUDE.md` · `.claude/rules/` · `.claude/skills/` (자리는 `규칙배치.md`) |
| 무엇이 어디 있나 (위치·경로) | `README.md` |
| 설계·사양·SOP·하드웨어 | `docs/통합문서.md` |
| **폐기된 사실** — 예전엔 어땠나 | `docs/변경이력.md` (측정 수치는 제외 — §12 `⛔` 마커가 정본) |
| 측정 **절 본문** — 언제 어떤 조건에서 나왔나 | `docs/성능검증-저널.md` 의 해당 갈래 끝에 새 절 |
| 측정 수치의 **확정값** | `docs/통합문서.md` §12 머리 `[CURRENT]` 표 — 저널에 절을 쓰면 **같이** 고친다 |
| 미결·알려진 위험 | `docs/통합문서.md` §12 머리 🔓 미결 표 |
| 무엇을 했나 — 완료·경위·판정 | `docs/작업로그.md` |
| CC 인프라 작업(훅·스킬·도구) | `docs/claude-code-작업로그.md` |
| 훅 구성·작업 방식·설계 원칙 | `docs/claude-code-작업문서.md` |
| 작업 전 설계·거부한 대안 | `docs/superpowers/specs/` |
| **지금 어디까지 · 다음 할 일** | `docs/작업로그.md` 의 `⏸`/`▶` |

🔴 **헷갈리면 「이것이 사실인가 규칙인가 기록인가」를 먼저 묻는다** — 사실은 통합문서, 규칙은 로드되는 면, 기록은 작업로그다.
